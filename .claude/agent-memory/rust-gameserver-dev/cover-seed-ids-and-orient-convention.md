Since NA21 (2026-09-25) `resources.cover_*` is generated by the `cover_extract`
bin in `crates/navmesh-extractor` from `SGWSpecCoverNode` / `CoverNodeArray`
markers in the `.umap` chunks. Procedure: `docs/engine/cover-extraction.md`.

- **Set ids are `world_id * 100000 + n`, in chunk-file then export order.**
  Content chains key `player_entered_cover` on them (1132/1133 use 1200001,
  the med-station desk). A re-extract against another client build can
  renumber. `cover_chain_key_is_the_set_a_player_at_the_desk_is_in` catches the
  desk; grep `player_entered_cover` in the Content seeds for any others.
- **The tool rewrites both seed files whole.** A world left off the `--map`
  list loses its rows.
- **`orient` convention: facing = `(cos o, sin o)` in BW `(x, z)`**, the one
  `cell/cover/scoring.rs::is_flanked` uses. Entity yaw is `dx.atan2(dz)`, so
  `orient = π/2 − yaw`. Don't feed an entity yaw into cover code, or the reverse.
- **Omitted cooked properties are archetype values, not 0.** CoverHeight→Low,
  CoverWidth→1.0, CoverQuality→3 (None). Quality is inferred because byte 3 is
  never written and 0,1,2,4 are. See [[ue3-absent-property-defaults]].
- **The cover index is per world.** `CoverIndex::nearby(world_id, ..)`,
  `sets_near(cover, Option<world>, ..)`, `pick_best(index, world, ..)`,
  `maintain_cover_for_npc(.., world_id: Option<i32>, ..)`. A test fixture whose
  space has no stamped world id silently gets no cover. Stamp it with
  `mgr.stamp_world_rows(&HashMap::from([("Castle".into(), WorldRow::enforcing(TEST_WORLD_ID))]))`.
- `resources.cover_nodes_chunk_id_fkey` already existed at the top of
  `db/resources/_foreign_keys.sql`, so grep the whole file before you add an FK.
  A duplicate only fails at `reload-db.sh` time ("constraint already exists").

**Why:** the prefab-local `.pak` corpus had been loaded as world positions.
Castle and Cellblock overlap in BW coordinates, so one global grid leaked
cover across worlds.

**How to apply:** before touching cover seeds, grouping thresholds or any
cover-query signature.
