On 2026-10-14 the owner chose four early Union zone owners: SGC_W1, Dakara_E1, Omega Site and Beta Site E1, covering Human, Free Jaffa and Asgard through first Beta E1 play. Omega is the first shared SGU hub; Beta E1 is the first common field map. The Human route implements first, but all three are planned now. Tollana remains in the separate Praxis campaign. See `docs/analysis/union-zone-planning/README.md` and `evidence.md` for source citations and the execution gate.

The owner approved a short authored Free Jaffa level-1 Dakara bridge scouting divided Jaffa loyalties because the project's current Dakara start predates recovered level-3–5 quest text that implies SGC events. The owner approved a post-Pertho Asgard prologue using existing Omega geometry and a remote Council scene because the audited handoff lacks named production maps for Pertho and the physical High Council. It centers on rescued consciousness databanks and their custody; the new character did not cause the original Pertho records leak. Preserve stock mission history and label new content explicitly; see `free-jaffa-route.md`, `asgard-route.md` and `asgard-post-pertho.md` in the same planning directory.
