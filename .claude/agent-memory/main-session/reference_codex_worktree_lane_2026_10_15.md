# Codex worktree and build-lane observations (2026-10-15)

- DW-01's app-managed worktree lacked the `external/` junction that `tools/build-lane/mk-worktree.ps1` creates. Its first `cimmeria-entity` C++ build failed until the junction was added to the repository's existing `external/` tree; the rerun passed clippy and broker tests. Source: DW-01 packet run and `tools/build-lane/mk-worktree.ps1`.
- In DW-02A, a sandboxed `lane.ps1` call reported both slots busy with blank holder details for over ten minutes. Separate sandboxed calls showed a different temporary `LOCALAPPDATA` location each time and no visible lane lock directory. Stopping that wait and running the same lane command with elevated workspace access reached the machine-wide lane: fmt and clippy passed immediately, and tests ran there. Do not remove lane slots manually or run compiling Cargo outside the lane. Source: DW-02A packet run and `tools/build-lane/lane.ps1`.
- The existing supervisor event store has bounded named cursors, but it reports an eviction gap as a Boolean and does not offer exact per-reader drop counts or per-source limits. DW-01 therefore introduced a separate pure workbench broker with a 300-second age limit and 64 KiB JSON row cap; later tap integration remains DW-08. Source: `crates/lab/src/supervisor/events/store.rs` and DW-01 implementation/review.
