Source: Explore agent, 2026-10-31. Nothing verified against a running lab (cimmeria-lab, lab-server and signoz refused connections that session). Return shapes come from `#[tool]` descriptions and `docs/guides/live-research-lab.md`; response-building code was mostly not read. ## 1. Architecture
- Supervisor and MCP server: `crates/lab` (Windows-only Rust, `rmcp` + axum). Stdio (one per session) or a shared daemon at `127.0.0.1:8779/mcp` (bearer token, one instance per logon session). Several clients via `CIMMERIA_LAB_INSTANCES` and the optional `instance` arg (default, p2, up to five). Config: `.mcp.json.example`; `tools/lab/daemon.ps1` runs the daemon as a scheduled task.
- Tools are `#[tool]` methods in `crates/lab/src/server/*.rs` (about 80, 12 files). `server/handler.rs` custom `call_tool` order: route to instance, lease gate, compact args, tool router, shape response. Each call logs `lab.call` (tool, instance, lease owner, outcome, duration; never arguments).
- In-client DLL: `crates/client-telemetry` (i686), `--features lab-bridge`, also gated at run time by a `lab` block in `current-session.json`. `sgw-start32.exe` launches SGW.exe suspended and injects the DLL (the 64-bit supervisor cannot inject directly).
- Daemon-to-client channel: framed JSON-RPC 2.0 over loopback TCP (`crates/lab/src/client.rs`, `crates/client-telemetry/src/bridge/transport.rs`). 4-byte LE length + UTF-8 JSON, 64-hex token as first frame, default port 8770 (`CIMMERIA_LAB_BRIDGE_PORT` per instance). The IO thread queues requests (64 deep); the main thread drains them inside the `FEngineLoop::Tick` hook; the tick count doubles as the watchdog heartbeat.
- Server-side MCP: `crates/lab-mcp` (`server_*` tools, token-gated, optional `lab-chaos` feature). CLI: `crates/lab-cli`.
- Two permission layers:
  - Lease policy `crates/lab/src/lease/policy.rs`: tools are OPEN, LEASED or OWN_LEASE; unclassified fails closed; a test enforces every routed tool is classified.
  - Agent `.claude/agents/lab-driver.md`: `tools: mcp__cimmeria-lab` plus a long `disallowedTools` list (login and character tools, raw `client_mem_*`, `client_call_native`, `client_console`, `client_hook_*`, `client_input_key`, `client_ui_click`, record, golden, calibrate, `lab_uat_attest`). `.codex/agents/lab-driver.toml` mirrors it.

## 3. Client side today
- State reads: entity position from memory (`AActor::Location` at actor+0xDC, rotation +0xE8); names, levels, hostility via stock `unit*` Lua through private unit slots 7700+; screen points via the game's `view:worldToPixel`. UI, chat, inventory, hotbar, combat log, player state: Lua reads plus window reads. Events: supervisor store (8192 events, named cursors, 1 s keeper drain; `supervisor/events/`). Camera: only `view_before/after` reliable; `camera_before/after` can read a zero pose (`live-research-lab.md` ~889, 925).
- Input: keys and typing are posted `WM_KEYDOWN/UP`; Shift virtual via hooked `GetKeyboardState`/`ToUnicodeEx`. Mouse buttons posted window messages applied at CEGUI's cursor. Cursor movement and drags call CEGUI native injectors via `call_native` (`supervisor/cegui_native.rs`, fake in `cegui_fake.rs`); posted `WM_MOUSEMOVE` never reaches CEGUI. Mouse-look via a DirectInput hook (`bridge/input/dinput.rs`); DI keyboard created but never read. Virtual focus fakes `GetForegroundWindow` and friends. Camera is native via `ASGWCamera_Player` vtable thunks. No SendInput, SetWindowsHookEx or UE3 `InputKey` use found in `crates/**/*.rs`.
- Native tiers: N1 real input + native camera, N2 slash command, N3 stock UI Lua, G (GM setup typed into chat), X (server shortcut). Only N1 counts as native pass.
- Screenshots: GDI `PrintWindow` by PID to `%LOCALAPPDATA%\cimmeria-lab\screenshots` (`supervisor/screenshot.rs`); path returned unless `image: true`.
- Game calls: `client_call_native` (addr, conv, args, ret), `client_mem_read/_write`, `client_hook_install` (dynamic cdecl hooks with capture), `client_lua_eval`.
- Hooks: `crates/client-telemetry/src/hooks/` (inline, IAT, vtable). Fingerprint gate installs nothing on a non-QA SGW.exe; shared prologue/chaining rule in `crates/client-hookgate`. `bridge/dynamic_hooks/` handles `hook_install`. Anchors: `docs/reverse-engineering/findings/client-instrumentation-hookpoints.md`. `CIMMERIA_CLIENT_HOOKS_DISABLE` kill switch.
- Bridge methods (`bridge/dispatch.rs:135-205`): `lua_eval`, `heartbeat`, `module_info`, `mem_read`, `mem_write`, `call_native`, `hook_*`, `events_read`, `console`, `input_*`. No entity, UI or camera bridge methods: the supervisor builds those from `lua_eval`, `mem_read`, `call_native`.
