## Differences from the contract

1. **`LabChaos::clear` returns `usize`** (entries removed), not `()`. The
   CH-05 `server_chaos_clear` tool reports `{cleared: n}`, and counting
   inside the lock is the only race-free way to get `n`. Callers that ignore
   it are unaffected.
2. **`addr_hash` is keyed per process.** It is a SipHash of the address
   under a `RandomState` made when the registry is created, printed as 16 hex
   digits. Rows from one server run correlate; across restarts they do not.
   An unkeyed hash of an IPv4 address can be reversed by hashing every
   address, which would make it the address under another name.
3. **`seed` is 0 when the profile has none** (`flush` delay, pack and a fixed
   shift). Otherwise it is the net seed, else the flush seed.
4. **`LabChaos` also implements `Default`** (clippy's `new_without_default`).
5. **One extra test**, `set_logs_a_hash_never_the_address`, guards the
   logging rule. `install_refuses_without_developer_mode` also checks that a
   refused install leaves `current()` empty and that `install(true)` then
   installs: it is the only test that touches the process-wide registry, so
   the two halves cannot race another test.
