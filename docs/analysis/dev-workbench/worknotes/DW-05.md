# DW-05 spatial model and bookmarks

The spatial frame reads client world, player, entities, screen projections and camera through existing lab readers. Authored regions and spawnlist are world-filtered read-only DB rows. Server runtime entities remain unknown until DW-03S-B proves a current client/server session binding. No map asset parser or seed writer was added.

Bookmarks live in the daemon's per-user `workbench/bookmarks/<instance>.json`, use stable UUIDs, and hold BigWorld metre coordinates, facing, observation time, operator-supplied source label and optional screenshot path. Mutating routes use the browser cookie/CSRF boundary. Actions additionally require a current lab lease and refuse a different world or a known space ID that cannot be revalidated. A same-world action with unknown space carries `space_verified: false`; submitted slash text and a dispatched point click carry `effect_verified: false` until independent readback exists.

Offline regression guards cover entity-ID collision across worlds/spaces/instances, stale-frame refusal, bookmark persistence and update/delete, and cross-world action refusal. Live spatial projection, native click and teleport effect are deferred to the separately approved lab UAT packet.
