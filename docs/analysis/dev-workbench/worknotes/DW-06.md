# DW-06 mission X-ray handoff

The local mission API now reads `resources.missions`, ordered `resources.mission_steps`, mission-scoped `resources.content_chains`, and the visible tracker for one selected positive mission ID. The five evidence layers remain independent. A pure read model shows a persisted active step and tracker text disagreeing and treats missing definition data as unknown. No seed rows or mission mechanics changed.

The live route has no trusted client-to-server session binding producer yet, so it does not query a player's `sgw_mission` row. The model accepts a bound context for the later DW-03S-B integration and requires unique agreement of session and player entity in `server_sessions` before a player-ID query. Wire mission packets and client mission-ID state remain unknown until DW-08 and a supported client reader respectively. The route does not drain the shared packet tap. Mission-scoped chain references are only the links directly resolved by `resources.content_chains`; this does not claim to enumerate every cross-scope chain with a mission condition.
