# DW-07 review handoff

The click callback now remembers the child-to-parent chain before rejecting a child with an invalid or oversized widget name. A bubbled parent at the same time and position is suppressed, so it cannot become a false `ui.click`. The Lua-stub regression uses a 1,025-byte child name, then a parent callback, and checks for zero click rows and one rejection. A subsequent click at a different position still records.

DW-10 must consume `PumpReport.click_rejected_total` and `click_rejected_lines` from the client pump when building recording drafts. `uat/record/sampler.rs::sample` currently reads `lua_error` from the pump and clicks from the event store, but does not carry these rejection counts into the draft. Mark any count increase or rejected line as an explicit evidence gap; do not present the recorded click sequence as complete.

Live-client bubbling remains unverified until the separately approved lab UAT packet.
