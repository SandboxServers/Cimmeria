# DW-16 — Lab overlay render/device seam

The existing `Direct3DCreate9` IAT detour and `CreateDevice`, `Reset`, and `TestCooperativeLevel` COM hooks provide the device pointer. The bootstrap installs these only after the global SGW.exe code and slot fingerprint report is usable; per-IAT import checking still applies. Boot retains that actual report for the later overlay gate, which also requires a Create9 detour hit and an active bridge. An EndScene slot is patched only in `lab-bridge` after `bridge_epoch()` exists. The render callback reads only atomic coarse status bits, draws three bounded opaque rectangles with `Clear`, and wraps them in `D3DSBT_ALL` capture/apply/release. The original EndScene runs after the panel path regardless of panel errors. A second device with the patched vtable remains auxiliary through CreateDevice, Reset, and TestCooperativeLevel probes. It becomes active after the selected device is lost or after two seconds since accepted creation or the last successful selected-device EndScene, once a successful foreign EndScene arrives. Auxiliary EndScene frequency cannot displace an owner that continues presenting, including three auxiliary calls between two owner frames. The two-second threshold uses a monotonic clock and a deterministic test clock. The handoff takes the same guard as a panel frame, so a foreign EndScene cannot displace the owner while its frame may still record a fault; busy handoffs defer until a later successful EndScene. A different vtable is refused without consuming the patch-failure budget. The unsupported-fingerprint test passes a real rejected report to the production gate and asserts that the patch callback is never invoked.

The device state disables rendering while lost or after a failed Reset, permits it after successful Reset, rejects recursive EndScene, and permanently disables it after three faults. The software budget is checked between driver calls; it cannot interrupt an individual slow D3D call. Failure reasons and counts are recorded atomically by EndScene and drained every 200 ms by one lab-only non-render worker into a bounded one-shot diagnostic event. Actual patch failures also record a reason and stop retries after three failures. Live COM vtable writes are serialized and use an aligned atomic compare/exchange after temporary page unprotection; an intervening slot change fails closed and retains the original callback. The panel has no text or target identity yet; DW-18 will publish trace/record/gap bits and controls. The no-client host tests use fake device operations and lifecycle state, including concurrent same-vtable installation. No original executable or live lab client was used.
