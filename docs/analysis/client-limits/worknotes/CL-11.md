**Method.** The fixture's `messages` array holds 84 records (49 inbound, 35
outbound). Records were sorted by `ts_ms`; values are the difference of two
`ts_ms` in milliseconds. Teleport pairs: each `gmGotoXYZ` with `dir` `in` and
`method_index` 163 (2 records) against the first later outbound record whose
name is `CREATE_ENTITY` or `onStaticMeshNameUpdate`. Neither name occurs, so
the row reports the first later outbound record of any name instead. Hold
pair: `onClientReady` to the first introduction; no `onClientReady` record
exists, so no pair. Gap pairs: each consecutive pair of outbound records (34
pairs); the maximum is reported. Outbound records carry no `msg_id`, so they
are matched by `msg_name`; one decodes as `unknown` (method 27) and still
counts as a record in the gap pairs. Capture date: the first `ts_ms` is
2026-10-10 22:04 UTC, matching the fixture's last commit date
(`git log -1 -- crates/wireclient/tests/fixtures/praxis_start_tap.json`).
