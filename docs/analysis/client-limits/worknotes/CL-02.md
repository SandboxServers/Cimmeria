# CL-02 worknote: client receive, resend and drain limits

> Type: worknote. Packet CL-02 of the [client-limits campaign](../README.md). Destined for `docs/client/limits/network.md` (CL-01 has not merged); the coordinator folds the rows in. Evidence and addresses: [client-mercury-receive-path.md § Receive limits](../../../reverse-engineering/findings/client-mercury-receive-path.md#receive-limits-cl-02-2026-10-11-static). Method: headless Ghidra on `SGW.exe`, read-only; no live client.

Column format is the contract's. Safe and break levels are `n/a`: none of these rows is driven by a lab-chaos profile.
