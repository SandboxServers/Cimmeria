## Method

- **World attribution.** `client.engine.memory` and `client.engine.hitch`
  carry no world. Each sample is attributed to the most recent
  `client.engine.level_visible` event with `visible = true` in the same
  session (ClickHouse `ASOF LEFT JOIN` on `session_id`), taking the package
  name before its first `-` (`Ihpet_Crater_Light-fff90001` is
  `Ihpet_Crater_Light`). A sample before the first map is `Login_Map`.
- **`peak_working_set_mb` is cumulative per process**, so a peak reported
  under `Login_Map` can come from an earlier world in the same process (a
  return to character select). Read it as "peak so far".
- **Hitch counts are lower bounds.** `client.engine.hitch` goes through the
  sink throttle (`suppressed` counts the dropped ones), and lab sessions in
  firehose capture use a 100 ms threshold instead of 200 ms.
- **World entry** pairs each server `Client requests playCharacter` with the
  next `SGWPlayer.onClientReady received` from the same client address
  (`ASOF` join), keeping pairs between 0 and 120 s (251 of 269).

## Decides

- **D-CL4.** Moot: the stock exe is already Large Address Aware (CL-04's PE
  read, confirmed here by `total_virtual_mb` = 4096). CL-12 is dropped.
- **But the 4 GB space is not slack.** Ihpet_Crater_Light player sessions
  reach 135 MB free with 3.5 GB committed. Any CL-13 override that grows a
  pool (texture streaming) must be measured on Ihpet first, and lab-chaos
  must not count on address-space headroom there.
