This is the **continuation** of Castle_CellBlock, world 12. The player escapes once. Keep the restored route from missions 622, 638–641, 680–689, Marsh, Livewire, and the armory ring intact. Add no repeatable quest, service hub, or forced kill to this world. Castle world 8 owns any returnable follow-up. The final developer ZIP's map bindings and scripted Matinee rows supply historical leads, not proof of current combat spawns or runtime presentation. The ZIP's named SQLite databases were never supplied. The recovered [oral history](story-research.md) supports the Op-CORE prison premise but does not define four-zone quest order.

The scopes below are complete as **dispatch contracts with sealed gates**. A gate is a required artifact or measurement, not permission for a coder to improvise an ID, client action, position, dialogue, or reward. The coordinator records resolved values in the Cellblock campaign ledger before marking an implementation packet `Ready`. If the gate finds no gap, mark the packet `Done / no change`; do not manufacture a commit to satisfy the packet count. If a gate finds multiple unrelated defects or more than one room cluster, clone the relevant packet contract with a suffixed ID and one defect or cluster per clone. Specialist packets are intentionally research/design work; they are not Haiku coding assignments.

## Shared dispatch and wave contract

Use the [four-zone campaign formula](execution-contract.md) for status, wave integration, review, fixes, CI, and the final remote PR. Cellblock's campaign branch is `content/cellblock-campaign`; packet branches are `cellblock/<id>-<slug>` in `.claude/worktrees/cellblock-<id>`, each with its own `sgw_<worktree>` test database. The coordinator creates those only when implementation begins, using `pwsh tools/build-lane/mk-worktree.ps1`; a packet worker edits only its allowlist and commits locally. It does not push, open a PR, take a lab lease, or change sibling campaign files. Integrate completed packet commits into the campaign feature branch at each wave boundary. Run local CI and adversarial review of the **integrated feature branch** after every wave, route verified findings to a fresh fixer agent, and give the repaired diff to a fresh reviewer, up to three review/fix rounds or until no issues remain. A remaining issue after round three blocks the wave and requires a newly scoped correction. The remote PR is opened only when the complete campaign passes local CI and final review. The one exception is CB-N05a, which ships early as its own PR to `main` (owner decision, 2026-10-13). Do not merge this campaign over a live asset-audit, ring, or class-start dependency without reconciling its branch/ledger first. Retire each packet worktree with `pwsh tools/build-lane/rm-worktree.ps1 --force <name>` once its commit is in the campaign branch; packet branches are never pushed, so `--merged` does not find them.

Haiku packet execution budget (owner decision, 2026-10-13): about **40k coder working tokens within the 90k total-context cap**, checked when the coordinator seals the packet; a sealed contract over budget splits into children before dispatch. Per-packet "50–60k" figures below predate that decision and are superseded for Haiku workers. If a gate or review correction threatens the budget, split a new packet while preserving the three-round quality gate. Each worker receives only this packet section, the frozen manifest it names, relevant repo rules, and the owned worktree path. It reports its commit, changed files, checks, test-revert proof, and unresolved facts once. Do not idle a worker while another packet runs. Use PowerShell, no direct compiling `cargo`; each compile/test goes through `pwsh tools/build-lane/lane.ps1`. Format before clippy; run affected crate checks and tests before any full-workspace wave gate. Live-DB tests use `pwsh tools/build-lane/live-db-test.ps1 <filter>` in the packet worktree after seed reload per the [seed-change skill](../../../.claude/skills/seed-change/SKILL.md). A runtime PR requires a regression test that fails on the pre-fix behavior. **Telemetry (owner decision, 2026-10-13):** every chain, mission or encounter packet emits progress telemetry (chain fired, step advance, objective credit, refusal reason) sufficient to debug the route from SigNoz alone, and its acceptance names those events. Update the packet's campaign worknote and the matching row in the ledger. Status/gap docs change only in the shared four-zone close-out FZ-99; CB-N08 updates the Cellblock ledger and content docs.
