## Lessons

- **One branch for the tail.** A PR freeze held four finished packets; the owner had them consolidated on one branch and shipped as #1642, then the last chain as #1645. One PR per wave tail cost less review than seven small ones, and the per-packet worktrees could be retired early.
- **An unverified WIP commit is not a packet.** TG-MIS-11's coder hit its turn limit and left a commit that had never been through the lane. It was finished, lane-checked and guarded on the tail branch before shipping; a coordinator resuming a capped worker checks that first.
- **Status docs once.** W0 deliberately left the gap analysis alone; this close-out made the one update, so no packet PR touched the status docs and none conflicted there.
