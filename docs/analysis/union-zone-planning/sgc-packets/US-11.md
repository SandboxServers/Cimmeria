## Goal

Seed every world object and region the SGC chains need: Harriman in the Control Room, Carter's virus terminal, the Failsafe Device, six pressable crates, two cylinder regions, and tags on the untagged static Jaffa rows 57-63 (D-US10 default **B**). This packet adds no chains.

## Rules (binding; this packet carries its own rules)

1. PowerShell only, absolute paths, and start every command with `Set-Location <worktree>;`. No bash.
2. Every compiling `cargo` call goes through the lane, in the foreground, in this order:
   1. `pwsh tools/build-lane/lane.ps1 cargo fmt --all -- --check`
   2. `pwsh tools/build-lane/lane.ps1 cargo clippy -p cimmeria-cell-content --all-targets -- -D warnings`
   3. `pwsh tools/build-lane/live-db-test.ps1 chain_replay_tests::union_sgc::world_seeds`
   4. `pwsh tools/build-lane/lane.ps1 cargo nextest run -p cimmeria-content-engine`

   Never run `cargo` directly. Never point anything at the database `sgw`.
3. Edit only the Allowlist. Never touch `dakara*`, `omega*` or `beta*` files, `db/scripts/`, chain files, or `union_sgc/mod.rs` / `rig.rs`.
4. Seeds are the source of truth: `db/resources/` only, no migrations. Seed SQL line endings match the neighbouring seed in the working tree (Union execution contract, Line endings); one `INSERT` per line.
5. Files have a soft cap of 500 lines and a hard cap of 700.
6. No `git stash`, no `git worktree prune`, no push. One local commit, with `git add` naming each path.
7. Tests are live-DB tests named `live_db_…`; the first line is `let pool = require_db_or_skip!();`; each doc comment names the revert that makes it fail.
8. Every new row's SQL comment carries a provenance label: these rows are all CIMMERIA_RECONSTRUCTION.
9. No lab, no live client. The shell guard wants `# guard-ok` at the end of any `Get-Content`/`Select-String`; prefer Read and Grep.
