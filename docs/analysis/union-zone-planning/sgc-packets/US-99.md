## Goal

Status docs change **once per campaign**, here. Fold the per-packet reports into the shared docs, state plainly what was tested in the client and what was not, and close the ledger.

## Rules (binding)

1. PowerShell only, absolute paths, `Set-Location <worktree>;` first. No bash. No `cargo` at all (docs only); if a check needs a build, it goes through `pwsh tools/build-lane/lane.ps1`.
2. `docs/**/*.md` is CRLF. After each edit: `$p='<abs path>'; $t=[IO.File]::ReadAllText($p) -replace "`r?`n","`r`n"; [IO.File]::WriteAllText($p,$t)`.
3. Never hand-edit a `<!-- gen:NAME -->` block; if one needs to change, run `python tools/docs-gen/regen.py` and commit its output.
4. Edit only the Allowlist. Never touch `dakara*`, `omega*` or `beta*` docs (their close-outs own them), seeds or code.
5. Files: soft cap 500 lines, hard cap 700. `unified-uat.md` is already long: add one section, do not grow other sections.
6. Say what was tested in the client and what never was. A row the lab never ran is "NT" (not tested), never "works".
7. No `git stash`, no `git worktree prune`, no push. One local commit naming each path.
8. Write for players and testers in plain English; no packet ids in player-facing UAT steps (ids go in the ledger).
