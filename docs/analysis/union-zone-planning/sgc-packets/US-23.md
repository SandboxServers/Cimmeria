## Goal

**1569** "Check the storage crates for any useful supplies." has one step, 4640, with **six required** objectives: 5381, 5385, 5386, 5387, 5388, 5389. H3 (architect, sealed by US-01) maps one crate to each objective:

| `SGC_W1_Crate2` | 15806 | 5385 | 5385 (LMG and flak jacket) |
| `SGC_W1_Crate3` | 15807 | 5386 | 5386 (stealth armor and knife) |

| `SGC_W1_Crate6` | 15810 | 5389 | 5389 (staff weapon and chest armor) |

The server offers 1569 to a Human when 1564 completes (or on load after it) and lights the six crates. Each press completes its objective once, shows its dialog and clears its glow. The sixth completion finishes the mission; the **existing** chains 3041-3044 (`sgc_w1_chains.sql`, `mission_completed 1569`, per archetype) hand out the class kit. This packet adds no item. The dialogs describe what is in each crate; the reward is the player's class kit. Everything is CIMMERIA_RECONSTRUCTION.

The old single crate `SGC_W1_Crate` (spawn 64) and chains 3041-3044 stay untouched.
