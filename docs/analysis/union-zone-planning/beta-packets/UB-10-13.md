# UB-10 to UB-13: Human arc, part 1 (1423 receiver, 381, 473, 478)

> **Type:** How-to (work packets) · **Index:** [beta-work-packets.md](../beta-work-packets.md) · **Wave:** B2 · **Common:** [chain-packet-common.md](chain-packet-common.md)

Read [chain-packet-common.md](chain-packet-common.md) first. It holds the row shapes, the patterns P1-P10, the registration list, the test helpers, the lane commands and the telemetry strings. The chain tables below use this shorthand:

| Shorthand | Rows it stands for |
|---|---|
| `Human` | two condition rows: `archetype gte 1`, `archetype lte 4` |
| `M done` / `M open` / `M active` | `mission_status` target M, `eq` `completed` / `not_active` / `active` |
| `S<id>` | `step_status` with that step id, `eq` `active` |
| `O<id> done` / `O<id> open` | `objective_status` with that objective id, `eq` / `neq` `completed` |
| `login` | trigger `player_loaded`, key `'Beta_Site_Evo_1'` |
| `done:M` | trigger `mission_completed`, key `'M'` |
| `tap:<tag>` | trigger `interact_tag`, key = the tag |
| `pick:<d>` | trigger `dialog_choice`, key = dialog id `d` |
| `zone:<name>` | trigger `enter_region`, key `'Beta_Site_Evo_1.<name>'` |
| `bind dsm/T` | `add_dialog_set` target dsm, `{"slot": T, "mission_id": M}` |
| `unbind dsm/T` | `remove_dialog_set` target dsm, `{"slot": T}` |
| `show d` | `display_dialog` target d |
| `next M S` | `advance_step` target M, key S |

Conditions and actions keep the order the table gives them (`sort_order` 0, 1, 2...). `once` is false unless the table says `once`. Templates: Carter 2300, Felger 2301 (UB-02a).

**Gates on every packet here:** HELD-B12 (`en=false` steps) must be answered `works` or `works with caveat` by UB-00a. HELD-B1 (the order 381, then 473, then 478) uses the UB-00a verdict. If UB-00a changed a row, the orchestrator has already copied the change into this file.
