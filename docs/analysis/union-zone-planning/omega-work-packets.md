## Child packet contract and stop

UO-00 turns each family into bounded children with exact existing file names, IDs, actor tags, positions, source build, tests, revert proof, telemetry events and lane commands. `db/resources/Content/Seed/` currently has no Omega-specific content-chain file; its creation/name is a packet decision, not an existing implementation. Shared mission/dialog/world seed files have one owner at a time across campaigns. Every content packet uses [TESTING.md](../../../TESTING.md), worktree seed reload and the build lane; client UAT needs explicit owner lab approval. A newly authored scene carries `CIMMERIA_AUTHORING` provenance, while the reused Omega map remains an existing asset.

**Stop** if 18→80 travel is not proved, if a faction receives another faction's `The SGU` mission, if private Asgard actors leak into the public hub, or if Beta cannot consume the outbound state. Omega-only UAT does not complete the three-race route.
