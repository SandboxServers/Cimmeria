## Why

The client names an Omega banker and an Omega registrar (F14, RESTORED_SOURCE): `DN_npc_OmegaSite_Banker` ("Storage Officer", moniker 29462) and `DN_npc_reg_OmegaSite_TeamCommandRegistrar` ("Organization Registrar", moniker 29068). The debug hub already uses both monikers, on templates 370 (banker), 330 (Team registrar) and 331 (Command registrar).

The server reads a registrar's type from its single interaction set: 7447 is Team and 7448 is Command. A template carrying both sets has no type. So the one client moniker needs two NPCs. This packet places a personal banker and both registrars in the world-18 hub, as clones of the debug-hub rows (D-UO14, CIMMERIA_RECONSTRUCTION). No new code; the existing banker and registrar arms answer the click.
