## Why

Six W8 packets each seed vendor templates, lists and spawns, and each needs the same three guards: the template carries one vendor bit and the right list, the list obeys the price rule (D-UO29), and the spawns stand clear of every other NPC. Written once here, the six packets each add a short test file that calls these helpers with their own ids, and no two packets write the same assertion twice.

## Contract excerpt (what the W8 packets call)

All items are `pub(super)` at the top level of `crates/cell-catalog/src/cell/spawner/tests/live_db_union_omega_vendor_common.rs` (no inner `mod`). Callers import them with `use super::super::live_db_union_omega_vendor_common::*;` from inside their own `mod live_db`.

```rust
pub(super) const OMEGA_WORLD: &str = "Omega_Site";
/// The shared sell, repair and recharge list of every vendor.
pub(super) const SELL_LIST: i32 = 2;
/// The three designs list 2 buys back; never stocked (D-UO29).
pub(super) const ARBITRAGE_DESIGNS: [i32; 3] = [21, 55, 3437];
/// Heavy weapons (UO-06 Q4): stocked only at tier 2 or higher.
pub(super) const HEAVY_WEAPONS: [i32; 6] = [4990, 6491, 6480, 5094, 6617, 4565];
/// `items.flags` bit CAN_BE_SOLD.
pub(super) const CAN_BE_SOLD: i32 = 1024;
pub(super) const HOSTILE_FACTION: i32 = 10;
/// Tier-1 consumable prices: Slappack 25, Antidote 50, Mark III Stimpack 100.
pub(super) const CONSUMABLE_T1: [i32; 3] = [25, 50, 100];

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(super) enum Price { Weapon, Armor, Crafting, Consumable }

/// One `item_list_items` row joined to its `items` design.
#[derive(Debug)]
pub(super) struct ListRow {
    pub item_id: i32,
    pub design_id: i32,
    pub quantity: i32,
    pub naquadah: i32,
    pub name: Option<String>,   // None when the design is not a real item
    pub tier: Option<i32>,
    pub tech_comp: Option<i32>,
    pub flags: Option<i32>,
}

/// D-UO29. `None` means "one of CONSUMABLE_T1" (a tier-1 consumable).
pub(super) fn expected_price(kind: Price, tier: i32, tc: i32) -> Option<i32>;
pub(super) async fn load_list(pool: &PgPool, list: i32) -> Vec<ListRow>;
pub(super) fn assert_list(list: i32, rows: &[ListRow], kind: Price, tier: Option<i32>);
pub(super) async fn assert_vendor_template(pool: &PgPool, template: i32, bit: i64, name_id: i32, list: i32);
/// `(spawn, template, tag)` per row.
pub(super) async fn assert_spawns(pool: &PgPool, spawns: &[(i32, i32, &str)]);
```

`expected_price`: `Weapon` → `Some(200 * tc)`; `Armor` → `Some(100 * tc)`; `Crafting` → `Some(25 * tc)`; `Consumable` → `None` when `tier == 1`, else `Some(25 * tc)`.

## Steps

1. **Header and imports.** A `//!` block: UO-25, D-UO29 (price rule), D-UO35 (one bit), and "callers: UO-11, UO-12, UO-27..UO-30, UO-39, UO-40". Then `#![allow(dead_code)]` with a comment: the W8 modules use these; a helper unused today must not fail clippy. Imports: `sqlx::{PgPool, Row}`, `crate::cell::spawner::*`, `crate::test_support::require_db_or_skip`.
2. **`load_list`.** One query, ordered by `li.item_id`:

   ```sql
   SELECT li.item_id, li.design_id, li.quantity, li.naquadah, i.name, i.tier, i.tech_comp, i.flags
     FROM resources.item_list_items li
     LEFT JOIN resources.items i ON i.item_id = li.design_id
    WHERE li.item_list_id = $1
    ORDER BY li.item_id
   ```

   Check the column types in `db/resources/Items/Tables/` before decoding (cast in SQL with `::int` if a column is `bigint` or `smallint`).
3. **`assert_list`.** Assert, each with a message naming `list` and the row's `item_id`:
   - 1 to 20 rows;
   - `item_id` in `638000 + (list − 63800) × 50 ..= 638000 + (list − 63800) × 50 + 19` (D-UO27);
   - the design is a real item (`name.is_some()`), not in `ARBITRAGE_DESIGNS`, has `flags & CAN_BE_SOLD != 0`, and appears once in the list;
   - `quantity == 1`;
   - when `tier` is `Some(t)`: the item's tier is `t`;
   - a design in `HEAVY_WEAPONS` only in a list whose `tier` is `Some(t)` with `t >= 2`;
   - the price: `expected_price(kind, item tier, tc)`; `Some(p)` must equal `naquadah`, `None` must be one of `CONSUMABLE_T1`.
4. **`assert_vendor_template`.** Query `SELECT t.class, t.faction, t.interaction_type::bigint, t.buy_item_list, t.sell_item_list, t.repair_item_list, t.recharge_item_list, t.trainer_ability_list_id, t.name_id, t.static_interaction_sets = '{}' AS no_static, t.interaction_set_id IS NULL AS no_set, x.text FROM resources.entity_templates t LEFT JOIN resources.texts x ON x.moniker_id = t.name_id WHERE t.template_id = $1` (copy the join from `live_db_union_omega_services.rs`). Assert: `class == "mob"`; faction is `Some` and not `HOSTILE_FACTION`; `interaction_type == bit` exactly; buy list `Some(list)`; sell, repair and recharge `Some(SELL_LIST)`; trainer list `None`; `name_id == Some(name_id)`; the text is non-empty; `no_static` and `no_set`.
5. **`assert_spawns`.** Copy `omega_services_stand_once_in_the_hub` in `live_db_union_omega_services.rs` (lines 211-268): `load_spawns_from_db` and `load_respawners`. Per tuple: exactly one record with that `spawn_id`, its template and tag match, `world_name == OMEGA_WORLD`, stationary, `respawn_secs == None`, `aggression_override == None`; at least 2.5 units (x/z) from every other `Omega_Site` record; at least 3.0 units from **every** respawner in world 18 (read the respawner record's world field from `crate::cell::spawner`; today 180, later also 181).
6. **Tests in this file**, inside `mod tests { use super::*; ... }`:

   | Test | Type | Asserts |
