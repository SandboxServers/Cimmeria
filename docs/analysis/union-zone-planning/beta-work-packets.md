UB-00 must compare raw objective text, client map actors and any direct world binding and record locality per step. Neither label is enough on its own to place a task or grant.

## Child packet contract and stop

UB-00 converts each family to bounded work packets with exact file ownership, source step/objective/task IDs, actor tags, coordinates with placement confidence, chain/mission ID claims, test module and revert proof, telemetry events and lane commands. One worker owns a shared seed file at a time. Tests follow [TESTING.md](../../../TESTING.md), seed reload uses each worker's database, and compiling cargo uses the build lane. Runtime packets update content docs; client UAT requires explicit owner approval before a lab lease. New side quests wait for the stock mission-catalog client proof and are labelled `CIMMERIA_AUTHORING`.

**Stop** if a `03_All_Beta_Missions` locality label is used as the sole world proof, if 1500/1423/481 grants cross races, if the Mimir teleporter or gate cannot complete a round trip, if a physical Council objective is silently credited, or if later E2 content leaks into first-visit E1 state.
