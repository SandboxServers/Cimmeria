## Dispatch gate and DK inheritance

Start the independent Union Dakara continuation after the first four-zone continuations and FZ-99 finish. Human implementation enters first from SGC mission 1570; plan the Free Jaffa level-1 start in the same campaign, but implement it after the Human inbound path works. Before creating a packet branch, compare the current DK ledger, merged commits, client UAT, board and worktrees. The existing [DK work packets](../dakara-e1-rebuild/work-packets.md) own world-61/62 mission children and their reserved chain range. A UD packet **adopts, finishes or tests** that work; it does not create a duplicate chain or reassign an active DK worker's files. If DK already completed a row, mark the UD row `Integrated` or `UATPending` from evidence and dispatch only the missing boundary.

The [Free Jaffa prologue v2](../sgw-handoff-pack-v1.2/pack/references/world_content/SGW_Free_Jaffa_Full_Starter_Prologue_to_Omega_v2.md), [Dakara starter master](../sgw-handoff-pack-v1.2/pack/references/world_content/SGW_Dakara_Free_Jaffa_Starter_Dev_Master_v1.md), [Human prologue v2](../sgw-handoff-pack-v1.2/pack/references/world_content/SGW_SGU_Human_Full_Starter_Prologue_to_Omega_v2.md) and the DK [audit](../dakara-e1-rebuild/audit.md) are the source set. World **61** is `Dakara_E1`, world **62** the Story Room; gate **25** is Dakara E1. Later Dakara worlds 24/63/64/65 have different map problems and are excluded.

## File and test contract for children

The [DK packet file table](../dakara-e1-rebuild/work-packets.md) is the starting allowlist: `db/resources/Content/Seed/dakara_e1_arrival_chains.sql`, `dakara_e1_betrayal_chains.sql` and `dakara_e1_climax_chains.sql` are **planned DK files**, not present implementations in this checkout. DK also reserves Dakara entity/spawn/point-set files. A UD child must name the exact presently existing file, one owning worker, exact chain IDs from the current allocation, test module under `crates/cell-content/src/cell/content/chain_replay_tests/`, live-DB join test, telemetry events, revert proof and lane commands. New authored IDs are separately claimed against the client catalog and all active branches. Use the [Union contract](execution-contract.md) for review, seed reload and client UAT; client lease always needs owner approval.

**Stop the Dakara campaign** if 1570 can be completed by a Jaffa without a truthful start variant, if the 1651 SGC loop drops mission or generator state, if one player's betrayal phase changes the other player's shared cast, or if 1654 departs without an SGC receiving state. Label source text, reconstructed combat/placement and new Jaffa bridge separately.
