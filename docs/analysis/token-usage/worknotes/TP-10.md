## Done

- `tools/token-profile/pr_stats/`, a package like `ingest/` and `report/` (run as `python tools/token-profile/pr_stats ...`):
  - `block.py` builds the comment: database fields from `pr_records()`, the stamp (profiler commit of the last ingest, newest Claude Code version among the PR's requests, price table), the gh fields, then the TP-01b scrubber over the block and its gate over the rendered body. `parse(body)` reads a block back, for TP-11.
  - `github.py` wraps `gh`: PR view, workflow runs by branch, timeline cross-references, and the comment upsert (find by marker at the start of the body, edit the oldest in place, leave an identical one alone, never create a second).
  - `backfill.py`: the database's merged PRs since `--since`, a rate limiter that only spends a slot on PRs that call gh, and a per-mode state file so a stopped run resumes.
  - `cli.py`: exit codes 0 printed/created/updated/unchanged, 2 error, 3 gate refused, 4 no data.
- The block keeps the plan's keys in the plan's order. One field added: `quality.ci_rounds` (head commits that ran CI), so the table can say "1 failed of 3".
- Fixed in the report layer: an in-process teammate with no custom agent type has its teammate name in `agents.agent_type` (42 rows in the 2026-10-03 database, such as `tp01a` and `pr653-angle-a`), and both `pr_records()` and the report's `wreq` view showed it. They now show `teammate` (`report.db.agent_type_sql`). The README's rule says teammate names never reach a report, and these would have gone into public comments.
- 26 tests in `pr_stats/test_pr_stats.py` with a fake `gh`: block schema and key order, round trip, database fields equal `pr_records()`, quality rules, idempotency (second post edits or leaves alone, never creates; duplicates left alone), hostile fixture values and a hostile gh title, gate refusal posts nothing and names only the detector, deny words, no-data PR makes no gh call, rate limiter spacing, backfill resume and the error stop. Checked that the idempotency tests fail with `upsert` always creating, and the teammate test fails with the old `COALESCE`.
