## User-level levers (not changed; for the coordinator to take to the user)

Measured from this session's transcript and the files on disk:

1. **Project MCP servers: about 3.5k-4k tokens of deferred tool names, plus about 0.5k of server instructions.** `.claude/settings.local.json` lists all five `.mcp.json` servers in `enabledMcpjsonServers`, so every session carries 359 tool names: Ghidra 224 (7.3k characters of names), x64dbg 47, cimmeria-lab 38, SigNoz 38, lab-server 12. Recommendation: drop `ghidra`, `x64dbg`, `cimmeria-lab` and `lab-server` from `enabledMcpjsonServers` and turn them on with `/mcp` in the RE and lab sessions that need them; keep `signoz` on only if most sessions do telemetry work. Estimated saving: about 3k tokens per session (Ghidra alone about 2.2k).
2. **claude.ai connectors: about 1k tokens.** Gmail, Google Calendar and Google Drive (only their auth tools load) and Claude Docs (8 tools plus a long server-instructions block, about 0.6k tokens). None of them is used in this repo. Recommendation: turn them off for Claude Code in the claude.ai connector settings, or disable them per project with `/mcp`.
3. **Personal `MEMORY.md` index: 19,656 characters, about 4.9k tokens.** It has a duplicate line (`feedback_telemetry_first_class.md` twice) and about 20 lines for campaigns marked COMPLETE or MERGED (pets, organizations, crafting, bank/vault, social, ammo, NPC AI, ability trees, Castle, Harset, historical CellBlocks, invisible guard, colo fix pass, and others). Recommendation: delete the duplicate and move finished-campaign lines into one "archived campaigns" memory file with a single index line. Estimated saving: about 2.5k-3k tokens.
4. **Skills: smaller than the ledger estimated.** The 3D, React Flow, Tailwind, Vite and similar entries aren't user-level skills: they're the repo's own `.claude/commands/*.md` (14 files, tracked in git) with no `description` frontmatter, so each loads only as a one-line title, about 200 tokens in all. The synced claude.ai skills (`docs`, `docx`, `pptx`, `xlsx`, `pdf`, `google-workspace`, `morning`, `import-memory`, `skill-creator`) carry about 6k characters of descriptions, about 1.5k tokens. Recommendation: disable the synced document skills for Claude Code if the user never makes Office files from it (about 1.5k); removing the 13 non-RE repo commands would save only about 0.2k, so it isn't worth a repo change on token grounds.

Together that is about 8k-9k tokens, which would put the first request near 60k.
