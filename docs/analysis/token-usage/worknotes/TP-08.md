## Done

- **Answer-key fix.** The caller counts for `0x00a35210` and `0x00a351d0` in [client-engine-sinks-and-seams.md](../../../reverse-engineering/findings/client-engine-sinks-and-seams.md) and [address-map.md](../../../reverse-engineering/address-map.md) were wrong (30 and 14). The binary has 51 and 41 call sites, in 32 and 36 functions; both docs now say so.
- **Probe README.** It now gives measured run times (7-30 s, not "a minute or two") and warns that a comma inside a token is lost through `analyzeHeadless.bat`.

## How it was measured

- **Headless runs** don't show in `tool_calls.fingerprint`: only 27 of 115 fingerprint as `analyzeHeadless.bat`, and the rest start with `cd` or a quoted path. A throwaway local script scanned the transcripts for Bash or PowerShell calls containing `analyzeHeadless` plus a Probe token, and for later calls naming the redirect file. It joined them to `tool_calls` by `tool_use_id`. Only aggregates were kept.
- **Controlled-run measures** come from each subagent's own transcript, priced with `ingest/prices.py`. The profiler database predates the runs, so re-ingesting will add them.
- **The headless arm used a copy of the Ghidra project** (2.5 GB, in the session scratchpad), because the GUI held the live one. The live project and its lock were never touched.
