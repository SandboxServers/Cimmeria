## Done

- **Syntax verified** against the Claude Code docs (prompt caching, "Choose the TTL yourself"; subagents, "Supported frontmatter fields"): an `experimental:` map with `cacheTtl: 1h` (or `5m`; any other value is ignored), read only from subagent files, Claude Code 2.1.248 or later (installed: 2.1.288). Precedence, first match wins: `FORCE_PROMPT_CACHING_5M`, `CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL`, the `subagentPromptCacheTtl` setting, then the frontmatter. None of the three overrides is set in the project or user settings, so the frontmatter applies. `1h` is ignored while a subscription draws on usage credits.
- **Simulator calibrated on real data, and its cold model fixed** (`tools/token-profile/report/sections/cache_sim.py`):
  - The warm rule holds. A request within its TTL read 100% of `min(P, previous P)` up to a 300 s gap under 5m (67% at 300-320 s, timestamp jitter, then 4-17%), and up to 3,600 s under 1h.
  - The cold rule did not. It read the transcript's *minimum* cold read, so one cold request that found nothing warm (25% of subagent first requests read 0) zeroed the estimate for the whole transcript. Leave-one-out over 840 held-out cold requests, the minimum predicted 0.38 of the real cache read; the mean predicts 0.91. The simulator now uses the mean (`cold_read`), and every row carries `delta_range_usd`, the 1h-minus-5m difference over no cold read, the mean and the largest observed one. The difference is not monotonic in the cold read, so the range includes the point estimate.
  - The aggregate calibration column (replay under the observed TTL / observed cache USD) was 0.97-1.04 per agent type before the fix and is 0.94-1.00 after, because cold requests are under 2% of requests. The fix matters for the counterfactual replay, not for that column.
  - Tests: `test_cold_read_is_the_mean_not_the_minimum` (fails with the old minimum), `test_cold_reads_follow_the_observed_ttl` and `test_delta_range_brackets_the_estimate`; all 108 token-profile tests pass. The Markdown report has a new "1h - 5m range" column.
- **`experimental.cacheTtl: 1h` set on `rust-gameserver-dev` only.** Nothing else in any agent file changed.

Decision rule: 1h only where the point estimate, all three sampled cold-read scenarios (none, the mean, the largest seen) and the whole bootstrap interval favour it. The three scenarios do not bound intermediate cold reads (CodeRabbit on #1130); the decision for `rust-gameserver-dev` also rests on the bootstrap interval, which excludes zero. Only `rust-gameserver-dev` passes, and it is also the only agent with hundreds of 5-60 min gaps (it waits on builds). Its last week alone (176 transcripts since 2026-09-26) gives -$319 on $2,578, -12.4%, so the effect is not left over from older behaviour. Three advisors (npc-ai-spawn, combat-systems, mission-systems) lean 1h at the point estimate, but their intervals cross zero.
