## Do the hook and the reader agree?

Yes, once the fix is in. The checks:

- **Pattern.** It is the same `CAP_RE`, matched on the result text after `lstrip()`, with no `is_error` check.
- **Text.** The hook joins only the `type: "text"` items of a list `content`. `read_dispatch` stores `text_of(content)`, which joins every item that has a string `text`. Tool results only hold `text` and `image` items, and an image item has no `text`, so the two texts are the same. Leave `text_of` unchanged.
- **Scope.** The hook checks every `tool_result` in a `user` record. The reader checks only the results whose `tool_use_id` matches a `tool_use` in the transcript. A real deny always answers a tool use, so the two cannot differ in practice. Accepted.
