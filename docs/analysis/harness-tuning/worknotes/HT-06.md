## What the fix coder changes in `.claude/hooks/report_contract.py`

1. Keep `CAP_MARKER`. Add `CAP_RE = re.compile(r"^(?:PreToolUse:\S+ hook error: )?" + re.escape(CAP_MARKER))`.
2. Add `is_cap_deny(rec)`. It is true when `rec["type"] == "user"`, `message.content` is a list, and a block with `type == "tool_result"` has text that matches `CAP_RE` after `.lstrip()`. The text is the block's `content` when that is a string, or else the `text` of its `type: "text"` items joined with `\n`.
3. In `read_transcript`, delete `if CAP_MARKER in raw: info["cap"] = True`. After the `isinstance(rec, dict)` check, add `if is_cap_deny(rec): info["cap"] = True`.
4. Don't require `is_error`. Missing a real deny would make the hook ask a capped agent for more, which D-HT3 forbids. The anchor alone already excludes the brief and Read or Grep quotes. The file stays at 250 lines or fewer.
