## Ruling: (a) widen P03

P03 now also covers `crates/content-engine/src/loader/action_spawn.rs` and gets one more test in `crates/content-engine/src/loader/tests/action_narrowing.rs`. This adds a file to P03's scope (an exception to R7), and the exception covers only the edit below.

Why:

- #246 item A is "no wrapping `as i32` in the action loader". `action_spawn.rs` was split out of `action.rs`, and `convert_action` delegates to it, so it sits inside the same boundary. A grep of `loader/` (non-test) finds no other `as i32` site, so after this edit the item is closed in full.
- The fix is one line through the existing `opt_i32` helper. A follow-up issue would cost more than the fix and leave #246-A half done.
- The behavior matches every other P03 site: a value out of range drops the action and logs a WARN. A wrapped `aggression` can turn a seeded passive NPC hostile, or the reverse, so dropping it loudly is right. Treating it as `None` (derive from faction) would hide a broken seed row.

No README "Out of scope" entry and no D-09 row (those apply only to ruling b).

## Edit 2: test in `crates/content-engine/src/loader/tests/action_narrowing.rs`

Don't add a `CASES` row. `params_with` builds a params object holding only the key under test, and `spawn_entity` without x/y/z is dropped anyway. The over and under tests would pass for the wrong reason (theatre), and `in_range_i32_param_keeps_the_action` would fail. Append this dedicated test at the end of the file:

```rust
/// `spawn_entity.aggression` lives in `action_spawn.rs`, not `action.rs`,
/// and needs a full spawn descriptor, so it cannot be a `CASES` row.
#[test]
fn spawn_entity_aggression_out_of_range_drops_the_action() {
    let spawn = |aggression: i64| {
        row(
            "spawn_entity",
            Some(207),
            Some("Rinla_Malac"),
            serde_json::json!({ "x": 1.0, "y": 2.0, "z": 3.0, "aggression": aggression }),
        )
    };
    for value in [OVER_I32, UNDER_I32] {
        assert!(
            convert_action(&spawn(value)).is_none(),
            "spawn_entity.aggression={value} wrapped instead of dropping the action"
        );
    }
    match convert_action(&spawn(i32::MAX as i64)) {
        Some(Action::SpawnEntity { aggression, .. }) => {
            assert_eq!(aggression, Some(i32::MAX));
        }
        other => panic!("expected SpawnEntity at i32::MAX, got {other:?}"),
    }
}
```
