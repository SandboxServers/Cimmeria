2026-10-23. One PR, as requested by the owner. Designs: [path display](../design-path-display.md), [startup update](../design-startup-update.md).

## Changes

Existing `displayPath` is now used by Settings, adoption status and backup copy, and Update/Repair/Uninstall confirmations. Canonical native paths remain in preferences/snapshots/identity checks. Startup checks once when safe; the main-page Update and restart action inspects, downloads/verifies when needed, then applies. Both frontend and configured native Play admission block known available/staged updates and failed attempts retaining an offer. Active/reconciliation updates block all builds, including disabled development builds. The native host supplies its compiled configuration; it is never taken from renderer IPC. A failed recheck preserves a known offer. A check failure without a known offer permits Play; failure of the initial inspection holds Play and offers a main-page retry. Nothing is downloaded or applied at startup.
