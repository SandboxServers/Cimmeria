## Step A2: `src/commands/uat/record.rs` (new)

Ports `Get-UatRunVerdict`, `Test-UatBrake`, `Test-UatStopLane` and the record
building of the lane loop. A run's record is a `batch::RunRecord`.

```rust
//! One run's record: the verdict of its rows, the brake, the error text and the
//! UTC stamps. Pure: no daemon, no clock reads of its own (callers pass times).

use std::sync::OnceLock;

use chrono::{DateTime, Utc};
use regex::Regex;
use serde_json::Value;

use crate::batch::{RowResult, RunRecord, Verdict};
use crate::daemon::mcp::{hide_lease_ids, McpError};
use crate::known_issues;

fn eqi(a: &str, b: &str) -> bool {
    a.eq_ignore_ascii_case(b)
}

/// One run's verdict from `lab_uat_run`'s rows (`Get-UatRunVerdict`). `expected`
/// are the planned row ids: a row the run did not report fails it, result
/// `MISSING`, naming every absent row. Otherwise the first row that is neither
/// `PASS` nor `SKIPPED` decides: its row, result, reason (first reason, lease ids
/// hidden) and the known issue `known_issues::tag` finds for it. All rows passing
/// is `ok` with every other field `None`.
pub fn run_verdict(rows: &[RowResult], expected: &[String]) -> Verdict {
    let absent: Vec<&str> = expected
        .iter()
        .map(String::as_str)
        .filter(|id| !id.is_empty() && !rows.iter().any(|r| eqi(&r.row, id)))
        .collect();
    if let Some(first) = absent.first() {
        return Verdict {
            ok: false,
            row: Some((*first).to_string()),
            result: Some("MISSING".to_string()),
            reason: Some(format!(
                "the run reported no result for {}",
                absent.join(", ")
            )),
            issue: None,
        };
    }
    let Some(first) = rows
        .iter()
        .find(|r| !eqi(&r.result, "PASS") && !eqi(&r.result, "SKIPPED"))
    else {
        return Verdict {
            ok: true,
            ..Verdict::default()
        };
    };
    let reason = hide_lease_ids(first.reasons.first().map(String::as_str).unwrap_or(""));
    let issue = known_issues::tag(&first.row, &reason).map(str::to_string);
    Verdict {
        ok: false,
        row: Some(first.row.clone()),
        result: Some(first.result.clone()),
        reason: Some(reason),
        issue,
    }
}

/// `Test-UatBrake`: true when the failed runs at the end of `outcomes` number at
/// least `max_consecutive` (0 never brakes). `outcomes` is `true` for a pass.
pub fn brake(outcomes: &[bool], max_consecutive: u32) -> bool {
    if max_consecutive == 0 {
        return false;
    }
    let streak = outcomes.iter().rev().take_while(|ok| !**ok).count();
    streak >= max_consecutive as usize
}

/// `Test-UatStopLane`: the brake, but never after the lane's last run (a lane
/// that ran every run did not stop early).
pub fn stop_lane(index: u32, total: u32, outcomes: &[bool], max_consecutive: u32) -> bool {
    index < total && brake(outcomes, max_consecutive)
}

/// The text stored for a run whose call failed: the error's first line with lease
/// ids hidden. A tool error reads `lab_uat_run failed: <message>` (as
/// `Invoke-McpTool` threw it); any other error keeps its own text.
pub fn error_text(error: &McpError) -> String {
    let full = match error {
        McpError::Tool(message) => format!("lab_uat_run failed: {message}"),
        other => other.to_string(),
    };
    hide_lease_ids(full.lines().next().unwrap_or(""))
}

/// Whether an error text is a timeout (`Timeout|timed out|canceled`, any case).

        .is_match(error)
}

/// The rows of a `lab_uat_run` reply: its `rows` array, `null` elements and
```

```rust
//! The summary of a batch: totals, per-row and per-lane pass counts, failures
//! grouped by signature. `summary.md` and `batch.json` are written from it.
//! LX-17 adds the `golden`, `chaos_divergence` and `heal` parts.

use std::fs;
use std::io;
use std::path::Path;

use chrono::{DateTime, Local};
use serde::ser::SerializeMap;
use serde::{Serialize, Serializer};

use crate::batch::{PlanLane, RunRecord};

const NL: &str = "\r\n";

fn eqi(a: &str, b: &str) -> bool {
    a.eq_ignore_ascii_case(b)
}

/// Passed and total counts of one row, `pass` first as in the JSON.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize)]
pub struct RowStat {
    pub pass: u32,
    pub total: u32,
}

/// Per-row counts in the order each row was first seen. Serialises as a JSON
/// object in that order (a `serde_json::Map` would sort the keys).
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct RowStats(pub Vec<(String, RowStat)>);

impl RowStats {
    /// The counts of `id` (ignoring case).
    pub fn get(&self, id: &str) -> Option<&RowStat> {
        self.0.iter().find(|(k, _)| eqi(k, id)).map(|(_, v)| v)
    }

    fn entry(&mut self, id: &str) -> &mut RowStat {
        let at = match self.0.iter().position(|(k, _)| eqi(k, id)) {
            Some(i) => i,
            None => {
                self.0.push((id.to_string(), RowStat::default()));
                self.0.len() - 1
            }
        };
        &mut self.0[at].1
    }
}

impl Serialize for RowStats {
    fn serialize<S: Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        let mut map = serializer.serialize_map(Some(self.0.len()))?;
        for (id, stat) in &self.0 {
            map.serialize_entry(id, stat)?;
        }
        map.end()
    }
}

/// One lane of the plan with its totals.
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct LaneStat {
    pub lane: u32,
    pub instance: String,
    pub runs: u32,
    pub passed: u32,
    pub braked: bool,

/// Failed runs with the same signature: `<row> <result>: <reason>` or
/// `error: <error>`. `issue` is the known issue of the first such run, never set
/// for an error. `runs` are `<instance>#<index>` in record order.
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct FailureGroup {
    pub signature: String,
    pub count: u32,
    pub issue: Option<String>,
    pub runs: Vec<String>,
}

/// The batch summary (`Merge-UatResults`). `Default` is for LX-17's tests.
#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize)]
pub struct Summary {
    pub ok: bool,
    pub runs: u32,
    pub passed: u32,
    pub failed: u32,
    pub failed_known: u32,
    pub failed_new: u32,
    pub rows: RowStats,
    pub lanes: Vec<LaneStat>,
    pub failures: Vec<FailureGroup>,
}

/// Aggregates run records into the summary. Lane deaths (`Index` 0) are records
/// like any other here, as in the PowerShell. `braked` are the instances of the
/// records marked `Braked`.
pub fn merge(runs: &[RunRecord], lanes: &[PlanLane], braked: &[String]) -> Summary {
    let mut rows = RowStats::default();
    for run in runs {
        for r in &run.rows {
            let stat = rows.entry(&r.row);
            stat.total += 1;
            if eqi(&r.result, "PASS") {
                stat.pass += 1;
            }
        }
    }
    let mut failures: Vec<FailureGroup> = Vec::new();
    for run in runs.iter().filter(|r| !r.ok) {
        let error = run.error.as_deref().filter(|e| !e.is_empty());
        let verdict = run.verdict.clone().unwrap_or_default();
        let signature = match error {
            Some(e) => format!("error: {e}"),
            None => format!(
                "{} {}: {}",
                verdict.row.as_deref().unwrap_or(""),
                verdict.result.as_deref().unwrap_or(""),
                verdict.reason.as_deref().unwrap_or("")
            ),
        };
        let at = match failures.iter().position(|g| eqi(&g.signature, &signature)) {
            Some(i) => i,
            None => {
                let issue = if error.is_some() {
                    None
                } else {
                    verdict.issue.clone().filter(|i| !i.is_empty())
                };
                failures.push(FailureGroup {
                    signature,
                    count: 0,
                    issue,
                    runs: Vec::new(),
                });
                failures.len() - 1
            }
        };
        failures[at].count += 1;
        failures[at]
            .runs
            .push(format!("{}#{}", run.instance, run.index));
    }
    let lane_stats: Vec<LaneStat> = lanes
        .iter()
        .map(|l| {
            let mine: Vec<&RunRecord> = runs
                .iter()
                .filter(|r| eqi(&r.instance, &l.instance))
                .collect();
            LaneStat {
                lane: l.lane,
                instance: l.instance.clone(),
                runs: mine.len() as u32,
                passed: mine.iter().filter(|r| r.ok).count() as u32,
                braked: braked.iter().any(|b| eqi(b, &l.instance)),
            }
        })
        .collect();
    let total = runs.len() as u32;
    let passed = runs.iter().filter(|r| r.ok).count() as u32;
    let known = runs
        .iter()
        .filter(|r| {
            !r.ok
                && r.error.as_deref().is_none_or(str::is_empty)
                && r.verdict
                    .as_ref()
                    .and_then(|v| v.issue.as_deref())
                    .is_some_and(|i| !i.is_empty())
        })
        .count() as u32;
    Summary {
        ok: total > 0 && passed == total,
        runs: total,
        passed,
        failed: total - passed,
        failed_known: known,
        failed_new: total - passed - known,
        rows,
        lanes: lane_stats,
        failures,
    }
}

/// The exit code of a batch with no golden comparison and no heal: 0 all passed,
/// 4 a lane stopped early, else 1 (`Get-UatExitCode`). LX-17a replaces this
/// whole function (it adds 5 and 8).
pub fn exit_code(summary: &Summary) -> u8 {
    if summary.ok {
        0
    } else if summary.lanes.iter().any(|l| l.braked) {
        4
    } else {
        1
    }
}

/// The summary as Markdown for people (`Format-UatSummary`), `\r\n` line ends,
/// the last line ended too.
pub fn format_markdown(summary: &Summary, title: &str, dir: &str) -> String {
    let mut lines: Vec<String> = Vec::new();
    lines.push(format!(
        "# {title}: {} ({}/{} runs passed)",
        if summary.ok { "PASS" } else { "FAIL" },
        summary.passed,
        summary.runs
    ));
    if summary.failed > 0 {
        lines.push(format!(
            "Failed: {} ({} known issue, {} new)",
            summary.failed, summary.failed_known, summary.failed_new
        ));
    }
    lines.push(String::new());
    lines.push("| Lane | Instance | Passed | Stopped early |".to_string());
    lines.push("|---|---|---|---|".to_string());
    for l in &summary.lanes {
        lines.push(format!(
            "| {} | {} | {}/{} | {} |",
            l.lane,
            l.instance,
            l.passed,
            l.runs,
            if l.braked { "yes" } else { "" }
        ));
    }
    lines.push(String::new());
    lines.push("| Row | Passed |".to_string());
    lines.push("|---|---|".to_string());
    for (id, stat) in &summary.rows.0 {
        lines.push(format!("| {id} | {}/{} |", stat.pass, stat.total));
    }
    if !summary.failures.is_empty() {
        lines.push(String::new());
        lines.push("Failures, grouped by the first failing row:".to_string());
        let mut sorted: Vec<&FailureGroup> = summary.failures.iter().collect();
        sorted.sort_by(|a, b| b.count.cmp(&a.count)); // stable: ties keep first-seen order
        for f in sorted {
            let tag = f
                .issue
                .as_deref()
                .filter(|i| !i.is_empty())
                .map(|i| format!(" (known: {i})"))
                .unwrap_or_default();
            lines.push(format!(
                "- {}x {}{}; runs: {}",
                f.count,
                f.signature,
                tag,
                f.runs.join(", ")
            ));
        }
    }
    lines.push(String::new());
    lines.push(format!("Batch: {dir}"));
    lines.iter().map(|l| format!("{l}{NL}")).collect()
}

        at.format("%Y-%m-%dT%H:%M:%S"),
        at.timestamp_subsec_nanos() / 100,
        at.format("%:z")
    )

/// What `batch.json` and `summary.md` need besides the summary.
pub struct BatchMeta<'a> {
    pub dir: &'a Path,
    pub title: &'a str,
    pub section: &'a str,
    pub row_ids: &'a [String],
    pub lane_count: u32,
    pub runs_per_lease: u32,
    pub started: DateTime<Local>,

/// A number that prints as an integer when it is whole (`3`, not `3.0`).
struct Minutes(f64);

impl Serialize for Minutes {
    fn serialize<S: Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        if self.0.fract() == 0.0 {
            serializer.serialize_i64(self.0 as i64)
        } else {
            serializer.serialize_f64(self.0)
        }
    }
}

/// `batch.json`: keys in the PowerShell's order.
#[derive(Serialize)]
struct BatchFile<'a> {
    section: &'a str,
    rows: &'a [String],
    leases: u32,
    runs_per_lease: u32,
    started: String,
    minutes: Minutes,
    summary: &'a Summary,
}

/// Writes `summary.md` then `batch.json` into `meta.dir` and returns the
/// Markdown (`Write-UatBatchSummary`). `summary.md` is the Markdown plus one more
/// `\r\n`; `batch.json` is indented JSON plus `\r\n`. `minutes` is the time from
/// `meta.started` to `now`, rounded to one decimal (halves to even).
pub fn write_batch_summary(
    summary: &Summary,
    meta: &BatchMeta,
    now: DateTime<Local>,
) -> io::Result<String> {
    let md = format_markdown(summary, meta.title, &meta.dir.display().to_string());
    fs::write(meta.dir.join("summary.md"), format!("{md}{NL}"))?;
    let elapsed = (now - meta.started).num_milliseconds() as f64 / 60_000.0;
    let file = BatchFile {
        section: meta.section,
        rows: meta.row_ids,
        leases: meta.lane_count,
        runs_per_lease: meta.runs_per_lease,
        started: local_stamp(meta.started),
        minutes: Minutes((elapsed * 10.0).round_ties_even() / 10.0),
        summary,
    };
    let mut json = serde_json::to_string_pretty(&file).map_err(io::Error::other)?;
    json.push_str(NL);
    fs::write(meta.dir.join("batch.json"), json)?;
    Ok(md)
}
```

```rust
/// The width the fail text is cut to (the mock-up's `FS-02: Login_PasswordEdit
/// holds 0 ch…` is 37).
const FAIL_TEXT_WIDTH: usize = 37;

/// The fancy line of one finished run:
/// `  <label>  ✓ pass  <p>/<n> rows  <time>` or
/// `  <label>  ✗ fail  <row>: <reason…>  [#issue]  <time>` or
/// `  <label>  ✗ error  <error…>  <time>`. The label is padded to `label_width`.
pub fn fancy_run_line(ui: &Ui, rec: &RunRecord, total: u32, label_width: usize) -> String {
    let label = format!("{} {}/{}", rec.instance, rec.index, total);
    let pad = " ".repeat(label_width.saturating_sub(label.chars().count()));
    let time = fmt_duration(rec.seconds);
    let body = if rec.ok {
        let passed = rec
            .rows
            .iter()
            .filter(|r| r.result.eq_ignore_ascii_case("PASS"))
            .count();
        format!(
            "{}  {}/{} rows  {time}",
            ui.paint(Tone::Ok, &format!("{} pass", ui.mark(Mark::Pass))),
            passed,
            rec.rows.len()
        )
    } else if let Some(error) = rec.error.as_deref().filter(|e| !e.is_empty()) {
        format!(
            "{}  {}  {time}",
            ui.paint(Tone::Fail, &format!("{} error", ui.mark(Mark::Fail))),
            cut(error, FAIL_TEXT_WIDTH)
        )
    } else {
        let verdict = rec.verdict.as_ref();
        let row = verdict.and_then(|v| v.row.as_deref()).unwrap_or("");
        let reason = verdict.and_then(|v| v.reason.as_deref()).unwrap_or("");
        let tag = verdict
            .and_then(|v| v.issue.as_deref())
            .filter(|i| !i.is_empty())
            .map(|i| format!("  {}", ui.paint(Tone::Warn, &format!("[{i}]"))))
            .unwrap_or_default();
        format!(
            "{}  {}{tag}  {time}",
            ui.paint(Tone::Fail, &format!("{} fail", ui.mark(Mark::Fail))),
            cut(&format!("{row}: {reason}"), FAIL_TEXT_WIDTH)
        )
    };
    format!("  {label}{pad}  {body}")
}

/// `3/4  75%`, coloured: 100 % green, 0 % red, else yellow (no runs: dim). The
/// percentage is rounded down.
pub fn rate_cell(ui: &Ui, pass: u32, total: u32) -> String {
    let pct = if total == 0 { 0 } else { pass * 100 / total };
    let tone = if total == 0 {
        Tone::Dim
    } else if pass == total {
        Tone::Ok
    } else if pass == 0 {
        Tone::Fail
    } else {
        Tone::Warn
    };
    ui.paint(tone, &format!("{pass}/{total}  {pct}%"))
}

    for l in &summary.lanes {
        lanes.row(vec![
            l.lane.to_string(),
            l.instance.clone(),

            } else {

    if !summary.failures.is_empty() {
        out.push('\n');
        out.push_str(&ui.paint(Tone::Heading, "Failures, grouped by the first failing row:"));
        out.push('\n');
        let mut sorted: Vec<&FailureGroup> = summary.failures.iter().collect();
        sorted.sort_by(|a, b| b.count.cmp(&a.count));
        for f in sorted {
            let tag = f
                .issue
                .as_deref()
                .filter(|i| !i.is_empty())
                .map(|i| format!("  {}", ui.paint(Tone::Warn, &format!("[{i}]"))))
                .unwrap_or_default();
            out.push_str(&format!(
                "  {}x {}{tag}  runs: {}\n",
                f.count,
                f.signature,
                f.runs.join(", ")
            ));
        }
    }
    out.push('\n');
    out.push_str(&format!("Batch: {}\n", ui.paint(Tone::Cmd, dir)));
    out
}

/// The one line `--quiet` prints at the end.
pub fn quiet_line(title: &str, summary: &Summary, dir: &str) -> String {
    format!(
        "{title}: {}/{} passed; {dir}",
        summary.passed, summary.runs
    )
}

/// Prints batch progress through an emitter, in the mode's style. Whole lines
/// only, so lanes never interleave inside a line.
pub struct Progress<'a> {
    ui: Ui,
    mode: ProgressMode,
    fancy: bool,
    lane_count: usize,
    per_lane: u32,
    width: usize,
    emit: &'a (dyn Fn(&str) + Sync),
}

impl<'a> Progress<'a> {
    /// `ui.fancy` makes the lines fancy only when they go to the console.
    pub fn new(
        ui: Ui,
        mode: ProgressMode,
        lanes: &[PlanLane],
        per_lane: u32,
        emit: &'a (dyn Fn(&str) + Sync),
    ) -> Self {
        Self {
            ui,
            mode,
            fancy: ui.fancy && mode == ProgressMode::Host,
            lane_count: lanes.len(),
            per_lane,
            width: label_width(lanes, per_lane),
            emit,
        }
    }

    /// Whether the fancy style is on.
    pub fn is_fancy(&self) -> bool {
        self.fancy
    }

    /// Sends one line, unless the mode is `None`.
    pub fn say(&self, line: &str) {
        if self.mode != ProgressMode::None {
            (self.emit)(line);
        }
    }

    /// The batch's header line.
    pub fn header(
        &self,
        section: &str,
        lanes: &[PlanLane],
        row_ids: &[String],
        batch_name: &str,
    ) -> String {
        if self.fancy {
            fancy_header(
                &self.ui,
                section,
                row_ids.len(),
                self.lane_count,
                self.per_lane,
                batch_name,
            )
        } else {
            plain_header(section, lanes, self.per_lane, row_ids)
        }
    }

    /// The line of one finished run.
    pub fn run_line(&self, rec: &RunRecord) -> String {
        if self.fancy {
            fancy_run_line(&self.ui, rec, self.per_lane, self.width)
        } else {
            format_progress_line(rec, self.per_lane)
        }
    }

    /// The line that says a lane stopped.
    pub fn notice(&self, instance: &str, rest: &str) -> String {
        lane_notice(&self.ui, self.fancy, instance, rest)
    }
}
```

## Step B2: `src/commands/uat/lanes.rs` (new)

The lane loop of `Invoke-LabUat`. It knows nothing of the daemon, paths or
printing: the MCP call, the lease wait, the sleep, the progress callbacks and the
stop flag are passed in (the PowerShell's scriptblocks).

```rust
//! The lanes of a batch: one thread per lane, each running the rows
//! `runs_per_lease` times, one after another.
//!
//! A lane starts `(lane - 1) * stagger` seconds after the batch. Each run is one
//! `call` (the caller makes the `lab_uat_run` call, with its own MCP session), its
//! record is appended to `batch.jsonl` as soon as it ends, then the brake and the
//! timeout wait decide whether the lane goes on. A lane that dies outside a run
//! (a panic, an append that fails) leaves an `Index` 0 record.

use std::any::Any;
use std::io;
use std::panic::{catch_unwind, AssertUnwindSafe};
use std::path::Path;
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::{Duration, Instant};

use chrono::Utc;
use serde_json::Value;

use crate::batch::{append_record, PlanLane, RunRecord};
use crate::daemon::mcp::McpError;

use super::record::{apply_error, apply_reply, lane_death, new_record, stop_lane, utc_stamp};

/// How long a lane waits for its instance's lease to clear after a timed-out run.
pub const LEASE_CLEAR_WAIT: Duration = Duration::from_secs(600);

/// One run: `(instance, timeout) -> the lab_uat_run reply`.
pub type CallFn<'a> = dyn Fn(&str, Duration) -> Result<Value, McpError> + Sync + 'a;
/// `(instance, max) -> whether the instance's lease cleared within max`.
pub type WaitFn<'a> = dyn Fn(&str, Duration) -> bool + Sync + 'a;
/// Sleeps for the stagger; a real one wakes early when the stop flag is set.
pub type SleepFn<'a> = dyn Fn(Duration) + Sync + 'a;
/// Called with each record after it is appended.
pub type RecordFn<'a> = dyn Fn(&RunRecord) + Sync + 'a;
/// Called with `(instance, text)` when a lane stops (the text follows the
/// instance in `[<instance>] <text>`).
pub type NoticeFn<'a> = dyn Fn(&str, &str) + Sync + 'a;

/// Called with each run's record (after its reply or error is applied, before
/// the brake and the append) and the reply when the call returned one. LX-17b
/// uses it for the run's chaos header and the golden diff.
pub type FinishFn<'a> = dyn Fn(&mut RunRecord, Option<&Value>) + Sync + 'a;

/// The `FinishFn` of a batch with nothing to add (LX-16b passes it).
pub fn no_finish(_rec: &mut RunRecord, _reply: Option<&Value>) {}

/// What a lane does, as numbers and names.
pub struct LaneConfig<'a> {
    /// The planned row ids the verdict checks the reply against.
    pub row_ids: &'a [String],
    pub runs_per_lease: u32,
    pub stagger_seconds: u32,
    pub run_timeout: Duration,
    /// Failed runs in a row that stop a lane (0 never).
    pub max_consecutive_failures: u32,
    /// `batch.jsonl`.
    pub jsonl: &'a Path,
}

/// What a lane needs from outside.
pub struct LaneEnv<'a> {
    pub call: &'a CallFn<'a>,
    pub wait_lease_free: &'a WaitFn<'a>,
    pub sleep: &'a SleepFn<'a>,
    pub on_record: &'a RecordFn<'a>,
    pub on_notice: &'a NoticeFn<'a>,
    /// The per-run seam LX-17b fills ([`no_finish`] until then).
    pub finish: &'a FinishFn<'a>,
    /// Set by Ctrl+C: no new run starts once it is set.
    pub stop: &'a AtomicBool,
}

/// Sleeps `total`, in short steps, returning at once when `stop` is set.
pub fn sleep_unless_stopped(total: Duration, stop: &AtomicBool) {
    let deadline = Instant::now() + total;
    while !stop.load(Ordering::SeqCst) {
        let left = deadline.saturating_duration_since(Instant::now());
        if left.is_zero() {
            break;
        }
        std::thread::sleep(left.min(Duration::from_millis(200)));
    }
}

fn panic_text(payload: &(dyn Any + Send)) -> String {
    if let Some(text) = payload.downcast_ref::<&str>() {
        (*text).to_string()
    } else if let Some(text) = payload.downcast_ref::<String>() {
        text.clone()
    } else {
        "the lane panicked".to_string()
    }
}

fn lane_body(lane: &PlanLane, cfg: &LaneConfig, env: &LaneEnv) -> io::Result<()> {
    if lane.lane > 1 {
        (env.sleep)(Duration::from_secs(
            u64::from(lane.lane - 1) * u64::from(cfg.stagger_seconds),
        ));
    }
    let total = cfg.runs_per_lease;
    let mut outcomes: Vec<bool> = Vec::new();
    for index in 1..=total {
        if env.stop.load(Ordering::SeqCst) {
            break;
        }
        let started = Instant::now();
        let mut rec = new_record(lane.lane, &lane.instance, index, Utc::now());
        let mut timed_out = false;
        let mut reply: Option<Value> = None;
        match (env.call)(&lane.instance, cfg.run_timeout) {
            Ok(r) => {
                apply_reply(&mut rec, &r, cfg.row_ids);
                reply = Some(r);
            }
            Err(error) => timed_out = apply_error(&mut rec, &error),
        }
        rec.seconds = started.elapsed().as_secs();
        // LX-17 hook: per-run finish (chaos header, golden diff); a no-op until LX-17b.
        (env.finish)(&mut rec, reply.as_ref());
        outcomes.push(rec.ok);
        // A run cut short may still hold its lease on the daemon: wait for it,
        // or the next run collides with it.
        let stuck = timed_out && !(env.wait_lease_free)(&lane.instance, LEASE_CLEAR_WAIT);
        let brake = stop_lane(index, total, &outcomes, cfg.max_consecutive_failures);
        rec.braked = brake || stuck;
        rec.ended = Some(utc_stamp(Utc::now()));
        append_record(cfg.jsonl, &rec)?;
        (env.on_record)(&rec);
        if stuck {
            (env.on_notice)(
                &lane.instance,
                "its lease did not clear after the timeout; lane stopped",
            );
        } else if brake {
            (env.on_notice)(
                &lane.instance,
                &format!(
                    "stopped after {} failed runs in a row",
                    cfg.max_consecutive_failures
                ),
            );
        }
        if rec.braked {
            break;
        }
    }
    Ok(())
}

/// Runs one lane. Never panics and never returns an error: a failure outside a
/// run becomes an `Index` 0 record (best effort).
pub fn run_lane(lane: &PlanLane, cfg: &LaneConfig, env: &LaneEnv) {
    let message = match catch_unwind(AssertUnwindSafe(|| lane_body(lane, cfg, env))) {
        Ok(Ok(())) => return,
        Ok(Err(error)) => error.to_string(),
        Err(payload) => panic_text(payload.as_ref()),
    };
    let death = lane_death(lane.lane, &lane.instance, &message, Utc::now());
    let _ = append_record(cfg.jsonl, &death);
}

/// Runs every lane at once, one thread each, and returns when all are done.
pub fn run_lanes(lanes: &[PlanLane], cfg: &LaneConfig, env: &LaneEnv) {
    std::thread::scope(|scope| {
        for lane in lanes {
            scope.spawn(move || run_lane(lane, cfg, env));
        }
    });
}
```

```rust
//! Ctrl+C during a batch. The first press sets [`STOP`] (no new run starts) and is
//! handled; the second press is left to the system's default, which ends the
//! process. On other systems than Windows nothing is installed: the default
//! Ctrl+C ends the process.

use std::sync::atomic::{AtomicBool, AtomicU32, Ordering};

/// Set by the first Ctrl+C press.
pub static STOP: AtomicBool = AtomicBool::new(false);
static PRESSES: AtomicU32 = AtomicU32::new(0);

/// Whether Ctrl+C was pressed.
pub fn stop_requested() -> bool {
    STOP.load(Ordering::SeqCst)
}

/// What one press does: the first sets [`STOP`] and returns `true` (handled);
/// every later one returns `false` (let the default handler end the process).
pub fn press() -> bool {
    if PRESSES.fetch_add(1, Ordering::SeqCst) == 0 {
        STOP.store(true, Ordering::SeqCst);
        true
    } else {
        false
    }
}

#[cfg(windows)]
mod win {
    use super::press;

    type HandlerRoutine = unsafe extern "system" fn(u32) -> i32;

    #[link(name = "kernel32")]
    unsafe extern "system" {
        fn SetConsoleCtrlHandler(handler: Option<HandlerRoutine>, add: i32) -> i32;
    }

    const CTRL_C_EVENT: u32 = 0;
    const CTRL_BREAK_EVENT: u32 = 1;

    unsafe extern "system" fn on_event(kind: u32) -> i32 {
        if (kind == CTRL_C_EVENT || kind == CTRL_BREAK_EVENT) && press() {
            eprintln!(
                "Ctrl+C: no new run will start; the runs under way finish first (Ctrl+C again stops now)"
            );
            1
        } else {
            0
        }
    }

    pub fn install() {
        // SAFETY: `on_event` has the `PHANDLER_ROUTINE` signature and lives for
        // the whole process; the call only registers it.
        unsafe {
            SetConsoleCtrlHandler(Some(on_event), 1);
        }
    }
}

/// Installs the handler (Windows); nothing elsewhere.
pub fn install() {
    #[cfg(windows)]
    win::install();
}
```

```rust
pub struct BatchOutcome {

/// The parts of a [`LaneEnv`] the caller supplies.
pub struct Hooks<'a> {
    pub call: &'a CallFn<'a>,
    pub wait_lease_free: &'a WaitFn<'a>,
    pub sleep: &'a SleepFn<'a>,
    /// [`no_finish`] until LX-17b.
    pub finish: &'a FinishFn<'a>,

/// Runs a batch under `root` (`batch-<yyyyMMdd-HHmmss>`): header, folder and
/// `plan.json` (before any lane starts), the lanes, then, always, the summary
/// files. An error is a message for exit 3: the folder or `plan.json` could not
/// be written (before any run), or the records or summary could not be read or
/// written after.
pub fn run_batch(
    input: &BatchInput,
    opts: &BatchOptions,
    ui: &Ui,
    root: &Path,
    hooks: &Hooks<'_>,
    emit: &(dyn Fn(&str) + Sync),
) -> Result<BatchOutcome, String> {
    let started = Local::now();
    let name = batch_folder_name(&started.naive_local());
    let progress = Progress::new(*ui, opts.mode, &input.lanes, opts.runs_per_lease, emit);
    progress.say(&progress.header(&input.section, &input.lanes, &input.row_ids, &name));

    // LX-15's plan.json writer: the folder and plan.json exist before any lane starts.
    let plan = build_plan(
        &input.section,
        &input.row_ids,
        &input.lanes,
        opts.runs_per_lease,
        started.with_timezone(&Utc),
        std::process::id(),
    );
    let dir = create_batch(root, &name, &plan).map_err(|failed| failed.message)?;

    let jsonl = dir.join(BATCH_JSONL);
    let cfg = LaneConfig {
        row_ids: &input.row_ids,
        runs_per_lease: opts.runs_per_lease,
        stagger_seconds: opts.stagger_seconds,
        run_timeout: Duration::from_secs(u64::from(opts.run_timeout_minutes) * 60),
        max_consecutive_failures: opts.max_consecutive_failures,
        jsonl: &jsonl,
    };
    let on_record = |rec: &RunRecord| progress.say(&progress.run_line(rec));
    let on_notice = |instance: &str, rest: &str| progress.say(&progress.notice(instance, rest));
    let env = LaneEnv {
        call: hooks.call,
        wait_lease_free: hooks.wait_lease_free,
        sleep: hooks.sleep,
        on_record: &on_record,
        on_notice: &on_notice,
        finish: hooks.finish,
        stop: hooks.stop,
    };
    run_lanes(&input.lanes, &cfg, &env);

    // Also after Ctrl+C: summarise whatever finished.
    let records = read_records(&jsonl)
        .map_err(|e| format!("cannot read {}: {e}", jsonl.display()))?;
    let mut braked: Vec<String> = Vec::new();
    for rec in records.iter().filter(|r| r.braked) {
        if !braked.iter().any(|b| b.eq_ignore_ascii_case(&rec.instance)) {
            braked.push(rec.instance.clone());
        }
    }
    let summary = merge(&records, &input.lanes, &braked);
    // LX-17 hook: chaos header. LX-17b makes the line above "let mut summary" and adds the line "summary.chaos = chaos::select_header(&records, input.chaos.as_deref());".
    let title = format!("lab uat {}", input.section);
    let meta = BatchMeta {
        dir: &dir,
        title: &title,
        section: &input.section,
        row_ids: &input.row_ids,
        lane_count: input.lanes.len() as u32,
        runs_per_lease: opts.runs_per_lease,
        started,
    };
    let md = write_batch_summary(&summary, &meta, Local::now())
        .map_err(|e| format!("cannot write the summary in {}: {e}", dir.display()))?;
    let exit = exit_code(&summary);
    Ok(BatchOutcome {
        summary,
        md,
        dir,
        title,
        exit,
        records,
        started,
    })
}

/// Prints the end of a batch: under `--quiet` one line; in the fancy style a blank
/// line and the tables; else a blank line and the Markdown (as the PowerShell's
/// `Write-Host ''; Write-Host $md`).
pub fn print_outcome(ui: &Ui, opts: &BatchOptions, outcome: &BatchOutcome) {
    let dir = outcome.dir.display().to_string();
    // LX-17 hook: under --json print json::compact_json(&outcome.summary, &dir) and return here.
    if opts.quiet {
        println!("{}", quiet_line(&outcome.title, &outcome.summary, &dir));
    } else if ui.fancy && opts.mode == ProgressMode::Host {
        println!();
        print!("{}", fancy_summary(ui, &outcome.summary, &outcome.title, &dir));
    } else {
        println!();
        println!("{}", outcome.md.replace("\r\n", "\n"));
    }
}

/// One `lab_uat_run` call on its own MCP session: connect, call (bounded by
/// `timeout`), close. `call` is LX-15's `RunCall::for_lane(instance)`.
fn call_lab_uat_run(ep: &Endpoint, call: &RunCall, timeout: Duration) -> Result<Value, McpError> {
    let mut client = McpClient::connect(ep)?;
    let reply = client.call_tool("lab_uat_run", call.to_value(), timeout);
    client.close();
    reply
}

/// Whether a real run still needs the PowerShell: `--json` (LX-17's compact JSON),
/// `--diff-golden`, `--heal` and `--chaos` (which implies `--diff-golden`; an
/// empty `--chaos ""` counts as none, as `args::chaos_specs` filters it).
pub fn needs_powershell(args: &Args) -> bool {
    args.json || args.diff_golden || args.heal || args.chaos.iter().any(|c| !c.is_empty())
}

/// Runs a real batch against the daemon at `ep` and returns the exit code
/// (0, 1 or 4; 3 when the batch folder cannot be written).
pub fn execute(args: &Args, ctx: &Ctx, ep: &Endpoint, input: BatchInput) -> u8 {
    let mode = progress_mode(args.json, args.quiet, args.progress_to_stderr);
    let call = |instance: &str, timeout: Duration| {
        call_lab_uat_run(ep, &input.call.for_lane(instance), timeout)
    };
    let wait = |instance: &str, max: Duration| mcp::wait_lease_free(ep, instance, max);
    let sleep = |total: Duration| sleep_unless_stopped(total, &ctrlc::STOP);
    let hooks = Hooks {
        call: &call,
        wait_lease_free: &wait,
        sleep: &sleep,
        finish: &no_finish,
        stop: &ctrlc::STOP,
    };
    let opts = BatchOptions {
        runs_per_lease: args.runs_per_lease,
        stagger_seconds: args.stagger_seconds,
        run_timeout_minutes: args.run_timeout_minutes,
        max_consecutive_failures: args.max_consecutive_failures,
        mode,
        quiet: args.quiet,
        json: args.json,
    };
    ctrlc::install();
    let emit = stdio_emit(mode);
    match run_batch(&input, &opts, &ctx.ui, &paths::uat_root(), &hooks, &emit) {
        Ok(outcome) => {
            // LX-17 hook: --heal pass (heal::heal_batch) runs here, before print_outcome.
            print_outcome(&ctx.ui, &opts, &outcome);
            outcome.exit
        }
        Err(message) => {
            // Exit 3, one JSON object under --json, else the message on stderr.
            let _ = stop(
                &ctx.ui,
                args.json,
                3,
                &message,
                &mut anstream::stdout(),
                &mut anstream::stderr(),
            );
            3
        }
    }
}
```

```rust
#![allow(dead_code)]
//! A lane harness: a scripted `lab_uat_run`, recording what the lanes ask for.

use std::collections::{HashMap, VecDeque};
use std::path::PathBuf;
use std::sync::atomic::{AtomicBool, AtomicUsize, Ordering};
use std::sync::Mutex;
use std::time::Duration;

use cimmeria_lab_cli::batch::{read_records, PlanLane, RunRecord};
use cimmeria_lab_cli::commands::uat::lanes::{no_finish, run_lanes, LaneConfig, LaneEnv};
use cimmeria_lab_cli::daemon::mcp::McpError;
use serde_json::{json, Value};

pub type Reply = Result<Value, McpError>;

/// A reply where every named row passed.
pub fn pass_reply(run_dir: &str, rows: &[&str]) -> Reply {
    let rows: Vec<Value> = rows.iter().map(|id| json!({"row": id, "result": "PASS"})).collect();
    Ok(json!({"run_dir": run_dir, "rows": rows}))
}

/// `n` passing replies.
pub fn passes(n: usize, rows: &[&str]) -> Vec<Reply> {
    (0..n).map(|_| pass_reply("C:\\runs\\a", rows)).collect()
}

/// A reply where `row` failed with `reason`.
pub fn fail_reply(row: &str, reason: &str) -> Reply {
    Ok(json!({"run_dir": "C:\\runs\\f", "rows": [{"row": row, "result": "FAIL", "reasons": [reason]}]}))
}

/// `n` failing replies on FS-P3.
pub fn fails(n: usize) -> Vec<Reply> {
    (0..n).map(|_| fail_reply("FS-P3", "clause aim failed")).collect()
}

/// The first run fails on FS-P2 (known #1341) after FS-P1 passed.
pub fn frost_reply() -> Reply {
    Ok(json!({"run_dir": "C:\\runs\\f", "rows": [
        {"row": "FS-P1", "result": "PASS"},
        {"row": "FS-P2", "result": "FAIL", "reasons": ["clause movie-over failed"]}]}))
}

/// A `call` closure over a per-instance script, for `Hooks` (no recording).
pub fn scripted(
    script: Vec<(&str, Vec<Reply>)>,
) -> impl Fn(&str, Duration) -> Reply + Sync {
    let map: Mutex<HashMap<String, VecDeque<Reply>>> = Mutex::new(
        script
            .into_iter()
            .map(|(k, v)| (k.to_string(), v.into_iter().collect()))
            .collect(),
    );
    move |instance: &str, _timeout: Duration| {
        map.lock()
            .unwrap()
            .get_mut(instance)
            .and_then(VecDeque::pop_front)
            .unwrap_or_else(|| Err(McpError::Tool("no scripted reply".to_string())))
    }
}

pub struct LaneRig {
    pub dir: tempfile::TempDir,
    pub calls: Mutex<Vec<(String, Duration)>>,
    pub waits: Mutex<Vec<(String, Duration)>>,
    pub sleeps: Mutex<Vec<Duration>>,
    pub notices: Mutex<Vec<(String, String)>>,
    pub seen: Mutex<Vec<RunRecord>>,
    pub script: Mutex<HashMap<String, VecDeque<Reply>>>,
    /// What the lease wait answers.
    pub wait_result: bool,
    pub stop: AtomicBool,
    /// Set `stop` inside this (1-based) call, as Ctrl+C would.
    pub stop_on_call: Option<usize>,
    /// Panic inside any call for this instance.
    pub panic_instance: Option<String>,
    /// Sleep this long inside each call.
    pub delay_ms: u64,
    pub in_flight: AtomicUsize,
    pub max_in_flight: AtomicUsize,
}

impl LaneRig {
    pub fn new(script: Vec<(&str, Vec<Reply>)>) -> Self {
        Self {
            dir: tempfile::tempdir().unwrap(),
            calls: Mutex::default(),
            waits: Mutex::default(),
            sleeps: Mutex::default(),
            notices: Mutex::default(),
            seen: Mutex::default(),
            script: Mutex::new(
                script
                    .into_iter()
                    .map(|(k, v)| (k.to_string(), v.into_iter().collect()))
                    .collect(),
            ),
            wait_result: true,
            stop: AtomicBool::new(false),
            stop_on_call: None,
            panic_instance: None,
            delay_ms: 0,
            in_flight: AtomicUsize::new(0),
            max_in_flight: AtomicUsize::new(0),
        }
    }

    pub fn jsonl(&self) -> PathBuf {
        self.dir.path().join("batch.jsonl")
    }

    /// The records on disk, in file order.
    pub fn records(&self) -> Vec<RunRecord> {
        read_records(&self.jsonl()).unwrap()
    }

    /// Runs the lanes: `n` runs per lane, a 15 minute run timeout.
    pub fn run(&self, lanes: &[PlanLane], row_ids: &[String], n: u32, stagger: u32, max: u32) {
        let call = |instance: &str, timeout: Duration| -> Reply {
            let count = {
                let mut calls = self.calls.lock().unwrap();
                calls.push((instance.to_string(), timeout));
                calls.len()
            };
            if self.panic_instance.as_deref() == Some(instance) {
                panic!("boom");
            }
            if self.stop_on_call == Some(count) {
                self.stop.store(true, Ordering::SeqCst);
            }
            let now = self.in_flight.fetch_add(1, Ordering::SeqCst) + 1;
            self.max_in_flight.fetch_max(now, Ordering::SeqCst);
            if self.delay_ms > 0 {
                std::thread::sleep(Duration::from_millis(self.delay_ms));
            }
            self.in_flight.fetch_sub(1, Ordering::SeqCst);
            self.script
                .lock()
                .unwrap()
                .get_mut(instance)
                .and_then(VecDeque::pop_front)
                .unwrap_or_else(|| Err(McpError::Tool("no scripted reply".to_string())))
        };
        let wait = |instance: &str, max: Duration| -> bool {
            self.waits.lock().unwrap().push((instance.to_string(), max));
            self.wait_result
        };
        let sleep = |total: Duration| self.sleeps.lock().unwrap().push(total);
        let on_record = |rec: &RunRecord| self.seen.lock().unwrap().push(rec.clone());
        let on_notice = |instance: &str, rest: &str| {
            self.notices
                .lock()
                .unwrap()
                .push((instance.to_string(), rest.to_string()))
        };
        let env = LaneEnv {
            call: &call,
            wait_lease_free: &wait,
            sleep: &sleep,
            on_record: &on_record,
            on_notice: &on_notice,
            finish: &no_finish,
            stop: &self.stop,
        };
        let jsonl = self.jsonl();
        let cfg = LaneConfig {
            row_ids,
            runs_per_lease: n,
            stagger_seconds: stagger,
            run_timeout: Duration::from_secs(15 * 60),
            max_consecutive_failures: max,
            jsonl: &jsonl,
        };
        run_lanes(lanes, &cfg, &env);
    }
}
```

## Step B6: wiring into `run`

In `crates/lab-cli/src/commands/uat/mod.rs`, `Grep "pub fn run"` and `Grep
"native_preflight"`. LX-15 left `native_preflight` and a `run` that sends every
real run to `fallback::run`. Replace the whole `run` function (and its doc
comment) with this; keep `native_preflight` and every import as they are:

```rust
/// Runs `lab uat` and returns its exit code. `--plan-only` and every refusal
/// before anything is driven are native (LX-15). A real run drives natively
/// unless it needs a flag the Rust code does not do yet (`--json`,
/// `--diff-golden`, `--heal`, `--chaos`): then the PowerShell script does the
/// whole run, its own pre-flight included, so nothing is planned twice.
/// LX-17b replaces this function and removes the fallback.
pub fn run(args: &Args, ctx: &Ctx) -> u8 {
    if !args.plan_only && batch_run::needs_powershell(args) {
        return fallback::run(ctx);
    }
    let (ep, outcome) = native_preflight(args, ctx);
    match outcome {
        Outcome::Done(code) => code,
        Outcome::Drive(ready) => {
            batch_run::execute(args, ctx, &ep, batch_run::BatchInput::from_ready(ready))
        }
    }
}
```

Nothing else in `mod.rs` changes. `Args` still carries every field this uses
(`plan_only`, `json`, `diff_golden`, `heal`, `chaos`).
