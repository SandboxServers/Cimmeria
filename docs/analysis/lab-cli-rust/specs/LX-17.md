## Decisions made here (the coordinator should reconcile the packet text)

1. **No `exit_code.rs`.** `summary::exit_code` is replaced in place (Step A2), because `Summary` and its 0/1/4 version are LX-16a's and the packet's `{golden,heal,json}.rs` list had no room for it. A chaos divergence is what a chaos run reports, not a failure: only its diffs that could not be made give 5; 8 wins over every other code.
2. **`merge_golden` takes the run-ref function as a parameter** (`&dyn Fn(&RunRecord) -> String`), as `Merge-UatGolden` takes a scriptblock; `chaos::merge_divergence` passes `chaos::run_ref` (its `seed=` ref), `summary::merge` passes `default_run_ref` for golden.
3. **Sort stability.** `Sort-Object -Descending` on small lists is stable in practice; Rust uses `sort_by` (stable) on the count, so ties keep first-seen order. A test pins it.
4. **`Split-Path -Leaf`** (the heal `diff` file name in `--json`) is `rsplit(['\\', '/']).next()`, so a Windows path splits on Linux CI too.
5. **Heal under Ctrl+C.** PowerShell aborted a heal call at once; the Rust heal cannot cancel a blocking call. `ctrlc::stop_requested()` is checked in the `call` and `wait` closures `heal_batch` passes (a hint that has not started fails at once, and the wait returns false, so healing stops). The "Ctrl+C mid-heal keeps the diffs already written" guarantee is kept by `heal_pass` writing the summary before it re-raises a panic from a closure (the PowerShell `finally`); the test simulates the interrupt with a panic.
6. **Check [456] of `test-uat.ps1`** ("a wait that throws counts as a held lease") has no Rust port: the wait closure returns `bool` (LX-12 decision 4); `a_lease_that_stays_held_stops_healing` in LX-12's `calibrate_heal.rs` covers the same stop.
7. **The per-run work is one closure.** `batch_run::finish_with(diff, golden_call)` returns the `FinishFn` LX-16b's lane loop calls after every run: it sets the run's own chaos header from its reply (`Get-UatRunChaos`) and, for a passing run under `--diff-golden`, the golden value (`Get-UatRunGolden`). The run's verdict never changes. A test can pass a stub for the golden call, so `uat_chaos_run.rs` needs no daemon.
8. **`--json` exit 3.** LX-16b already prints a batch-folder failure through `preflight::stop`, which writes `{"ok":false,"exit":3,"error":...}` under `--json`; this packet adds nothing there.

```rust
/// The comparison of the runs that carry a `Golden` value (`Merge-UatGolden`):
/// counts of matches, divergences and errors (a diff that could not be made),
/// and every non-match line grouped with its count and up to
/// [`RUN_REFS_MAX`] run refs, most common first (ties keep the order first
/// seen). `None` when no run has a value (a batch without `--diff-golden`).
/// `run_ref` names a run in a group.
pub fn merge_golden(
    runs: &[RunRecord],
    run_ref: &dyn Fn(&RunRecord) -> String,
) -> Option<GoldenSummary> {
    let with_golden: Vec<&RunRecord> = runs
        .iter()
        .filter(|r| r.golden.as_deref().is_some_and(|g| !g.is_empty()))
        .collect();
    if with_golden.is_empty() {
        return None;
    }
    let (mut matched, mut diverged, mut errors) = (0, 0, 0);
    let mut groups: Vec<GoldenGroup> = Vec::new();
    for run in with_golden {
        let line = run.golden.as_deref().unwrap_or("");
        if line == "match" {
            matched += 1;
            continue;
        }
        if line.starts_with("error: ") {
            errors += 1;
        } else {
            diverged += 1;
        }
        let at = match groups.iter().position(|g| g.line == line) {
            Some(i) => i,
            None => {
                groups.push(GoldenGroup {
                    line: line.to_string(),
                    count: 0,
                    runs: Vec::new(),
                });
                groups.len() - 1
            }
        };
        groups[at].count += 1;
        if groups[at].runs.len() < RUN_REFS_MAX {
            groups[at].runs.push(run_ref(run));
        }
    }
    groups.sort_by(|a, b| b.count.cmp(&a.count));
    Some(GoldenSummary {
        matched,
        diverged,
        errors,
        groups,
    })
}

/// The first line of a message, without its CR.
fn first_line(text: &str) -> &str {
    text.split('\n').next().unwrap_or("").trim_end_matches('\r')
}

/// Each run of CR and LF characters becomes one space.
fn collapse_newlines(text: &str) -> String {
    let mut out = String::new();
    let mut in_run = false;
    for c in text.chars() {
        if c == '\r' || c == '\n' {
            if !in_run {
                out.push(' ');
            }
            in_run = true;
        } else {
            in_run = false;
            out.push(c);
        }
    }
    out
}

/// The value `--diff-golden` stores in a run's `Golden` field, from a
/// `lab_golden_diff` reply or the message of a call that failed: `match`, the
/// first divergence line, or `error: <why>`. A refusal (`no_golden`,
/// `cannot_diff`) or a reply without a verdict is an error, never a match.
/// Newlines become spaces, lease ids are hidden, and the value is cut to
/// [`VALUE_MAX`] characters (`...` at the end when cut).
pub fn golden_value(reply: Option<&Value>, call_error: Option<&str>) -> String {
    let field = |key: &str| reply.and_then(|r| r.get(key));
    let text = |key: &str| field(key).and_then(Value::as_str).unwrap_or("");
    let value = if let Some(why) = call_error.filter(|e| !e.is_empty()) {
        format!("error: {why}")
    } else if field("ok").and_then(Value::as_bool) != Some(true) {
        let code = text("code");
        let prefix = if code.is_empty() {
            String::new()
        } else {
            format!("{code}: ")
        };
        format!("error: {prefix}{}", text("error"))
    } else {
        match (field("match").and_then(Value::as_bool), text("first")) {
            (Some(true), _) => "match".to_string(),
            (Some(false), first) if !first.is_empty() => first.to_string(),
            _ => "error: lab_golden_diff gave no verdict".to_string(),
        }
    };
    clip_text(&hide_lease_ids(&collapse_newlines(&value)), VALUE_MAX)
}

pub struct DiffArgs {

    pub specs_dir: Option<String>,
}

impl DiffArgs {
    pub fn new(section: &str, specs_dir: Option<&Path>) -> DiffArgs {

#[derive(Serialize)]
struct DiffCall<'a> {
    section: &'a str,
    #[serde(skip_serializing_if = "Option::is_none")]
    specs_dir: Option<&'a str>,
    run_dir: &'a str,
}

/// The `Golden` value `--diff-golden` gives one finished run, or `None` for
/// none: no `--diff-golden` (`diff` is `None`), or a run that did not pass
/// (only passing runs are compared). A passing run that named no folder is an
/// error, with no call. `invoke` is the call itself, so the lane loop passes
/// the MCP call and a test passes a stub.
pub fn run_golden(
    rec: &RunRecord,
    diff: Option<&DiffArgs>,
    invoke: &mut dyn FnMut(Value) -> Result<Value, McpError>,
) -> Option<String> {
    let diff = diff?;
    if !rec.ok {
        return None;
    }
    let run_dir = rec.run_dir.as_deref().unwrap_or("");
    if run_dir.is_empty() {
        return Some("error: the run named no run folder".to_string());
    }
    let call = DiffCall {
        section: &diff.section,
        specs_dir: diff.specs_dir.as_deref(),
        run_dir,
    };
    let args = serde_json::to_value(&call).expect("a plain struct serialises");
    Some(match invoke(args) {
        Ok(reply) => golden_value(Some(&reply), None),
        Err(e) => golden_value(
            None,
            Some(first_line(&call_error_text("lab_golden_diff", &e))),
        ),
    })
}

/// One `lab_golden_diff` call on its own MCP session (the lane loop's
/// `Invoke` of the PowerShell): the session is closed whatever the answer.
pub fn call_golden_diff(ep: &Endpoint, args: Value) -> Result<Value, McpError> {
    let mut client = McpClient::connect(ep)?;
    let reply = client.call_tool("lab_golden_diff", args, DIFF_TIMEOUT);
    client.close();
    reply
}
```

```rust
//! header of a batch, a chaos run's ref in a divergence group, and the
//! divergence from the golden).

use std::sync::OnceLock;

use regex::Regex;

use crate::batch::RunRecord;

use super::golden::{merge_golden, GoldenSummary};

/// `seed=<digits>`: what differs between the runs' headers.
fn seed_digits() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    RE.get_or_init(|| Regex::new(r"seed=\d+").expect("seed regex"))
}

/// `seed=<anything up to a space>`: a seed as the run ref shows it.
fn seed_token() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    RE.get_or_init(|| Regex::new(r"seed=\S+").expect("seed token regex"))
}

fn header_of(run: &RunRecord) -> &str {
    run.chaos.as_deref().unwrap_or("")
}

/// The batch's chaos header (`Select-UatChaosHeader`): the runs' own headers
/// replace the typed one (`fallback`, kept only when no run returned one). Runs
/// differ in seed, so when the headers differ only by seed the seed is named once
/// as `<per run>`; headers that differ beyond that are counted, not listed.
pub fn select_header(runs: &[RunRecord], fallback: Option<&str>) -> Option<String> {
    let mut seen: Vec<&str> = Vec::new();
    for run in runs {
        let h = header_of(run);
        if !h.is_empty() && !seen.contains(&h) {
            seen.push(h);
        }
    }
    match seen.len() {
        0 => fallback.filter(|f| !f.is_empty()).map(str::to_string),
        1 => Some(seen[0].to_string()),
        _ => {
            let mut norm: Vec<String> = Vec::new();
            for h in &seen {
                let n = seed_digits().replace_all(h, "seed=<per run>").into_owned();
                if !norm.contains(&n) {
                    norm.push(n);
                }
            }
            if norm.len() == 1 {
                Some(norm.remove(0))
            } else {
                Some(format!(
                    "{} (+{} other spec(s) in batch.jsonl)",
                    norm[0],
                    norm.len() - 1
                ))
            }
        }
    }
}

/// The runs that ran under chaos (`chaos` true: they carry the runner's header)
/// or the rest (`chaos` false), in order, cloned.
pub fn select_runs(runs: &[RunRecord], chaos: bool) -> Vec<RunRecord> {
    runs.iter()
        .filter(|r| !header_of(r).is_empty() == chaos)
        .cloned()
        .collect()
}

/// A chaos run's ref in a divergence group (`Get-UatChaosRunRef`):
/// `<instance>#<index> seed=<seed>`, one seed per distinct value, joined with
/// `,`; a header with no seed is shown whole in parentheses; no header is the
/// plain `<instance>#<index>`.
pub fn run_ref(run: &RunRecord) -> String {
    let base = format!("{}#{}", run.instance, run.index);
    let header = header_of(run);
    let mut seeds: Vec<String> = Vec::new();
    for m in seed_token().find_iter(header) {
        let seed = m.as_str().trim_end_matches(';').to_string();
        if !seeds.contains(&seed) {
            seeds.push(seed);
        }
    }
    if !seeds.is_empty() {
        format!("{base} {}", seeds.join(","))
    } else if !header.is_empty() {
        format!("{base} ({header})")
    } else {
        base
    }
}

/// reported as `chaos_divergence` in place of `golden`): the same shape and
/// grouping as [`merge_golden`], each group's runs named by [`run_ref`]. `None`
/// only when no chaos run was compared.
pub fn merge_divergence(runs: &[RunRecord]) -> Option<GoldenSummary> {
    merge_golden(&select_runs(runs, true), &run_ref)
}
```

```rust
/// A golden comparison for `--json`: counts, `errors` when some, then `first`
/// (the most common divergence, never an error line) or, only when no run
/// diverged, `error` (the most common error line); lines cut to `max_line`.
fn compact_golden(g: &GoldenSummary, max_line: usize) -> CompactGolden {
    let mut lines = g.groups.iter().map(|x| x.line.as_str());
    let div = lines.clone().find(|l| !l.starts_with("error: "));
    let err = lines.find(|l| l.starts_with("error: "));
    CompactGolden {
        matched: g.matched,
        diverged: g.diverged,
        errors: g.errors,
        first: div.map(|l| clip_text(l, max_line)),
        error: if div.is_none() {
            err.map(|l| clip_text(l, max_line))
        } else {
            None
        },
    }
}

/// [`compact_json`] with explicit caps (the tests use small ones).
pub fn compact_json_with(
    summary: &Summary,
    batch_dir: &str,
    max_failures: usize,
    max_heal: usize,
) -> String {
    let mut fails: Vec<&FailureGroup> = summary.failures.iter().collect();
    fails.sort_by(|a, b| b.count.cmp(&a.count)); // stable: ties keep their order
    let failures: Vec<Failure> = fails
        .iter()
        .take(max_failures)
        .map(|f| Failure {
            n: f.count,
            why: clip_text(&f.signature, WHY_MAX),
            issue: f.issue.clone().filter(|i| !i.is_empty()),
            runs: f.runs.iter().take(RUNS_PER_GROUP).cloned().collect(),
        })
        .collect();
    let out = Compact {
        ok: summary.ok,
        runs: summary.runs,
        passed: summary.passed,
        failed: summary.failed,
        failed_known: (summary.failed > 0).then_some(summary.failed_known),
        failed_new: (summary.failed > 0).then_some(summary.failed_new),
        rows: Rows(&summary.rows),
        lanes: summary
            .lanes
            .iter()
            .map(|l| Lane {
                instance: &l.instance,
                passed: format!("{}/{}", l.passed, l.runs),
                braked: l.braked,
            })
            .collect(),
        failures,
        more_failure_groups: (fails.len() > max_failures).then(|| fails.len() - max_failures),
        golden: summary
            .golden
            .as_ref()
            .map(|g| compact_golden(g, GOLDEN_LINE_MAX)),
        chaos_divergence: summary
            .chaos_divergence
            .as_ref()
            .map(|g| compact_golden(g, GOLDEN_LINE_MAX)),
        heal: summary
            .heal
            .iter()
            .take(max_heal)
            .map(|h| HealOut {

        chaos: summary.chaos.as_deref().filter(|c| !c.is_empty()),
        batch: batch_dir,
    };
    serde_json::to_string(&out).expect("a plain struct serialises")
}
```

```rust
//! `lab uat --heal` (lab-spec-vocab D-SV8 (a)): after the batch, recalibrate
//! each pose a failed row missed on, save the proposed diffs in the batch
//! folder, and list them in `batch.json`, `summary.md` and `--json`. The spec

use std::collections::HashSet;
use std::panic::{catch_unwind, resume_unwind, AssertUnwindSafe};
use std::time::Duration;

use chrono::Local;
use serde_json::Value;

use crate::batch::RunRecord;
use crate::commands::calibrate;
use crate::commands::calibrate::heal::{invoke_heal, HealHint, HealJob, HealRecord};
use crate::commands::Ctx;
use crate::daemon::mcp::{self, McpClient, McpError};
use crate::daemon::status::Endpoint;

use super::batch_run::{BatchInput, BatchOptions, BatchOutcome};

use super::progress::{stdio_emit, ProgressMode};
use super::summary::{exit_code, write_batch_summary, BatchMeta, HealEntry, Summary};

/// The distinct `(row, pose)` pairs of the runs' row summaries that carry a
/// heal hint (`{pose, step}`, set only on a failed row whose first failed step
/// missed on a pose), in the order first seen. A `PASS` row (any case), a row
/// with no hint, and a hint with an empty pose or row are ignored.
pub fn heal_hints(runs: &[RunRecord]) -> Vec<HealHint> {
    let mut seen: HashSet<(String, String)> = HashSet::new();
    let mut out = Vec::new();
    for run in runs {
        for r in &run.rows {
            if r.result.eq_ignore_ascii_case("PASS") {
                continue;
            }
            let pose = r
                .heal
                .as_ref()
                .and_then(|h| h.get("pose"))
                .and_then(Value::as_str)
                .unwrap_or("");
            if pose.is_empty() || r.row.is_empty() {
                continue;
            }
            if seen.insert((r.row.clone(), pose.to_string())) {
                out.push(HealHint {
                    row: r.row.clone(),
                    pose: pose.to_string(),
                });
            }
        }
    }
    out
}

/// The three things a heal pass talks to. `call` is the `lab_uat_calibrate`
/// call, `say` prints one progress line, `wait` (when given) waits for the
/// instance's lease to clear after a failed call, `print_diff` (when given)
/// prints a proposal's text (the caller passes it only in host mode).
pub struct HealIo<'a> {
    pub call: &'a mut dyn FnMut(Value) -> Result<Value, McpError>,
    pub say: &'a mut dyn FnMut(&str),
    pub wait: Option<&'a mut dyn FnMut(&str) -> bool>,
    pub print_diff: Option<&'a mut dyn FnMut(&str)>,
}

/// `lab uat --heal` after the batch: recalibrates each hint of `runs` on
/// `instance`, says a line per hint, and records the proposals as
/// `summary.heal`, rewriting `summary.md` and `batch.json`. Returns the new
/// Markdown, or `None` when no proposal was written (the files stay as the
/// batch left them). The summary is rewritten before a panic from a closure is
/// re-raised, so an interrupted heal still lists the diffs already written.
pub fn heal_pass(
    runs: &[RunRecord],
    summary: &mut Summary,
    batch: &BatchMeta<'_>,
    specs_dir: &str,
    instance: &str,
    io: HealIo<'_>,
) -> Option<String> {
    let HealIo {
        call,
        say,
        wait,
        mut print_diff,
    } = io;
    let hints = heal_hints(runs);
    if hints.is_empty() {
        say("heal: no failed row carries a heal hint; nothing to recalibrate");
        return None;
    }
    let names: Vec<String> = hints
        .iter()
        .map(|h| format!("{} {}", h.row, h.pose))
        .collect();
    say(&format!(
        "heal: recalibrating {} pose(s) on {}: {}",
        hints.len(),
        instance,
        names.join(", ")
    ));
    let job = HealJob {
        batch_dir: batch.dir,
        section: batch.section,
        specs_dir,
        instance,
    };
    let mut records: Vec<HealRecord> = Vec::new();
    let outcome = catch_unwind(AssertUnwindSafe(|| {
        let mut on_record = |r: &HealRecord| {
            records.push(r.clone());
            say(&r.line);
            if let (Some(text), Some(print)) = (r.text.as_deref(), print_diff.as_mut()) {
                print(text);
            }
        };
        invoke_heal(&hints, &job, call, Some(&mut on_record), wait)
    }));
    // The PowerShell `finally`: whatever happened, list the proposals.
    let proposed: Vec<HealEntry> = records
        .iter()
        .filter_map(|r| {
            let diff = r.diff.as_ref()?;
            Some(HealEntry {
                row: r.row.clone().unwrap_or_default(),
                pose: r.pose.clone().unwrap_or_default(),
                diff: diff.display().to_string(),
            })
        })
        .collect();
    let mut markdown = None;
    if !proposed.is_empty() {
        summary.heal = proposed;
        match write_batch_summary(summary, batch, Local::now()) {
            Ok(text) => markdown = Some(text),
            Err(e) => say(&format!("heal: cannot write the summary: {e}")),
        }
    }
    if let Err(panic) = outcome {
        resume_unwind(panic);
    }
    markdown
}

/// `--heal` after a native batch (the `-Heal` block of `uat.ps1`): recalibrates
/// each hint on the batch's one instance (`--heal` needs `--leases 1`) and, when
/// a proposal was written, replaces `outcome.md` with the new Markdown and
/// `outcome.exit` with the recomputed code (8). The caller skips it after Ctrl+C.
pub fn heal_batch(
    ctx: &Ctx,
    ep: &Endpoint,
    input: &BatchInput,
    opts: &BatchOptions,
    outcome: &mut BatchOutcome,
) {
    let Some(instance) = input.lanes.first().map(|l| l.instance.clone()) else {
        return;
    };
    let title = outcome.title.clone();
    let meta = BatchMeta {
        dir: &outcome.dir,
        title: &title,
        section: &input.section,
        row_ids: &input.row_ids,
        lane_count: input.lanes.len() as u32,
        runs_per_lease: opts.runs_per_lease,
        started: outcome.started,
    };
    let specs = input.specs_dir.clone().unwrap_or_default();
    // Each call is its own MCP session, as the PowerShell's was. After Ctrl+C a
    // hint that has not started fails at once and the wait gives up.
    let mut call = |a: Value| -> Result<Value, McpError> {
        if ctrlc::stop_requested() {
            return Err(McpError::Tool("interrupted by Ctrl+C".to_string()));
        }
        let mut client = McpClient::connect(ep)?;
        let reply = client.call_tool("lab_uat_calibrate", a, calibrate::outcome::timeout(None));
        client.close();
        reply
    };
    let emit = stdio_emit(opts.mode);
    let mut say = |m: &str| emit(m);
    let mut wait = |i: &str| {
        !ctrlc::stop_requested() && mcp::wait_lease_free(ep, i, Duration::from_secs(600))
    };
    let ui = &ctx.ui;
    let mut print = |t: &str| println!("{}", calibrate::render::render_diff(ui, t));
    let io = HealIo {
        call: &mut call,
        say: &mut say,
        wait: Some(&mut wait),
        print_diff: if opts.mode == ProgressMode::Host {
            Some(&mut print)
        } else {
            None
        },
    };
    let healed = heal_pass(&outcome.records, &mut outcome.summary, &meta, &specs, &instance, io);
    if let Some(markdown) = healed {
        outcome.md = markdown;
        outcome.exit = exit_code(&outcome.summary);
    }
}
```

`print(text)`, write `(**print)(text)`. Both are the same call.

```rust
/// Every file under a folder with its bytes, sorted: a write, a new file or a
/// deleted one changes it.
fn tree(dir: &Path) -> Vec<(String, Vec<u8>)> {
    fn walk(dir: &Path, out: &mut Vec<(String, Vec<u8>)>) {
        for entry in fs::read_dir(dir).unwrap() {
            let path = entry.unwrap().path();
            if path.is_dir() {
                walk(&path, out);
            } else {
                out.push((path.display().to_string(), fs::read(&path).unwrap()));
            }
        }
    }
    let mut out = Vec::new();
    walk(dir, &mut out);
    out.sort();
    out
}

    run_dir: &'a Path,
    calls: &'a RefCell<Vec<Value>>,

    move |a: Value| {

                "pose": a["pose"], "confirmed": 0, "probes": 108, "reason": "no candidate hovered the target"}]}))
        }
    }
}
```
