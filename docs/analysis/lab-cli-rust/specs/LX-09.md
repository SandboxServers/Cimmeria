## Rules this port keeps (from `clients.ps1`, D-LC5)

1. Only `stop` is a verb. Anything else, or no verb, prints the usage line and exits 2, before the daemon is asked.
2. `stop` with no instance, `''` or `all` (any letter case) means every instance.
3. `--force` with all instances prints `--force needs a named instance` and exits 2 **before the daemon is asked**.
4. The daemon status comes from `GET /status`. No status: print the daemon-down line, exit 1, stop nothing.
5. A named instance that the daemon does not host: exit 2, naming the hosted ones.
6. Instance names and `all` and `stop` match without regard to case (PowerShell's `-eq` did).
7. An instance with no `client_pid` is "no client". A leased instance is refused (exit 3) unless `--force` is given with a named instance. Only a process whose image is `SGW.exe` is touched.
8. Exit codes: 0 nothing refused or failed; 1 daemon down; 2 usage; 3 a leased client was refused; 4 a client could not be stopped (4 wins over 3).
9. The flag is spelled `--force` in every message (LX-02 made `argv::rewrite` turn the PowerShell `-Force` into it, so `-Force` still works when typed). This is the only text change from the PowerShell strings.

```rust
//! Which instances `lab clients stop` stops, refuses or skips, and the lines
//! it prints. Pure: no process is touched and nothing is printed here. Port of
//! `Select-StopTargets`, `Get-LeaseHeld`, `Get-LeaseWho` and the messages of
//! tools/lab/cli/clients.ps1.

use serde_json::Value;

use crate::daemon::status::{InstanceRow, StatusReply};
use crate::ui::{Mark, Tone, Ui};

/// Printed (exit 2) for a missing or unknown verb.
pub const USAGE: &str = "usage: lab clients stop [<instance>|all] [--force]";
/// Printed (exit 2) for `--force` with no instance or `all`.
pub const FORCE_NEEDS_NAME: &str = "--force needs a named instance";
/// Printed (exit 1) when the daemon gives no status.
pub const DAEMON_DOWN: &str =
    "daemon not running (or status endpoint unavailable); nothing stopped";

/// Whether `which` means every instance: absent, empty or `all` (any case).
pub fn is_all(which: Option<&str>) -> bool {
    match which {
        None => true,
        Some(name) => name.is_empty() || name.eq_ignore_ascii_case("all"),
    }
}

/// Instance names compare without regard to case, as PowerShell's `-eq` did.
pub fn same_name(a: &str, b: &str) -> bool {
    a.eq_ignore_ascii_case(b)
}

/// Whether the image path names `SGW.exe`: the last path component, any case,
/// the whole name (`SGW.exe.bak` and `notSGW.exe` are not it).
#[cfg_attr(not(windows), allow(dead_code))]
pub fn is_sgw_image(path: &str) -> bool {
    let name = path.rsplit(['\\', '/']).next().unwrap_or(path);
    name.eq_ignore_ascii_case("SGW.exe")
}

/// Whether a session holds the instance's lease (`lease.held` is JSON `true`).
pub fn lease_held(inst: &InstanceRow) -> bool {
    matches!(
        inst.lease.as_ref().and_then(|lease| lease.get("held")),
        Some(Value::Bool(true))
    )
}

/// A JSON field as text: empty for a missing or null field.
fn text(value: Option<&Value>) -> String {
    match value {
        None | Some(Value::Null) => String::new(),
        Some(Value::String(s)) => s.clone(),
        Some(other) => other.to_string(),
    }
}

/// `owner (purpose)` of the instance's lease, `-` for a part the status
/// leaves out. Never a lease id.
pub fn lease_who(inst: &InstanceRow) -> String {
    let held = inst.lease.as_ref().and_then(|lease| lease.get("lease"));
    let mut owner = text(held.and_then(|h| h.get("owner")));
    let mut purpose = text(held.and_then(|h| h.get("purpose")));
    if owner.is_empty() {
        owner = "-".to_string();
    }
    if purpose.is_empty() {
        purpose = "-".to_string();
    }
    format!("{owner} ({purpose})")
}

/// The instances a stop names, sorted into buckets.
#[derive(Debug, Default)]
pub struct StopTargets<'a> {
    /// To stop (includes `forced`).
    pub stop: Vec<&'a InstanceRow>,
    /// The leased ones stopped because of `--force`.
    pub forced: Vec<&'a InstanceRow>,
    /// Leased and not stopped.
    pub refuse: Vec<&'a InstanceRow>,
    /// No client.
    pub none: Vec<&'a InstanceRow>,
}

/// Sorts the instances a stop names. `--force` applies only to a named
/// instance, never to all. Port of `Select-StopTargets`.
pub fn select_stop_targets<'a>(
    status: &'a StatusReply,
    which: Option<&str>,
    force: bool,
) -> StopTargets<'a> {
    let all = is_all(which);
    let mut targets = StopTargets::default();
    for inst in &status.instances {
        if !all && !which.is_some_and(|name| same_name(&inst.instance, name)) {
            continue;
        }
        if inst.client_pid.is_none() {
            targets.none.push(inst);
            continue;
        }
        if !lease_held(inst) {
            targets.stop.push(inst);
            continue;
        }
        if force && !all {
            targets.forced.push(inst);
            targets.stop.push(inst);
        } else {
            targets.refuse.push(inst);
        }
    }
    targets
}

/// A line led by a glyph in fancy mode, the bare text in plain mode.
fn marked(ui: &Ui, mark: Mark, tone: Tone, plain: &str, fancy: &str) -> String {
    if ui.fancy {
        format!("{} {fancy}", ui.paint(tone, ui.mark(mark)))
    } else {
        plain.to_string()
    }
}

/// Stderr lines for an error: the bare message in plain mode; `error: ...`
/// and an indented dim `hint: ...` in fancy mode (the `Ui::error` look).
pub fn error_lines(ui: &Ui, message: &str, hint: Option<&str>) -> Vec<String> {
    if !ui.fancy {
        return vec![message.to_string()];
    }
    let mut lines = vec![format!("{} {message}", ui.paint(Tone::Fail, "error:"))];
    if let Some(hint) = hint {
        lines.push(format!("  {}", ui.paint(Tone::Dim, &format!("hint: {hint}"))));
    }
    lines
}

/// An instance with no client.
pub fn none_line(ui: &Ui, label: &str) -> String {
    let text = format!("{label}: no client");
    marked(ui, Mark::Stopped, Tone::Dim, &text, &text)
}

/// A leased instance that is not stopped.
pub fn refuse_line(ui: &Ui, label: &str, who: &str) -> String {
    let plain = format!("{label}: leased to {who}; not stopped (use --force to override)");
    let fancy = format!(
        "refused {label}: leased by {who}  {}",
        ui.paint(Tone::Dim, "use --force to override")
    );
    marked(ui, Mark::Fail, Tone::Fail, &plain, &fancy)
}

/// The warning before a leased client is stopped anyway.
pub fn forced_line(ui: &Ui, label: &str, who: &str) -> String {
    let plain = format!(
        "{label}: leased to {who}; stopping anyway (--force). The holder loses the client and the watchdog may relaunch it."
    );
    let fancy = format!(
        "{label}: leased by {who}; stopping anyway (--force). The holder loses the client and the watchdog may relaunch it."
    );
    marked(ui, Mark::Warn, Tone::Warn, &plain, &fancy)
}

/// A client that was stopped.
pub fn stopped_line(ui: &Ui, label: &str, pid: u32) -> String {
    marked(
        ui,
        Mark::Pass,
        Tone::Ok,
        &format!("{label}: stopped pid {pid}"),
        &format!("stopped {label} (pid {pid})"),
    )
}

/// A pid that is not a running `SGW.exe`: nothing was touched.
pub fn not_sgw_line(ui: &Ui, label: &str, pid: u32) -> String {
    let text = format!("{label}: no client (pid {pid} is not a running SGW)");
    marked(ui, Mark::Stopped, Tone::Dim, &text, &text)
}

/// A client still alive after the stop (stderr). `reason` is the error text
/// when the stop could not even be tried (for example "Windows only").
pub fn failed_line(ui: &Ui, label: &str, pid: u32, reason: Option<&str>) -> String {
    let (plain, fancy) = match reason {
        None => (
            format!("{label}: could not stop pid {pid}"),
            format!("could not stop {label} (pid {pid})"),
        ),
        Some(reason) => (
            format!("{label}: could not stop pid {pid}: {reason}"),
            format!("could not stop {label} (pid {pid}): {reason}"),
        ),
    };
    marked(ui, Mark::Fail, Tone::Fail, &plain, &fancy)
}
```

## Step 3: `crates/lab-cli/src/commands/clients/win.rs` (new, complete file)

```rust
//! Stops one game client by pid. Windows only: the other platforms get a stub
//! that says so (the lab runs the Windows client; Linux CI only compiles this).
//!
//! The steps are `Stop-LabClient` of the PowerShell command: act only on a
//! process whose image is `SGW.exe`; ask its windows to close; wait 8 s;
//! force-stop it; wait 2 s more. The process handle is opened first and held,
//! so a reused pid cannot be swapped in between the image check and the stop.

use std::time::Duration;

/// How long the windows get to close before the process is force-stopped.
pub const GRACE: Duration = Duration::from_millis(8000);

/// What a stop did.
#[cfg_attr(not(windows), allow(dead_code))]
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum StopOutcome {
    /// No process with that pid, or it is not `SGW.exe`: nothing was touched.
    NotSgw,
    /// The process was `SGW.exe` and is gone.
    Stopped,
    /// The process was `SGW.exe` and is still alive (for example an elevated
    /// client this shell may not stop).
    Failed,
}

/// Stops the client with this pid, giving its windows [`GRACE`] to close.
pub fn stop_client(pid: u32) -> Result<StopOutcome, String> {
    stop_client_with(pid, GRACE)
}

/// The same with a chosen grace period (tests use a short one).
#[cfg(not(windows))]
pub fn stop_client_with(_pid: u32, _grace: Duration) -> Result<StopOutcome, String> {
    Err("Windows only".to_string())
}

/// The same with a chosen grace period (tests use a short one).
#[cfg(windows)]
pub fn stop_client_with(pid: u32, grace: Duration) -> Result<StopOutcome, String> {
    use windows_sys::Win32::Foundation::{
        CloseHandle, GetLastError, ERROR_INVALID_PARAMETER, FALSE, HANDLE, WAIT_OBJECT_0,
    };
    use windows_sys::Win32::System::Threading::{
        OpenProcess, QueryFullProcessImageNameW, TerminateProcess, WaitForSingleObject,
        PROCESS_QUERY_LIMITED_INFORMATION, PROCESS_SYNCHRONIZE, PROCESS_TERMINATE,
    };

    use super::targets::is_sgw_image;

    /// Waits for the process to exit; true when it has.
    fn exited(handle: HANDLE, wait: Duration) -> bool {
        let ms = u32::try_from(wait.as_millis()).unwrap_or(u32::MAX);
        // SAFETY: `handle` is a live process handle with SYNCHRONIZE access.
        unsafe { WaitForSingleObject(handle, ms) == WAIT_OBJECT_0 }
    }

    // SAFETY: plain Win32 calls; the handle is closed on every path below.
    let handle = unsafe {
        let full = OpenProcess(
            PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_SYNCHRONIZE | PROCESS_TERMINATE,
            FALSE,
            pid,
        );
        if full.is_null() {
            // Without the right to terminate (an elevated client): still look,
            // so the outcome can be `Failed` rather than a lie.
            OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_SYNCHRONIZE, FALSE, pid)
        } else {
            full
        }
    };
    if handle.is_null() {
        // SAFETY: reads this thread's last error.
        let code = unsafe { GetLastError() };
        // No such process: the PowerShell "no client" case.
        return if code == ERROR_INVALID_PARAMETER {
            Ok(StopOutcome::NotSgw)
        } else {
            Err(format!("cannot open pid {pid} (Windows error {code})"))
        };
    }

    let mut buffer = [0u16; 1024];
    let mut length = buffer.len() as u32;
    // SAFETY: `buffer` holds `length` u16s; flags 0 asks for the Win32 path.
    let queried =
        unsafe { QueryFullProcessImageNameW(handle, 0, buffer.as_mut_ptr(), &mut length) } != 0;
    if !queried {
        let gone = exited(handle, Duration::ZERO);
        // SAFETY: closes the handle opened above, once.
        unsafe { CloseHandle(handle) };
        return if gone {
            Ok(StopOutcome::NotSgw)
        } else {
            Err(format!("cannot read the image name of pid {pid}"))
        };
    }
    let image = String::from_utf16_lossy(&buffer[..length as usize]);
    if !is_sgw_image(&image) {
        // SAFETY: closes the handle opened above, once.
        unsafe { CloseHandle(handle) };
        return Ok(StopOutcome::NotSgw);
    }

    post_close_to_windows_of(pid);
    let mut done = exited(handle, grace);
    if !done {
        // SAFETY: `handle` was opened with PROCESS_TERMINATE when the OS allowed it;
        // a refusal just leaves the process alive and is caught by the wait below.
        unsafe { TerminateProcess(handle, 1) };
        done = exited(handle, Duration::from_millis(2000));
    }
    // SAFETY: closes the handle opened above, once.
    unsafe { CloseHandle(handle) };
    Ok(if done {
        StopOutcome::Stopped
    } else {
        StopOutcome::Failed
    })
}

/// Posts `WM_CLOSE` to every top-level window that belongs to `pid`.
#[cfg(windows)]
fn post_close_to_windows_of(pid: u32) {
    use windows_sys::Win32::Foundation::{BOOL, HWND, LPARAM, TRUE};
    use windows_sys::Win32::UI::WindowsAndMessaging::{
        EnumWindows, GetWindowThreadProcessId, PostMessageW, WM_CLOSE,
    };

    struct Target {
        pid: u32,
    }

    unsafe extern "system" fn close_if_owned(hwnd: HWND, lparam: LPARAM) -> BOOL {
        // SAFETY: `lparam` is the `&Target` passed to EnumWindows below, alive
        // for the whole enumeration.
        let target = unsafe { &*(lparam as *const Target) };
        let mut owner: u32 = 0;
        // SAFETY: `hwnd` comes from EnumWindows; `owner` is a valid out pointer.
        unsafe { GetWindowThreadProcessId(hwnd, &mut owner) };
        if owner == target.pid {
            // SAFETY: posting to a window handle is safe even if it just died.
            unsafe { PostMessageW(hwnd, WM_CLOSE, 0, 0) };
        }
        TRUE
    }

    let target = Target { pid };
    // SAFETY: the callback only reads `target`, which outlives the call.
    unsafe { EnumWindows(Some(close_if_owned), &target as *const Target as LPARAM) };
}
```

```rust
/// Runs `lab clients ...`: asks the daemon for its status, stops the clients
/// that may be stopped, prints one line per instance. Returns the exit code.
pub fn run(args: &Args, ctx: &Ctx) -> u8 {
    let mut emit = |stream: Stream, line: String| match stream {

        Stream::Err => anstream::eprintln!("{line}"),

/// The command with its three outside effects injected: `fetch` asks the
/// daemon (called only after every usage check), `stopper` stops one pid, and
/// `emit` receives each output line as it is produced.
pub fn execute(
    args: &Args,
    ui: &Ui,
    fetch: impl FnOnce() -> Option<StatusReply>,
    stopper: &mut dyn FnMut(u32) -> Result<StopOutcome, String>,
    emit: &mut dyn FnMut(Stream, String),
) -> u8 {
    let fail = |emit: &mut dyn FnMut(Stream, String), message: &str, hint: Option<&str>| {
        for line in targets::error_lines(ui, message, hint) {
            emit(Stream::Err, line);
        }
    };
    let is_stop = args
        .verb
        .as_deref()
        .is_some_and(|verb| verb.eq_ignore_ascii_case("stop"));
    if !is_stop {
        fail(emit, targets::USAGE, None);
        return 2;
    }
    let which = args.which.as_deref();
    let all = targets::is_all(which);
    // Refused before the daemon is asked, so nothing is stopped.
    if args.force && all {
        fail(
            emit,
            targets::FORCE_NEEDS_NAME,
            Some("name the instance: lab clients stop p2 --force"),
        );
        return 2;
    }
    let Some(status) = fetch() else {
        fail(emit, targets::DAEMON_DOWN, Some("start it: lab start"));
        return 1;
    };
    if let Some(name) = which.filter(|_| !all) {
        let hosted: Vec<&str> = status.instances.iter().map(|i| i.instance.as_str()).collect();
        if !hosted.iter().any(|h| targets::same_name(h, name)) {
            let message = format!(
                "unknown instance '{name}'; the daemon hosts: {}",
                hosted.join(", ")
            );
            fail(emit, &message, None);
            return 2;
        }
    }

    let sel = targets::select_stop_targets(&status, which, args.force);
    for inst in &sel.none {
        emit(Stream::Out, targets::none_line(ui, &inst.instance));
    }
    for inst in &sel.refuse {
        emit(
            Stream::Out,
            targets::refuse_line(ui, &inst.instance, &targets::lease_who(inst)),
        );
    }
    let mut failed = 0u32;
    for inst in &sel.stop {
        let label = inst.instance.as_str();
        let Some(pid) = inst.client_pid else { continue };
        if sel.forced.iter().any(|f| targets::same_name(&f.instance, label)) {
            emit(
                Stream::Out,
                targets::forced_line(ui, label, &targets::lease_who(inst)),
            );
        }
        match stopper(pid) {
            Ok(StopOutcome::Stopped) => emit(Stream::Out, targets::stopped_line(ui, label, pid)),
            Ok(StopOutcome::NotSgw) => emit(Stream::Out, targets::not_sgw_line(ui, label, pid)),
            Ok(StopOutcome::Failed) => {
                failed += 1;
                emit(Stream::Err, targets::failed_line(ui, label, pid, None));
            }
            Err(reason) => {
                failed += 1;
                emit(Stream::Err, targets::failed_line(ui, label, pid, Some(&reason)));
            }
        }
    }
    if failed > 0 {
        4
    } else if !sel.refuse.is_empty() {
        3
    } else {
        0
    }
}
```

## Plain versus fancy output

Plain mode (`!ui.fancy`, which is every piped run and every test using
`Ui::plain()`): the exact PowerShell lines, one per instance, stdout for
progress and stderr for the usage, daemon-down, unknown-instance and
could-not-stop lines, with no `error:` prefix. Fancy mode: one line per
instance led by a glyph (`○ p3: no client`, `✗ refused p3: leased by <owner> (<purpose>)  use --force to override`,
`✓ stopped p2 (pid 1234)`, `! <label>: ... stopping anyway ...`), and stderr
messages as `error: <message>` plus a dim `hint:` line.
