## Decisions (where the packet text and the PowerShell disagree)

1. **Lease text.** The packet writes `<owner> (<purpose>) · <ago> left`;
   `status.ps1` prints `<owner> (<purpose>, <ago> left)`. The packet also
   says plain mode prints the PowerShell text and fancy mode the mock-up, so:
   plain = `claude-a1 (FS UAT, 12m left)`, fancy = `claude-a1 (FS UAT) · 12m left`.
2. **Last column name.** Plain header `SEED` with values `seeded` / `-`
   (PowerShell); fancy header `PROFILE` with `seeded` / `not seeded` (mock-up).
3. **Plain table.** `Format-Table -AutoSize | Out-String` prints a blank line,
   the header, a dash row (as long as each header), the rows, then a blank
   line; columns are separated by one space, padded to the widest cell, and
   the last column is not padded. Plain mode reproduces that, with `\n` line
   endings. An empty table prints nothing.
4. **`--json`** does not exist for `status`, `logs` or `version`.
5. **Ctrl+C under `--follow`** needs no new crate: on Windows the code declares
   `SetConsoleCtrlHandler` from `kernel32` by hand (the `windows-sys` features
   in `Cargo.toml` do not include `Win32_System_Console`, and `Cargo.toml`
   must not change). Off Windows nothing is installed (Ctrl+C ends the
   process the default way); CI never presses it.
6. **Negative `remaining_s`** prints as `0s` (the PowerShell prints `-5s`).

```rust
//! The daemon log filter behind `lab logs`: the instance and level filters,
//! continuation lines kept with their entry, and token masking.

use std::sync::OnceLock;

use regex::Regex;

/// The level words, lowest first. A line's level is its second
/// whitespace-separated field, compared ignoring case.
pub const LEVELS: [&str; 5] = ["trace", "debug", "info", "warn", "error"];

/// The rank of a level word (`trace` 0 .. `error` 4), ignoring case.
pub fn level_rank(word: &str) -> Option<u8> {
    let word = word.to_ascii_lowercase();
    LEVELS
        .iter()
        .position(|level| *level == word)
        .map(|rank| rank as u8)
}

fn entry_start() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    RE.get_or_init(|| Regex::new(r"^[0-9]{4}-[0-9]{2}-[0-9]{2}T").expect("valid regex"))
}

fn bearer() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    RE.get_or_init(|| Regex::new(r"(?i)bearer\s+\S+").expect("valid regex"))
}

fn hex64() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    RE.get_or_init(|| Regex::new(r"(?i)\b[0-9a-f]{64}\b").expect("valid regex"))
}

/// Whether `line` starts a log entry: it begins with `yyyy-MM-ddT`. Every
/// other line (a panic body, a backtrace) is a continuation line.
pub fn is_entry_start(line: &str) -> bool {
    entry_start().is_match(line)
}

/// `line` with a bearer token and any 64-hex token replaced by `<redacted>`
/// (the bearer pattern first, then the hex one).
pub fn redact(line: &str) -> String {
    let masked = bearer().replace_all(line, "<redacted>");
    hex64().replace_all(&masked, "<redacted>").into_owned()
}

/// The filter state: feed it every line of the log in order.
pub struct LogFilter {
    instance: Option<Regex>,
    min_rank: Option<u8>,
    keep: bool,
}

impl LogFilter {
    /// `instance` keeps entries that name it (`instance="x"` or
    /// `instance=Some("x")`, ignoring case, the whole name). `level` keeps
    /// entries at or above it. An empty string or an unknown level word is no
    /// filter. With no filter every line is kept, even before the first entry.
    pub fn new(instance: Option<&str>, level: Option<&str>) -> Self {
        let instance = instance.filter(|name| !name.is_empty()).map(|name| {
            let pattern = format!(r#"(?i)instance=(?:Some\()?"{}""#, regex::escape(name));
            Regex::new(&pattern).expect("escaped instance name is a valid regex")
        });
        let min_rank = level.filter(|word| !word.is_empty()).and_then(level_rank);
        // Before the first entry a continuation line has no entry to follow,
        // so with a filter on it is dropped.
        let keep = instance.is_none() && min_rank.is_none();
        Self {
            instance,
            min_rank,
            keep,
        }
    }

    /// `Some(masked line)` when `line` passes, else `None`. A line that is not
    /// an entry start is kept or dropped with the entry above it, so a level
    /// word inside a continuation line never ranks it on its own.
    pub fn accept(&mut self, line: &str) -> Option<String> {
        if is_entry_start(line) {
            self.keep = true;
            if let Some(instance) = &self.instance {
                if !instance.is_match(line) {
                    self.keep = false;
                }
            }
            if self.keep {
                if let Some(min) = self.min_rank {
                    let rank = line.split_whitespace().nth(1).and_then(level_rank);
                    match rank {
                        Some(rank) if rank >= min => {}
                        _ => self.keep = false,
                    }
                }
            }
        }
        if self.keep {
            Some(redact(line))
        } else {
            None
        }
    }
}

/// The lines of `lines` that pass the filters, masked.
pub fn filter_lines<'a>(
    lines: impl IntoIterator<Item = &'a str>,
    instance: Option<&str>,
    level: Option<&str>,
) -> Vec<String> {
    let mut filter = LogFilter::new(instance, level);
    lines
        .into_iter()
        .filter_map(|line| filter.accept(line))
        .collect()
}

/// The last `count` lines of `text` that pass the filters, masked (what a
/// plain `lab logs` prints).
pub fn tail_lines(
    text: &str,
    instance: Option<&str>,
    level: Option<&str>,
    count: usize,
) -> Vec<String> {
    let mut kept = filter_lines(text.lines(), instance, level);
    let skip = kept.len().saturating_sub(count);
    kept.drain(..skip);
    kept
}
```

/// The plain-mode column names, in the PowerShell order.
pub const COLUMNS: [&str; 6] = ["INSTANCE", "ACCOUNT", "CLIENT", "PORT", "LEASE", "SEED"];

/// The plain-mode first line when the daemon does not answer.
pub const DAEMON_DOWN: &str = "daemon: not running (or status endpoint unavailable)";

/// A duration as `12s`, `5m` or `2h 3m` (minutes and hours truncate, so 90 s
/// is `1m`). Port of `Format-Ago`.
pub fn format_ago(seconds: u64) -> String {
    if seconds < 60 {
        format!("{seconds}s")
    } else if seconds < 3600 {
        format!("{}m", seconds / 60)
    } else {
        format!("{}h {}m", seconds / 3600, (seconds % 3600) / 60)
    }
}

/// A table cell: the text, or `-` when it is missing or empty.
fn dash(value: Option<&str>) -> String {
    match value {
        Some(text) if !text.is_empty() => text.to_string(),
        _ => "-".to_string(),
    }
}

/// Seconds left on a lease: `remaining_s`, or 0 when it is missing or negative.
fn remaining_s(held: &Value) -> u64 {
    held.get("remaining_s")
        .and_then(|value| {
            value
                .as_u64()
                .or_else(|| value.as_f64().map(|seconds| seconds.max(0.0) as u64))
        })
        .unwrap_or(0)
}

/// The LEASE cell. `free` when the lease is missing or not held; `held` when
/// it is held but the daemon sent no lease object. Held: plain mode is
/// `<owner> (<purpose>, <ago> left)`, fancy mode `<owner> (<purpose>) · <ago> left`.
/// A missing owner or purpose is `-`. Never shows the lease id. Port of
/// `Get-LeaseText`.
pub fn lease_text(lease: Option<&Value>, fancy: bool) -> String {
    let Some(lease) = lease else {
        return "free".to_string();
    };
    if !lease.get("held").and_then(Value::as_bool).unwrap_or(false) {
        return "free".to_string();
    }
    let Some(held) = lease.get("lease").filter(|value| value.is_object()) else {
        return "held".to_string();
    };
    let owner = dash(held.get("owner").and_then(Value::as_str));
    let purpose = dash(held.get("purpose").and_then(Value::as_str));
    let left = format_ago(remaining_s(held));
    if fancy {
        format!("{owner} ({purpose}) · {left} left")
    } else {
        format!("{owner} ({purpose}, {left} left)")
    }
}

/// Whether the instance's profile folder exists:
/// `<root>\<label>\profile\Documents\My Games\Firesky\SGWGame`. Port of
/// `Get-SeedText`.
pub fn is_seeded(profile_root: &Path, label: &str) -> bool {
    profile_root
        .join(label)
        .join("profile")
        .join("Documents")
        .join("My Games")
        .join("Firesky")
        .join("SGWGame")
        .exists()
}

/// The instances named by labd.env's `CIMMERIA_LAB_INSTANCES` (comma list,
/// each trimmed, blanks dropped), or `default` when there are none.
pub fn instance_labels(lines: &[EnvLine]) -> Vec<String> {
    let raw = env_file::get(lines, "CIMMERIA_LAB_INSTANCES").unwrap_or("");
    let labels: Vec<String> = raw
        .split(',')
        .map(|label| label.trim().to_string())
        .filter(|label| !label.is_empty())
        .collect();
    if labels.is_empty() {
        vec!["default".to_string()]
    } else {
        labels
    }
}

/// One instance row, ready to print in either mode.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct StatusRow {
    pub instance: String,
    pub account: String,
    pub client: String,
    pub port: String,
    /// The LEASE cell in plain mode.
    pub lease_plain: String,
    /// The LEASE cell in fancy mode.
    pub lease_fancy: String,
    pub seeded: bool,
}

/// Rows from the daemon's reply, in its order.
pub fn rows_from_reply(reply: &StatusReply, profile_root: &Path) -> Vec<StatusRow> {
    reply
        .instances
        .iter()
        .map(|inst| StatusRow {
            instance: inst.instance.clone(),
            account: dash(inst.account.as_deref()),
            client: inst
                .client_pid
                .map_or_else(|| "-".to_string(), |pid| pid.to_string()),
            port: inst
                .bridge_port
                .map_or_else(|| "-".to_string(), |port| port.to_string()),
            lease_plain: lease_text(inst.lease.as_ref(), false),
            lease_fancy: lease_text(inst.lease.as_ref(), true),
            seeded: is_seeded(profile_root, &inst.instance),
        })
        .collect()
}

/// Rows for the daemon-down case: only the instance and the seed are known.
pub fn rows_from_labels(labels: &[String], profile_root: &Path) -> Vec<StatusRow> {
    labels
        .iter()
        .map(|label| StatusRow {
            instance: label.clone(),
            account: "-".to_string(),
            client: "-".to_string(),
            port: "-".to_string(),
            lease_plain: "-".to_string(),
            lease_fancy: "-".to_string(),
            seeded: is_seeded(profile_root, label),
        })
        .collect()
}

/// The first line. Plain: `daemon: pid <pid>, up <ago>, version <version>`, or
/// [`DAEMON_DOWN`]. Fancy: `lab daemon  ● running  pid <pid> · up <ago> · <version>`,
/// or `lab daemon  ○ not running  (or status endpoint unavailable)`.
pub fn daemon_line(ui: &Ui, reply: Option<&StatusReply>) -> String {
    match reply {
        Some(reply) => {
            let ago = format_ago(reply.daemon.uptime_s.unwrap_or(0));
            if ui.fancy {
                format!(
                    "{}  {} {}  pid {} · up {} · {}",
                    ui.paint(Tone::Bold, "lab daemon"),
                    ui.paint(Tone::Ok, ui.mark(Mark::Running)),
                    ui.paint(Tone::Ok, "running"),
                    reply.daemon.pid,
                    ago,
                    reply.daemon.version
                )
            } else {
                format!(
                    "daemon: pid {}, up {}, version {}",
                    reply.daemon.pid, ago, reply.daemon.version
                )
            }
        }
        None if ui.fancy => format!(
            "{}  {} {}  {}",
            ui.paint(Tone::Bold, "lab daemon"),
            ui.paint(Tone::Fail, ui.mark(Mark::Stopped)),
            ui.paint(Tone::Fail, "not running"),
            ui.paint(Tone::Dim, "(or status endpoint unavailable)")
        ),
        None => DAEMON_DOWN.to_string(),
    }
}

/// The plain table, as `Format-Table -AutoSize | Out-String` prints it: a
/// blank line, the header, a dash row, the rows, a blank line. Columns are one
/// space apart and padded to their widest cell; the last column is not padded.
/// No rows is an empty string.
pub fn plain_table(rows: &[StatusRow]) -> String {
    if rows.is_empty() {
        return String::new();
    }
    let data: Vec<[String; 6]> = rows
        .iter()
        .map(|row| {
            [
                row.instance.clone(),
                row.account.clone(),
                row.client.clone(),
                row.port.clone(),
                row.lease_plain.clone(),
                if row.seeded { "seeded" } else { "-" }.to_string(),
            ]
        })
        .collect();
    let mut widths = COLUMNS.map(str::len);
    for row in &data {
        for (i, cell) in row.iter().enumerate() {
            widths[i] = widths[i].max(cell.chars().count());
        }
    }
    let line = |cells: &[String; 6]| -> String {
        cells
            .iter()
            .enumerate()
            .map(|(i, cell)| {
                if i == 5 {
                    cell.clone()
                } else {
                    format!("{cell:<width$}", width = widths[i])
                }
            })
            .collect::<Vec<_>>()
            .join(" ")
    };
    let header = COLUMNS.map(String::from);
    let dashes = COLUMNS.map(|name| "-".repeat(name.len()));
    let mut out = String::from("\n");
    out.push_str(&line(&header));
    out.push('\n');
    out.push_str(&line(&dashes));
    out.push('\n');
    for row in &data {
        out.push_str(&line(row));
        out.push('\n');
    }
    out.push('\n');
    out
}

/// The fancy table of the mock-up: `INSTANCE ACCOUNT CLIENT PORT LEASE PROFILE`,
/// two spaces between columns, instance names cyan, `-` and `free` dim,
/// `seeded` green, `not seeded` yellow. No rows is an empty string.
pub fn fancy_table(ui: &Ui, rows: &[StatusRow]) -> String {
    if rows.is_empty() {
        return String::new();
    }
    let dim_dash = |text: &str| {
        if text == "-" {
            ui.paint(Tone::Dim, text)
        } else {
            text.to_string()
        }
    };
    let mut table = Table::new(&["Instance", "Account", "Client", "Port", "Lease", "Profile"]);
    for row in rows {
        let lease = if row.lease_fancy == "free" || row.lease_fancy == "-" {
            ui.paint(Tone::Dim, &row.lease_fancy)
        } else {
            row.lease_fancy.clone()
        };
        let profile = if row.seeded {
            ui.paint(Tone::Ok, "seeded")
        } else {
            ui.paint(Tone::Warn, "not seeded")
        };
        table.row(vec![
            ui.paint(Tone::Cmd, &row.instance),
            dim_dash(&row.account),
            dim_dash(&row.client),
            dim_dash(&row.port),
            lease,
            profile,
        ]);
    }
    table.render(ui)
}

/// The whole output and the exit code: 0 with a reply; 1 without one (the
/// `labd.env` instances are listed with the seed column only).
pub fn render(
    ui: &Ui,
    reply: Option<&StatusReply>,
    env_lines: &[EnvLine],
    profile_root: &Path,
) -> (String, u8) {
    let (rows, code) = match reply {
        Some(reply) => (rows_from_reply(reply, profile_root), 0),
        None => (
            rows_from_labels(&instance_labels(env_lines), profile_root),
            1,
        ),
    };
    let head = daemon_line(ui, reply);
    let text = if ui.fancy {
        let table = fancy_table(ui, &rows);
        if table.is_empty() {
            format!("{head}\n")
        } else {
            format!("{head}\n\n{table}")
        }
    } else {
        format!("{head}\n{}", plain_table(&rows))
    };
    (text, code)
}

/// Runs `lab status`: asks the daemon's `GET /status`, prints, exits 0 (the
/// daemon answered) or 1 (it did not).
pub fn run(args: &Args, ctx: &Ctx) -> u8 {
    let _ = args;
    let reply = status::fetch(&Endpoint::discover());

/// How often `--follow` looks at the file.
pub const POLL: Duration = Duration::from_millis(500);

/// Set by the Ctrl+C handler; `--follow` stops when it is set.
static STOP: AtomicBool = AtomicBool::new(false);

/// Ctrl+C and Ctrl+Break set [`STOP`] instead of ending the process, so
/// `--follow` can return exit code 0. Declared by hand (no extra crate).
#[cfg(windows)]
fn install_ctrl_c() {
    #[link(name = "kernel32")]
    extern "system" {
        fn SetConsoleCtrlHandler(
            handler: Option<unsafe extern "system" fn(u32) -> i32>,
            add: i32,
        ) -> i32;
    }
    unsafe extern "system" fn on_ctrl(kind: u32) -> i32 {
        // CTRL_C_EVENT is 0 and CTRL_BREAK_EVENT is 1.
        if kind == 0 || kind == 1 {
            STOP.store(true, Ordering::SeqCst);
            1
        } else {
            0
        }
    }
    // SAFETY: `on_ctrl` is a valid handler for the life of the process and
    // only stores to an atomic.
    unsafe {
        SetConsoleCtrlHandler(Some(on_ctrl), 1);
    }
}

/// Off Windows Ctrl+C ends the process the default way.
#[cfg(not(windows))]
fn install_ctrl_c() {}

/// Plain mode: the line as it is. Fancy mode: the timestamp dim and the level
/// word coloured (ERROR red, WARN yellow, INFO as is, DEBUG and TRACE dim). A
/// continuation line is never coloured.
pub fn paint_line(ui: &Ui, line: &str) -> String {
    if !ui.color || !log_filter::is_entry_start(line) {
        return line.to_string();
    }
    static RE: OnceLock<Regex> = OnceLock::new();
    let re = RE.get_or_init(|| Regex::new(r"^(\S+)(\s+)(\S+)(.*)$").expect("valid regex"));
    let Some(caps) = re.captures(line) else {
        return line.to_string();
    };
    let tone = match caps[3].to_ascii_lowercase().as_str() {
        "error" => Some(Tone::Fail),
        "warn" => Some(Tone::Warn),
        "debug" | "trace" => Some(Tone::Dim),
        _ => None,
    };
    let level = match tone {
        Some(tone) => ui.paint(tone, &caps[3]),
        None => caps[3].to_string(),
    };
    format!(
        "{}{}{}{}",
        ui.paint(Tone::Dim, &caps[1]),
        &caps[2],
        level,
        &caps[4]
    )
}

/// `lab logs --follow`: prints the last `tail` lines of the file that pass
/// `filter` (the raw tail is taken first, then filtered, so fewer can show),
/// then polls every `poll` for appended bytes and prints each new complete
/// line that passes. A file that shrinks (rotation) is read again from the
/// top. A last line without its newline is held until the newline arrives.
/// Returns `Ok` when `stop` is set; an `Err` is a failed read of the first
/// snapshot or a failed write to `out`.
pub fn follow_file(
    path: &Path,
    ui: &Ui,
    filter: &mut LogFilter,
    tail: usize,
    stop: &AtomicBool,
    poll: Duration,
    out: &mut dyn Write,
) -> io::Result<()> {
    let bytes = std::fs::read(path)?;
    let mut pos = bytes.len() as u64;
    let text = String::from_utf8_lossy(&bytes);
    let raw: Vec<&str> = text.lines().collect();
    let first = raw.len().saturating_sub(tail);
    for line in &raw[first..] {
        if let Some(kept) = filter.accept(line) {
            writeln!(out, "{}", paint_line(ui, &kept))?;
        }
    }
    out.flush()?;

    let mut pending: Vec<u8> = Vec::new();
    while !stop.load(Ordering::SeqCst) {
        std::thread::sleep(poll);
        if stop.load(Ordering::SeqCst) {
            break;
        }
        let Ok(meta) = std::fs::metadata(path) else {
            continue;
        };
        let len = meta.len();
        if len < pos {
            pos = 0;
            pending.clear();
        }
        if len == pos {
            continue;
        }
        let Ok(mut file) = File::open(path) else {
            continue;
        };
        if file.seek(SeekFrom::Start(pos)).is_err() {
            continue;
        }
        let mut chunk = Vec::new();
        if file.read_to_end(&mut chunk).is_err() {
            continue;
        }
        pos += chunk.len() as u64;
        pending.extend_from_slice(&chunk);
        while let Some(end) = pending.iter().position(|&byte| byte == b'\n') {
            let raw_line: Vec<u8> = pending.drain(..=end).collect();
            let line = String::from_utf8_lossy(&raw_line);
            let line = line.trim_end_matches(['\r', '\n']);
            if let Some(kept) = filter.accept(line) {
                writeln!(out, "{}", paint_line(ui, &kept))?;
            }
        }
        out.flush()?;
    }
    Ok(())
}

/// Runs `lab logs`. Exit 0; 1 when there is no log (plain stderr text
/// `no daemon log yet: <path>`) or it cannot be read.
pub fn run(args: &Args, ctx: &Ctx) -> u8 {
    let path = paths::labd_log_path();
    if !path.exists() {
        let message = format!("no daemon log yet: {}", path.display());
        if ctx.ui.fancy {
            ctx.ui.error(&message, Some("start the daemon: lab start"));
        } else {
            anstream::eprintln!("{message}");
        }
        return 1;
    }
    let instance = args.instance.as_deref().filter(|name| !name.is_empty());
    let level = args.level.as_deref().filter(|word| !word.is_empty());
    let count = args.lines as usize;
    let mut out = anstream::stdout().lock();

    if args.follow {
        install_ctrl_c();
        let mut filter = LogFilter::new(instance, level);
        return match follow_file(&path, &ctx.ui, &mut filter, count, &STOP, POLL, &mut out) {
            Ok(()) => 0,
            Err(err) if err.kind() == io::ErrorKind::BrokenPipe => 0,
            Err(err) => {
                ctx.ui
                    .error(&format!("cannot read {}: {err}", path.display()), None);
                1
            }
        };
    }

    let bytes = match std::fs::read(&path) {
        Ok(bytes) => bytes,
        Err(err) => {
            ctx.ui
                .error(&format!("cannot read {}: {err}", path.display()), None);
            return 1;
        }
    };
    let text = String::from_utf8_lossy(&bytes);
    for line in log_filter::tail_lines(&text, instance, level, count) {
        if writeln!(out, "{}", paint_line(&ctx.ui, &line)).is_err() {
            break;
        }
    }
    0
}

#[derive(Clone)]
struct SharedBuf(Arc<Mutex<Vec<u8>>>);

impl Write for SharedBuf {
    fn write(&mut self, bytes: &[u8]) -> std::io::Result<usize> {
        self.0.lock().expect("buf lock").extend_from_slice(bytes);
        Ok(bytes.len())
    }
    fn flush(&mut self) -> std::io::Result<()> {
        Ok(())
    }
}

struct Follow {
    stop: Arc<AtomicBool>,
    out: SharedBuf,
    handle: Option<JoinHandle<()>>,
}

impl Follow {
    fn start(path: PathBuf, instance: Option<&'static str>, level: Option<&'static str>, tail: usize) -> Self {
        let stop = Arc::new(AtomicBool::new(false));
        let out = SharedBuf(Arc::new(Mutex::new(Vec::new())));
        let handle = {
            let stop = Arc::clone(&stop);
            let mut out = out.clone();
            std::thread::spawn(move || {
                let mut filter = LogFilter::new(instance, level);
                follow_file(
                    &path,
                    &Ui::plain(),
                    &mut filter,
                    tail,
                    &stop,
                    Duration::from_millis(20),
                    &mut out,
                )
                .expect("follow_file");
            })
        };
        Follow {
            stop,
            out,
            handle: Some(handle),
        }
    }

    fn text(&self) -> String {
        String::from_utf8_lossy(&self.out.0.lock().expect("buf lock")).into_owned()
    }

    fn wait_for(&self, needle: &str) {
        for _ in 0..250 {
            if self.text().contains(needle) {
                return;
            }
            std::thread::sleep(Duration::from_millis(20));
        }
        panic!("timed out waiting for {needle:?}; saw {:?}", self.text());
    }

    /// Sets the stop flag (what Ctrl+C does) and returns the final output.
    fn finish(mut self) -> String {
        self.stop.store(true, Ordering::SeqCst);
        self.handle.take().expect("handle").join().expect("follow thread");
        self.text()
    }
}

fn append(path: &std::path::Path, text: &str) {
    let mut file = std::fs::OpenOptions::new()
        .append(true)
        .open(path)
        .expect("open log");
    file.write_all(text.as_bytes()).expect("append");
}
