## What this packet does, and where it differs from the packet text

Without `--once` and `--json`, when stdout is a terminal, `lab watch` loops: alternate
screen, hidden cursor, a redraw every `--interval-seconds`, quit on `q`, `Esc` or Ctrl+C,
and the screen and cursor always restored. A redirected stdout still prints one snapshot
(LX-13's code path, untouched).

Decided here (the coordinator should reconcile the packet):

1. **One extra file**, `commands/watch/frame.rs`: the pure frame renderer. The packet
   names only `live.rs` and `mod.rs`; the renderer and its tests would push `live.rs`
   past the 500-line soft cap, and "pure fn in its own file" is what the tests need.
2. **The live view runs when stdout is a terminal** (`IsTerminal`), not when
   `ctx.ui.fancy` is true. A terminal with `NO_COLOR` set still gets the live view,
   without colour or glyphs (the frame uses `#` and `-` for the bar then). A redirected
   stdout prints one snapshot, as LX-13 does.
3. **A title line above the frame**, composed by `live.rs` (the pure frame has no clock):
   `lab watch  HH:MM:SS  every 2s  q to quit`. The frame is cut to `height - 1` lines so
   title plus frame fit in the window with the last row free (the PowerShell view did the
   same: a full-height frame scrolls the alternate screen).
4. **Width** is the terminal's columns less one (a full-width line wraps on some hosts),
   or 120 when the terminal is narrower than 41 columns or its size cannot be read. This
   is LX-13's `frame_width` rule, measured every tick so a resize is picked up.
5. **Keys are optional.** If raw mode cannot be enabled (stdin redirected), the view still
   draws and waits by sleeping; only Ctrl+C from the shell ends it then, and the guard
   still restores the screen on the way out where Rust gets control. The guide already
   says this.
6. **Escape sequences are written with `crossterm::Command::write_ansi`**, not
   `execute!`, so the bytes are the same on every OS and a test can capture them in a
   `Vec<u8>`. On Windows, `execute!` is what switches virtual-terminal output on, so the
   loop makes one throwaway `execute!(stdout, ResetColor)` call first (step 2). That
   Windows detail is only proven by a real console: LX-20's live check covers it.
7. **One bad tick is shown, not fatal**: a snapshot error becomes a red `error: <first
   line>` under the title, lease ids hidden, and the loop goes on.

## Step 1: `commands/watch/frame.rs` (new)

The frame as a pure function: no clock, no terminal, no I/O. Layout, top to bottom:

1. Header: a glyph, the batch name (bold), the section, the state word. States colour as
   `live` green, `done` default, `interrupted` red, `unknown` dim. Without a batch:
   `no batch`, and `  daemon down` in red when the daemon is down.
2. Progress line: `███████░░░░ 4/6  passed 3  failed 1 (1 known)`. The bar is
   `bar_width(width)` cells wide: a quarter of the width, at least 10, at most 40. Filled
   cells are `runs * bar_width / total` (integer, capped at the bar width, 0 when `total`
   is 0). Without a plan total the bar is left out: `4 runs  passed 3  failed 1`.
3. A blank line, then the instance table (INSTANCE, CLIENT, LEASE, RUN, ROW, SHOT) with
   each lane's last progress line indented four spaces under its row. No table when
   `instances` is empty.
4. A blank line, then the last failure: `✗ last failure  default#2  [#1343]  FS-01 BLOCKED: ...`
   (the issue tag sits before the reason so a narrow window cuts the reason, not the tag).
5. A blank line, then the footer, the same words as the plain text frame: `orphan
   SGW.exe: 1, 2, 3 +2 (#1342?)`, `relaunches: p2 1`, `login retries: 2 (#1343)` joined by
   two spaces on one line; then, as separate lines, `daemon has no run progress: lab
   install, then lab restart` (old daemon) and `daemon down: showing the batch files only`
   (daemon down with a batch), both yellow.
6. Every line goes through `hide_lease_ids`, then is cut to the width (`…` and a colour
   reset when it is cut). If the frame has more than `height - 1` lines (`height >= 2`),
   it keeps `height - 2` lines and ends with `… <n> more lines` (dim), where `n` is the
   number of lines that were hidden plus the one the marker replaced. `height` 0 or 1
   means unknown: no cut.

Write exactly this:

```rust
//! The fancy frame of `lab watch`'s live view: a pure function of the snapshot,
//! so tests can check every line without a terminal.

use crate::daemon::mcp::hide_lease_ids;
use crate::ui::table::Table;
use crate::ui::{skip_escape, visible_width, Mark, Tone, Ui};

use super::snapshot::{BatchState, BatchView, Snapshot};

/// The narrowest and widest progress bar, in cells.
const NARROWEST_BAR: usize = 10;
const WIDEST_BAR: usize = 40;

/// The frame as lines, each at most `width` visible columns. `height` is the
/// rows this frame may use (0 or 1: unknown, no cut). A frame that is too tall
/// is cut and ends with `… <n> more lines`.
pub fn render_frame(snapshot: &Snapshot, width: usize, height: usize, ui: &Ui) -> Vec<String> {
    let mut lines = vec![header_line(snapshot, ui)];
    if let Some(batch) = &snapshot.batch {
        lines.push(progress_line(batch, width, ui));
    }
    let table = instance_lines(snapshot, width, ui);
    if !table.is_empty() {
        lines.push(String::new());
        lines.extend(table);
    }
    if let Some(line) = failure_line(snapshot, ui) {
        lines.push(String::new());
        lines.push(line);
    }
    let footer = footer_lines(snapshot, ui);
    if !footer.is_empty() {
        lines.push(String::new());
        lines.extend(footer);
    }
    finish(lines, width, height, ui)
}

/// Hides lease ids, cuts every line to `width`, and cuts the frame to `height`.
fn finish(lines: Vec<String>, width: usize, height: usize, ui: &Ui) -> Vec<String> {
    let mut out: Vec<String> = lines
        .iter()
        .map(|line| fit_line(&hide_lease_ids(line), width))
        .collect();
    if height >= 2 && out.len() > height - 1 {
        let keep = height - 2; // the marker line takes the last kept row
        let hidden = out.len() - keep;
        out.truncate(keep);
        let marker = ui.paint(Tone::Dim, &format!("… {hidden} more lines"));
        out.push(fit_line(&marker, width));
    }
    out
}

/// `line` cut to `width` visible columns, ending in `…` (and a colour reset when
/// the line was painted) when it is cut.
pub fn fit_line(line: &str, width: usize) -> String {
    if visible_width(line) <= width {
        return line.to_string();
    }
    if width == 0 {
        return String::new();
    }
    let keep = width - 1;
    let mut out = String::new();
    let mut visible = 0;
    let mut styled = false;
    let mut chars = line.chars();
    while let Some(c) = chars.next() {
        if c == '\x1b' {
            styled = true;
            out.push(c);
            out.push_str(&skip_escape(&mut chars));
        } else if visible < keep {
            out.push(c);
            visible += 1;
        } else {
            break;
        }
    }
    out.push('…');
    if styled {
        out.push_str("\x1b[0m");
    }
    out
}

/// A glyph and a space, painted; empty when glyphs are off.
fn glyph(ui: &Ui, mark: Mark, tone: Tone) -> String {
    let g = ui.mark(mark);
    if g.is_empty() {
        String::new()
    } else {
        format!("{} ", ui.paint(tone, g))
    }
}

fn header_line(snapshot: &Snapshot, ui: &Ui) -> String {
    let Some(batch) = &snapshot.batch else {
        let mut line = "no batch".to_string();
        if !snapshot.daemon_up {
            line.push_str("  ");
            line.push_str(&ui.paint(Tone::Fail, "daemon down"));
        }
        return line;
    };
    let (mark, mark_tone, word_tone) = match batch.state {
        BatchState::Live => (Mark::Active, Tone::Cmd, Some(Tone::Ok)),
        BatchState::Done => (Mark::Pass, Tone::Ok, None),
        BatchState::Interrupted => (Mark::Fail, Tone::Fail, Some(Tone::Fail)),
        BatchState::Unknown => (Mark::Warn, Tone::Warn, Some(Tone::Dim)),
    };
    let word = batch.state.as_str();
    let word = match word_tone {
        Some(tone) => ui.paint(tone, word),
        None => word.to_string(),
    };
    let mut parts = vec![ui.paint(Tone::Bold, &batch.name)];
    if let Some(section) = &batch.section {
        parts.push(section.clone());
    }
    parts.push(word);
    format!("{}{}", glyph(ui, mark, mark_tone), parts.join("  "))
}

/// The progress bar's width in cells for a frame `width` columns wide.
pub fn bar_width(width: usize) -> usize {
    (width / 4).clamp(NARROWEST_BAR, WIDEST_BAR)
}

/// Filled cells of a bar `width` cells wide after `runs` of `total` runs:
/// `runs * width / total`, never above `width`; 0 when `total` is 0.
pub fn bar_cells(runs: u32, total: u32, width: usize) -> usize {
    if total == 0 {
        return 0;
    }
    let done = u64::from(runs.min(total));
    let cells = done * u64::try_from(width).unwrap_or(u64::MAX) / u64::from(total);
    usize::try_from(cells).unwrap_or(width).min(width)
}

fn progress_line(batch: &BatchView, width: usize, ui: &Ui) -> String {
    let head = match batch.total {
        Some(total) if total > 0 => {
            let cells = bar_width(width);
            let filled = bar_cells(batch.runs, total, cells);
            let (full, empty) = if ui.fancy { ('█', '░') } else { ('#', '-') };
            format!(
                "{}{} {}",
                ui.paint(Tone::Ok, &full.to_string().repeat(filled)),
                ui.paint(Tone::Dim, &empty.to_string().repeat(cells - filled)),
                batch.runs_text()
            )
        }
        _ => format!("{} runs", batch.runs),
    };
    let passed = format!("passed {}", batch.passed);
    let passed = if batch.passed > 0 {
        ui.paint(Tone::Ok, &passed)
    } else {
        passed
    };
    let mut failed = format!("failed {}", batch.failed);
    if batch.failed > 0 {
        failed = ui.paint(Tone::Fail, &failed);
    }
    if batch.known > 0 {
        failed.push_str(&ui.paint(Tone::Dim, &format!(" ({} known)", batch.known)));
    }
    format!("{head}  {passed}  {failed}")
}

/// The table header, each instance's row, and under a row its lane's last
/// progress line (indented four spaces). Empty without instances.
fn instance_lines(snapshot: &Snapshot, width: usize, ui: &Ui) -> Vec<String> {
    if snapshot.instances.is_empty() {
        return Vec::new();
    }
    let mut table = Table::new(&["INSTANCE", "CLIENT", "LEASE", "RUN", "ROW", "SHOT"]);
    for i in &snapshot.instances {
        let client = i
            .client_pid
            .map_or_else(|| "-".to_string(), |pid| pid.to_string());
        let lease = match i.lease.as_deref().filter(|l| !l.is_empty()) {
            Some("free") | None => ui.paint(Tone::Dim, i.lease.as_deref().unwrap_or("-")),
            Some(text) => text.to_string(),
        };
        let run = if i.run.contains("braked") {
            ui.paint(Tone::Fail, &i.run)
        } else {
            i.run.clone()
        };
        let shot = i.shot_s.map_or_else(|| "-".to_string(), |s| format!("{s}s"));
        table.row(vec![
            ui.paint(Tone::Cmd, &i.instance),
            client,
            lease,
            run,
            i.row_cell(),
            shot,
        ]);
    }
    let sized = Ui {
        width: Some(width),
        ..*ui
    };
    let text = table.render(&sized);
    let mut rendered = text.lines();
    let mut out = Vec::new();
    if let Some(header) = rendered.next() {
        out.push(header.to_string());
    }
    for (line, instance) in rendered.zip(&snapshot.instances) {
        out.push(line.to_string());
        if let Some(last) = instance.last.as_deref().filter(|l| !l.is_empty()) {
            out.push(format!("    {}", ui.paint(Tone::Dim, last)));
        }
    }
    out
}

fn failure_line(snapshot: &Snapshot, ui: &Ui) -> Option<String> {
    let last = snapshot.batch.as_ref()?.last_failure.as_ref()?;
    let issue = last
        .issue
        .as_ref()
        .map(|tag| format!("{}  ", ui.paint(Tone::Warn, &format!("[{tag}]"))))
        .unwrap_or_default();
    Some(format!(
        "{}{}  {}  {}{}",
        glyph(ui, Mark::Fail, Tone::Fail),
        ui.paint(Tone::Dim, "last failure"),
        last.run,
        issue,
        last.why
    ))
}

fn footer_lines(snapshot: &Snapshot, ui: &Ui) -> Vec<String> {
    let mut parts: Vec<String> = Vec::new();
    if !snapshot.orphans.is_empty() {
        let shown: Vec<String> = snapshot
            .orphans
            .iter()
            .take(3)
            .map(|p| p.to_string())
            .collect();
        let more = if snapshot.orphans.len() > 3 {
            format!(" +{}", snapshot.orphans.len() - 3)
        } else {
            String::new()
        };
        parts.push(format!("orphan SGW.exe: {}{more} (#1342?)", shown.join(", ")));
    }
    if let Some(logs) = &snapshot.logs {
        if !logs.relaunches.is_empty() {
            let each: Vec<String> = logs
                .relaunches
                .iter()
                .map(|(name, count)| format!("{name} {count}"))
                .collect();
            parts.push(format!("relaunches: {}", each.join(", ")));
        }
        if logs.login_retries > 0 {
            parts.push(format!("login retries: {} (#1343)", logs.login_retries));
        }
    }
    let mut lines = Vec::new();
    if !parts.is_empty() {
        lines.push(ui.paint(Tone::Dim, &parts.join("  ")));
    }
    if snapshot.old_daemon {
        lines.push(ui.paint(
            Tone::Warn,
            "daemon has no run progress: lab install, then lab restart",
        ));
    }
    if !snapshot.daemon_up && snapshot.batch.is_some() {
        lines.push(ui.paint(Tone::Warn, "daemon down: showing the batch files only"));
    }
    lines
}
```

## Step 2: `commands/watch/live.rs` (new)

The terminal part: raw mode, the guard, key reading, the loop. Behaviour:

- `ScreenGuard<W: Write>` writes `\x1b[?1049h\x1b[?25l` (enter the alternate screen, hide
  the cursor) when created and `\x1b[?25h\x1b[?1049l` (show the cursor, leave the screen)
  when dropped, after switching raw mode off if it switched it on. Drop runs on a normal
  exit, an early return and a panic.
- `encode_frame(lines)`: cursor to the top-left (`\x1b[1;1H`), every line followed by
  erase-to-end-of-line and `\r\n` (`\x1b[K\r\n`), then erase-below (`\x1b[J`), so a shorter
  frame leaves nothing behind.
- `is_quit(&Event)`: `q`, `Q`, `Esc` (key presses only, not releases), and Ctrl+C.
  In raw mode Ctrl+C arrives as a key event, not a signal.
- `run_live` returns 0 on quit; 3 if the terminal cannot be written to.

```rust
//! The live view of `lab watch`: alternate screen, hidden cursor, a redraw
//! every interval, quit on `q`, `Esc` or Ctrl+C, and the screen always put back.

use std::io::{self, Write};
use std::path::PathBuf;
use std::time::{Duration, Instant};

use chrono::Local;
use crossterm::cursor::{Hide, MoveTo, Show};
use crossterm::event::{self, Event, KeyCode, KeyEventKind, KeyModifiers};
use crossterm::terminal::{
    self, Clear, ClearType, EnterAlternateScreen, LeaveAlternateScreen,
};
use crossterm::Command;

use crate::daemon::mcp::hide_lease_ids;
use crate::ui::{Tone, Ui};

use super::frame::{fit_line, render_frame};
use super::{take_snapshot, Args};

/// How long one wait for a key lasts; also the sleep step without keys.
const TICK: Duration = Duration::from_millis(100);

/// The ANSI bytes of a crossterm command, the same on every OS.
fn ansi(command: impl Command) -> String {
    let mut text = String::new();
    command
        .write_ansi(&mut text)
        .expect("writing to a String cannot fail");
    text
}

/// Enters the alternate screen with the cursor hidden; puts both back on drop.
pub struct ScreenGuard<W: Write> {
    out: W,
    /// Whether this guard's owner switched raw mode on, so drop switches it off.
    raw: bool,
}

impl<W: Write> ScreenGuard<W> {
    /// Writes the enter sequence. `raw` says raw mode is on and is to be
    /// switched off on drop. If the write fails the guard is dropped on the way
    /// out, so the screen and raw mode are restored.
    pub fn enter(out: W, raw: bool) -> io::Result<Self> {
        let mut guard = Self { out, raw };
        let seq = format!("{}{}", ansi(EnterAlternateScreen), ansi(Hide));
        guard.out.write_all(seq.as_bytes())?;
        guard.out.flush()?;
        Ok(guard)
    }

    /// Draws one frame over the previous one.
    pub fn draw(&mut self, lines: &[String]) -> io::Result<()> {
        self.out.write_all(encode_frame(lines).as_bytes())?;
        self.out.flush()
    }
}

impl<W: Write> Drop for ScreenGuard<W> {
    fn drop(&mut self) {
        // Raw mode first: a write to a closed console must not leave the parent
        // shell without its line editing.
        if self.raw {
            let _ = terminal::disable_raw_mode();
        }
        let seq = format!("{}{}", ansi(Show), ansi(LeaveAlternateScreen));
        let _ = self.out.write_all(seq.as_bytes());
        let _ = self.out.flush();
    }
}

/// One frame as terminal bytes: home, each line then erase-to-end-of-line and
/// CRLF (raw mode does not translate `\n`), then erase below.
pub fn encode_frame(lines: &[String]) -> String {
    let mut out = ansi(MoveTo(0, 0));
    let erase_line = ansi(Clear(ClearType::UntilNewLine));
    for line in lines {
        out.push_str(line);
        out.push_str(&erase_line);
        out.push_str("\r\n");
    }
    out.push_str(&ansi(Clear(ClearType::FromCursorDown)));
    out
}

/// Whether this event asks to quit: `q`, `Esc`, or Ctrl+C (key presses only).
pub fn is_quit(event: &Event) -> bool {
    let Event::Key(key) = event else {
        return false;
    };
    if key.kind != KeyEventKind::Press {
        return false;
    }
    let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
    match key.code {
        KeyCode::Esc => true,
        KeyCode::Char(c) => {
            (!ctrl && c.eq_ignore_ascii_case(&'q')) || (ctrl && c.eq_ignore_ascii_case(&'c'))
        }
        _ => false,
    }
}

/// The frame width for a terminal `columns` wide: one less (a full-width line
/// wraps on some hosts), or 120 when the terminal is narrower than 41 columns
/// or its size is unknown (0).
pub fn live_width(columns: u16) -> usize {
    if columns >= 41 {
        usize::from(columns) - 1
    } else {
        120
    }
}

/// The line above the frame.
pub fn title_line(clock: &str, interval_seconds: u32, ui: &Ui) -> String {
    ui.paint(
        Tone::Dim,
        &format!("lab watch  {clock}  every {interval_seconds}s  q to quit"),
    )
}

/// One tick's lines: the title, then the frame (cut to the rows left under the
/// title) or, when the snapshot cannot be read, one red error line.
fn compose(args: &Args, batch_dir: &Option<PathBuf>, ui: &Ui, columns: u16, rows: u16) -> Vec<String> {
    let width = live_width(columns);
    let clock = Local::now().format("%H:%M:%S").to_string();
    let mut lines = vec![fit_line(&title_line(&clock, args.interval_seconds, ui), width)];
    match take_snapshot(args, batch_dir.clone()) {
        Ok(snapshot) => {
            let height = usize::from(rows).saturating_sub(1);
            lines.extend(render_frame(&snapshot, width, height, ui));
        }
        Err(why) => {
            // One bad tick (a file mid-write, a daemon restart) is shown, not fatal.
            let first = why.lines().next().unwrap_or("");
            let text = format!("error: {}", hide_lease_ids(first));
            lines.push(fit_line(&ui.paint(Tone::Fail, &text), width));
        }
    }
    lines
}

/// Waits one interval; true when a quit key was pressed. Without keys (raw mode
/// unavailable) it only sleeps.
fn wait_tick(interval: Duration, keys: bool) -> bool {
    let until = Instant::now() + interval;
    while Instant::now() < until {
        if !keys {
            std::thread::sleep(TICK);
            continue;
        }
        match event::poll(TICK) {
            Ok(true) => {
                if event::read().is_ok_and(|event| is_quit(&event)) {
                    return true;
                }
            }
            Ok(false) => {}
            Err(_) => std::thread::sleep(TICK),
        }
    }
    false
}

/// Runs the live view until `q`, `Esc` or Ctrl+C. Returns 0, or 3 when the
/// terminal cannot be written to. `batch_dir` is `--batch`, already checked.
pub fn run_live(args: &Args, ui: &Ui, batch_dir: Option<PathBuf>) -> u8 {
    let interval = Duration::from_secs(u64::from(args.interval_seconds));
    // On Windows, execute! switches virtual-terminal output on as a side effect
    // (the guard writes raw ANSI); on other systems it does nothing of note.
    let _ = crossterm::execute!(io::stdout(), crossterm::style::ResetColor);
    let raw = terminal::enable_raw_mode().is_ok();
    let mut guard = match ScreenGuard::enter(io::stdout(), raw) {
        Ok(guard) => guard,
        Err(_) => return 3,
    };
    loop {
        let (columns, rows) = terminal::size().unwrap_or((0, 0));
        let lines = compose(args, &batch_dir, ui, columns, rows);
        if guard.draw(&lines).is_err() {
            return 3; // the guard restores on drop
        }
        if wait_tick(interval, raw) {
            return 0;
        }
    }
}
```
