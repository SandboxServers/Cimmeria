## Decisions made here (the coordinator should reconcile the packet text)

1. **`changed` order.** The daemon's JSON object has no guaranteed key order
   and this crate's `serde_json` has no `preserve_order`, so the fields of
   `changed` print in one fixed order: `radius_m`, `bearing_deg`, `dy_m`,
   `pitch_deg`, `yaw_offset_deg`, `zoom`, then any other key alphabetically.
   The PowerShell printed them in the order the daemon sent. The one check
   where that shows (`guard`, zoom and yaw) has its expected text changed
   below.
2. **Flag names in messages.** The PowerShell messages say `-Apply`,
   `-BudgetMinutes`; the Rust ones say `--apply`, `--budget-minutes`
   (everything else byte for byte).
3. **Repo root.** The PowerShell used the checkout the script sat in. `lab.exe`
   may be installed elsewhere, so the repo root is the checkout that
   `paths::default_specs_dir()` finds (`<repo>/docs/guides/uat-specs`, three
   levels up). With none found, `--apply` is refused (exit 2) and the final
   hint omits `git -C`.
4. **Heal closures.** The call closure returns `Result<Value, McpError>` (so
   LX-17 wraps `McpClient::call_tool`); the lease-wait closure returns `bool`
   (the PowerShell's "wait that throws" case does not exist).
5. **`sgw_pids`.** LX-12 depends only on LX-02 to LX-05, so it carries its own
   small `sgw_pids()` in `calibrate/preflight.rs` (a copy of LX-08's
   `commands/doctor/system.rs` one). Merging the two copies is a later cleanup;
   do not import LX-08's.
6. **Typed clap arguments.** `calibrate::Args` (LX-02b) is unchanged: section
   and row are `Option<String>`, `budget_minutes` is `Option<u32>`, so
   `--budget-minutes -1` is a clap usage error (exit 2) and 0 or 31 reach our
   own check (exit 2 as well).

## What the daemon returns (read once)

`lab_uat_calibrate` replies `{ "run_dir": "...", "outcomes": [{ "ok": bool,
"section", "row", "pose": "frost", "score": 8312, "confirmed": 3, "changed":
{ "bearing_deg": [322.5, 330.0], "zoom": ["none", 250.0] }, "diff_path":
"...\\first-session.diff", "probes": 41, "reason": "..." }] ]`. `score`,
`changed`, `diff_path` and `reason` may be absent. `changed` holds only the
fields that differ, as `[old, new]`, with the string `"none"` for an unset
value. `diff_path` is on the first outcome that proposed (one diff carries
every proposal). `lab_uat_run` replies `{ "rows": [{ "row", "result",
"reasons": [...] }] }`.

//! What `lab_uat_calibrate` answers and how `lab calibrate` shows it: the
//! typed outcome, the plain-mode line, the `--json` objects (key order and
//! size budgets of the PowerShell), the exit code, the argument checks.
//!

use std::time::Duration;

use serde::ser::{SerializeMap, Serializer};
use serde::Serialize;
use serde_json::Value;

use crate::daemon::mcp::{hide_lease_ids, McpError};

/// The sweep confirms its winner this many times (`confirmed 3/3`).
pub const CONFIRM_RUNS: i64 = 3;
/// The largest `--budget-minutes`.
pub const MAX_BUDGET: u32 = 30;
/// The `--json` object of a failed `--apply` stays within this many characters.
pub const APPLY_ERROR_MAX: usize = 700;

/// The usage line (exit 2 when the section or the row is missing).
pub const USAGE: &str = "usage: lab calibrate <section> <row> [--pose <id>] [--instance <name>] [--prepare <row ids>] [--budget-minutes 1-30] [--apply] [--json] [--quiet]";

/// Print order of a pose's changed fields (the spec's pose-line order); any
/// other field follows, alphabetically.
const FIELD_ORDER: [&str; 6] = [
    "radius_m",
    "bearing_deg",
    "dy_m",
    "pitch_deg",
    "yaw_offset_deg",
    "zoom",
];

/// One pose's result from `lab_uat_calibrate`.
#[derive(Debug, Clone, PartialEq)]
pub struct Outcome {
    pub ok: bool,
    pub pose: String,
    pub score: Option<f64>,
    pub confirmed: i64,
    /// `(field, old, new)` in [`FIELD_ORDER`]; a value is a number or the
    /// string `"none"`.
    pub changed: Vec<(String, Value, Value)>,
    /// Empty when this outcome proposed nothing or the tool named no file.
    pub diff_path: String,
    pub reason: String,
}

impl Outcome {
    /// Reads one element of the reply's `outcomes`. Missing fields are empty,
    /// `false` or `0` (the PowerShell's `Get-UatField` returns `$null`).
    pub fn from_value(v: &Value) -> Outcome {
        let text = |key: &str| {
            v.get(key)
                .and_then(Value::as_str)
                .unwrap_or("")
                .to_string()
        };
        Outcome {
            ok: v.get("ok").and_then(Value::as_bool).unwrap_or(false),
            pose: text("pose"),
            score: v.get("score").and_then(Value::as_f64),
            confirmed: v
                .get("confirmed")
                .and_then(Value::as_f64)
                .map_or(0, |c| c.round() as i64),
            changed: changes_from(v.get("changed")),
            diff_path: text("diff_path"),
            reason: text("reason"),
        }
    }
}

/// The `changed` object as `(field, old, new)`, sorted by [`FIELD_ORDER`].
/// An entry that is not a two-element array is skipped.
fn changes_from(changed: Option<&Value>) -> Vec<(String, Value, Value)> {
    let Some(map) = changed.and_then(Value::as_object) else {
        return Vec::new();
    };
    let mut out: Vec<(String, Value, Value)> = map
        .iter()
        .filter_map(|(name, pair)| {
            let pair = pair.as_array()?;
            if pair.len() != 2 {
                return None;
            }
            Some((name.clone(), pair[0].clone(), pair[1].clone()))
        })
        .collect();
    out.sort_by_key(|(name, _, _)| {
        let rank = FIELD_ORDER
            .iter()
            .position(|f| f == name)
            .unwrap_or(FIELD_ORDER.len());
        (rank, name.clone())
    });
    out
}

/// The outcomes of a `lab_uat_calibrate` reply (none when the key is absent).
pub fn outcomes_from(reply: &Value) -> Vec<Outcome> {
    reply
        .get("outcomes")
        .and_then(Value::as_array)
        .map(|rows| {
            rows.iter()
                .filter(|v| !v.is_null())
                .map(Outcome::from_value)
                .collect()
        })
        .unwrap_or_default()
}

/// The argument checks that need no daemon: an error message, or `None`.
/// An empty section or row counts as missing.
pub fn check_arguments(section: &str, row: &str, budget: Option<u32>) -> Option<String> {
    if section.is_empty() || row.is_empty() {
        return Some(USAGE.to_string());
    }
    if let Some(b) = budget {
        if !(1..=MAX_BUDGET).contains(&b) {
            return Some(format!("--budget-minutes must be 1 to {MAX_BUDGET}"));
        }
    }
    None
}

/// A changed field's short name: `bearing_deg` becomes `bearing`.
pub fn field_label(name: &str) -> &str {
    match name {
        "radius_m" => "radius",
        "bearing_deg" => "bearing",
        "pitch_deg" => "pitch",
        "yaw_offset_deg" => "yaw",
        other => other,
    }
}

/// One value of a changed pair: a number with at least one and at most three
/// decimals (`330.0`, `3.75`), or the tool's `"none"` for an unset field.
pub fn format_value(v: &Value) -> String {
    match v {
        Value::String(s) => s.clone(),
        Value::Number(n) => {
            let x = n.as_f64().unwrap_or(0.0);
            let fixed = format!("{x:.3}");
            let trimmed = fixed.trim_end_matches('0');
            if trimmed.ends_with('.') {
                format!("{trimmed}0")
            } else {
                trimmed.to_string()
            }
        }
        _ => "none".to_string(),
    }
}

/// A score as the PowerShell prints it: `8312`, not `8312.0`.
pub fn score_text(score: f64) -> String {
    if score.fract() == 0.0 && score.abs() < 1e15 {
        format!("{}", score as i64)
    } else {
        format!("{score}")
    }
}

/// The changed fields as `(label, "old -> new")`, in print order.
pub fn changes(o: &Outcome) -> Vec<(String, String)> {
    o.changed
        .iter()
        .map(|(name, old, new)| {
            (
                field_label(name).to_string(),
                format!("{} -> {}", format_value(old), format_value(new)),
            )
        })
        .collect()
}

/// The plain line printed for a pose:
///
/// ```text
/// frost: score 8312, confirmed 3/3, bearing 322.5 -> 330.0; diff <path>
/// frost: score 8312, confirmed 3/3, unchanged; diff <path>
/// frost: no proposal: <reason> (best score 5100, confirmed 1/3)
/// ```
pub fn format_line(o: &Outcome) -> String {
    let confirmed = format!("confirmed {}/{CONFIRM_RUNS}", o.confirmed);
    let reason = hide_lease_ids(&o.reason);
    if !o.ok {
        let mut line = format!("{}: no proposal", o.pose);
        if !reason.is_empty() {
            line.push_str(&format!(": {reason}"));
        }
        if let Some(score) = o.score {
            line.push_str(&format!(" (best score {}, {confirmed})", score_text(score)));
        }
        return line;
    }
    let mut parts: Vec<String> = Vec::new();
    if let Some(score) = o.score {
        parts.push(format!("score {}", score_text(score)));
    }
    parts.push(confirmed);
    let changes = changes(o);
    if changes.is_empty() {
        parts.push("unchanged".to_string());
    } else {
        for (label, text) in &changes {
            parts.push(format!("{label} {text}"));
        }
    }
    let mut line = format!("{}: {}", o.pose, parts.join(", "));
    if !reason.is_empty() {
        line.push_str(&format!(" ({reason})"));
    }
    if !o.diff_path.is_empty() {
        line.push_str(&format!("; diff {}", o.diff_path));
    }
    line
}

/// 0 when every pose has a proposal (or is unchanged); 1 when a pose found
/// none, or there were no outcomes.
pub fn exit_code(outcomes: &[Outcome]) -> u8 {
    if outcomes.is_empty() || outcomes.iter().any(|o| !o.ok) {
        1
    } else {
        0
    }
}

/// Text cut to `max` characters, ending `...` when cut.
pub fn limit_text(text: &str, max: usize) -> String {
    if text.chars().count() <= max {
        return text.to_string();
    }
    let head: String = text.chars().take(max.saturating_sub(3)).collect();
    format!("{head}...")
}

/// Each run of CR and LF characters becomes one space.
fn collapse_newlines(text: &str) -> String {
    let mut out = String::new();
    let mut in_run = false;
    for c in text.chars() {
        if c == '\r' || c == '\n' {
            if !in_run {
                out.push(' ');
            }
            in_run = true;
        } else {
            in_run = false;
            out.push(c);
        }
    }
    out
}

/// The seconds a calibrate call may take: the budget (15 by default) plus

    (u64::from(budget.unwrap_or(15)) + 5) * 60
}

/// [`timeout_secs`] as a `Duration`.
pub fn timeout(budget: Option<u32>) -> Duration {

/// A failed `lab_uat_calibrate` call as one line, named once: the first line
/// of the message, lease ids hidden, `lab_uat_calibrate failed: ` in front
/// unless the message already starts with the tool's name.
pub fn format_call_error(message: &str) -> String {

        .split('\n')
        .next()
        .unwrap_or("")
        .trim_end_matches('\r');
    let m = hide_lease_ids(first);
    if m.starts_with("lab_uat_calibrate") {
        m
    } else {
        format!("lab_uat_calibrate failed: {m}")
    }
}

/// `{ "bearing": "322.5 -> 330.0" }`: a map in the order given.
#[derive(Debug, Clone)]
struct Changed(Vec<(String, String)>);

impl Serialize for Changed {
    fn serialize<S: Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        let mut map = serializer.serialize_map(Some(self.0.len()))?;
        for (label, text) in &self.0 {
            map.serialize_entry(label, text)?;
        }
        map.end()
    }
}

/// The `--json` entries of the outcomes: `{ pose, ok, score, confirmed,
/// changed, diff, reason }`, `diff` only when `with_diff`, a reason cut to 40
/// characters (the full text is on the human line).
fn compact_outcomes(outcomes: &[Outcome], with_diff: bool) -> Vec<JsonOutcome> {
    outcomes
        .iter()
        .map(|o| {
            let changes = changes(o);
            let reason = hide_lease_ids(&o.reason);
            JsonOutcome {
                pose: o.pose.clone(),
                ok: o.ok,
                score: o.score.map(|s| s.round() as i64),
                confirmed: o.confirmed,
                changed: if changes.is_empty() {
                    None
                } else {
                    Some(Changed(changes))
                },
                diff: if with_diff && !o.diff_path.is_empty() {
                    Some(o.diff_path.clone())
                } else {
                    None
                },
                reason: if reason.is_empty() {
                    None
                } else {
                    Some(limit_text(&collapse_newlines(&reason), 40))
                },
            }
        })
        .collect()
}

#[derive(Serialize)]
struct CompactReply<'a> {
    ok: bool,
    section: &'a str,
    row: &'a str,
    #[serde(skip_serializing_if = "Option::is_none")]
    outcomes: Option<Vec<JsonOutcome>>,
    #[serde(skip_serializing_if = "Option::is_none")]
    applied: Option<bool>,
}

fn to_json<T: Serialize>(value: &T) -> String {
    serde_json::to_string(value).expect("a plain struct serialises")
}

/// The `--json` object: `{ok, section, row, outcomes, applied}` on one line,
/// no nulls and no empty arrays (`outcomes` only when there are some,
/// `applied` only when true). `ok` is "every pose proposed or unchanged".
pub fn compact_json(section: &str, row: &str, outcomes: &[Outcome], applied: bool) -> String {
    let entries = compact_outcomes(outcomes, true);
    to_json(&CompactReply {
        ok: exit_code(outcomes) == 0,
        section,
        row,
        outcomes: if entries.is_empty() { None } else { Some(entries) },
        applied: if applied { Some(true) } else { None },
    })
}

#[derive(Serialize)]
struct StopJson {

    exit: u8,
    error: String,
}

/// A usage or pre-flight failure under `--json`:
/// `{"ok":false,"exit":N,"error":"..."}`, the message cut to 300 characters.
pub fn stop_json(code: u8, message: &str) -> String {

        ok: false,
        exit: code,

}

#[derive(Serialize)]
struct ApplyError {
    ok: bool,
    exit: u8,
    error: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    run_dir: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    diff: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    outcomes: Option<Vec<JsonOutcome>>,
    #[serde(skip_serializing_if = "Option::is_none")]
    outcomes_cut: Option<usize>,
}

/// The `--json` object of a failed `--apply` (exit 2): `{ok, exit, error,
/// run_dir, diff, outcomes, outcomes_cut}`, so an agent keeps the proposal
/// and the poses' results. The error (which starts with the diff path) is cut
/// to 200 characters and the outcomes carry no `diff` of their own. Outcomes
/// are dropped from the end until the object fits `max` characters, counted
/// as `outcomes_cut`. Pass [`APPLY_ERROR_MAX`] for `max`.
pub fn apply_error_json(
    message: &str,
    run_dir: &str,
    diff_path: &str,
    outcomes: &[Outcome],
    max: usize,
) -> String {
    let entries = compact_outcomes(outcomes, false);
    let total = entries.len();
    let non_empty = |s: &str| if s.is_empty() { None } else { Some(s.to_string()) };
    let mut out = ApplyError {
        ok: false,
        exit: 2,
        error: limit_text(&hide_lease_ids(message), 200),
        run_dir: non_empty(run_dir),
        diff: non_empty(diff_path),
        outcomes: None,
        outcomes_cut: None,
    };
    let mut keep = total;
    loop {
        out.outcomes = if keep > 0 {
            Some(entries[..keep].to_vec())
        } else {
            None
        };
        out.outcomes_cut = if keep < total {
            Some(total - keep)
        } else {
            None
        };
        let json = to_json(&out);
        if json.chars().count() <= max || keep == 0 {
            return json;
        }
        keep -= 1;
    }
}

```rust
//! Fancy-mode rendering of the pose lines and the diff. In plain mode both
//! return the PowerShell text byte for byte.

use crate::daemon::mcp::hide_lease_ids;
use crate::ui::{Mark, Tone, Ui};

use super::outcome::{changes, format_line, score_text, Outcome, CONFIRM_RUNS};

/// One pose's line.
///
/// Fancy:
/// ```text
/// ✓ frost  score 8312 · confirmed 3/3 · bearing 322.5 → 330.0
/// · supply  unchanged · score 7400 · confirmed 3/3
/// ✗ frost  no proposal: <reason> (best score 5100, confirmed 1/3)
/// ```
/// The pose is bold, `✓` green, `✗` bold red, separators and details dim
/// where shown above in the tail. Plain: [`format_line`].
pub fn render_line(ui: &Ui, o: &Outcome) -> String {
    if !ui.fancy {
        return format_line(o);
    }
    let reason = hide_lease_ids(&o.reason);
    let confirmed = format!("confirmed {}/{CONFIRM_RUNS}", o.confirmed);
    let pose = ui.paint(Tone::Bold, &o.pose);
    if !o.ok {
        let mut line = format!("{} {pose}  no proposal", ui.paint(Tone::Fail, ui.mark(Mark::Fail)));
        if !reason.is_empty() {
            line.push_str(&format!(": {reason}"));
        }
        if let Some(score) = o.score {
            let tail = format!(" (best score {}, {confirmed})", score_text(score));
            line.push_str(&ui.paint(Tone::Dim, &tail));
        }
        return line;
    }
    let dot = ui.paint(Tone::Dim, " · ");
    let mut parts: Vec<String> = Vec::new();
    if let Some(score) = o.score {
        parts.push(format!("score {}", score_text(score)));
    }
    parts.push(confirmed);
    let changes = changes(o);
    let mut line = if changes.is_empty() {
        format!(
            "{} {pose}  unchanged{dot}{}",
            ui.paint(Tone::Dim, "·"),
            ui.paint(Tone::Dim, &parts.join(" · "))
        )
    } else {
        for (label, text) in &changes {
            parts.push(format!("{label} {}", text.replace(" -> ", " → ")));
        }
        format!(
            "{} {pose}  {}",
            ui.paint(Tone::Ok, ui.mark(Mark::Pass)),
            parts.join(&dot)
        )
    };
    if !reason.is_empty() {
        line.push_str(&ui.paint(Tone::Dim, &format!(" ({reason})")));
    }
    line
}

/// The diff text: plain unchanged; fancy with `+` lines green, `-` lines red,
/// `@@` lines cyan and the `---`/`+++` headers bold. Lines are joined with
/// `\n`, with no trailing newline.
pub fn render_diff(ui: &Ui, text: &str) -> String {
    if !ui.fancy {
        return text.to_string();
    }
    text.lines()
        .map(|l| {
            if l.starts_with("+++") || l.starts_with("---") {
                ui.paint(Tone::Bold, l)
            } else if l.starts_with("@@") {
                ui.paint(Tone::Cmd, l)
            } else if l.starts_with('+') {
                ui.paint(Tone::Ok, l)
            } else if l.starts_with('-') {
                ui.paint(Tone::Fail, l)
            } else {
                l.to_string()
            }
        })
        .collect::<Vec<_>>()
        .join("\n")
}

## Step 4: `calibrate/apply.rs`

`--apply`'s git flow. The commands are `git -C <repo> ls-files --error-unmatch
-- <rel>`, `git -C <repo> diff --quiet HEAD -- <rel>` and `git -C <repo> apply
<diff>`. Nothing is ever staged or committed.

```rust
//! `--apply`: `git apply` the proposed diff in this checkout, unless its spec
//! has local edits or is not tracked. Never stages, never commits. Every
//! error starts with the diff's path, so the proposal is never lost with the
//! failure.

use std::path::Path;
use std::process::{Command, Stdio};

/// The spec folder, from the repo root: a diff for any other path is not this
/// checkout's to apply.
pub const SPEC_PREFIX: &str = "docs/guides/uat-specs/";

/// What [`apply_diff`] did.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ApplyResult {
    pub ok: bool,
    /// Set when `!ok`; starts with the diff path (`<diff>: <why>`).
    pub error: Option<String>,
    /// The repo-relative file the diff names, when it was read far enough.
    pub target: Option<String>,
}

impl ApplyResult {
    /// A refusal: `<diff_path>: <message>` (just the message with no path).
    pub fn refused(diff_path: &str, message: &str, target: Option<String>) -> ApplyResult {
        let error = if diff_path.is_empty() {
            message.to_string()
        } else {
            format!("{diff_path}: {message}")
        };
        ApplyResult {
            ok: false,
            error: Some(error),
            target,
        }
    }
}

/// The number of `+++ ` file headers in a diff.
pub fn diff_file_count(text: &str) -> usize {
    text.split('\n')
        .filter(|l| l.trim_end_matches('\r').starts_with("+++ "))
        .count()
}

/// The repo-relative file a diff applies to (its `+++ b/<path>` line), or
/// `None` when it names none or more than one: `lab_uat_calibrate` proposes
/// for one spec, so a second file is not its diff.
pub fn diff_target(text: &str) -> Option<String> {
    if diff_file_count(text) != 1 {
        return None;
    }
    text.split('\n').find_map(|l| {
        l.trim_end_matches('\r')
            .strip_prefix("+++ b/")
            .map(str::trim)
            .filter(|t| !t.is_empty())
            .map(str::to_string)
    })
}

/// Runs git in `repo`; `Some(true)` when it exits 0, `None` when it cannot run.
fn git_ok(repo: &Path, args: &[&str]) -> Option<bool> {
    Command::new("git")
        .arg("-C")
        .arg(repo)
        .args(args)
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null())
        .status()
        .ok()
        .map(|s| s.success())
}

/// Whether a repo-relative file has local edits, staged or not (`git diff
/// HEAD`), or is not tracked at all (`git diff` cannot see an untracked file,
/// and `git apply` over it would leave nothing to revert to): `true` then,
/// and when git cannot tell.
pub fn spec_dirty(repo: &Path, rel: &str) -> bool {
    if git_ok(repo, &["ls-files", "--error-unmatch", "--", rel]) != Some(true) {
        return true;
    }
    git_ok(repo, &["diff", "--quiet", "HEAD", "--", rel]) != Some(true)
}

/// `git apply` the diff file in `repo`. The refusals, in order (each is
/// `<diff>: <message>`):
///
/// 1. `no diff was proposed; nothing to apply` (empty path)
/// 2. `the diff file is missing; nothing to apply`
/// 3. `the diff touches <n> files, not one spec; apply it by hand` (n > 1)
/// 4. `the diff names no file`
/// 5. `the diff is for <target>, not this checkout's docs/guides/uat-specs/; apply it by hand`
/// 6. `<target> is not in <repo>`
/// 7. `<target> has uncommitted changes or is not tracked; commit or revert them, then: git -C "<repo>" apply "<diff>"`
/// 8. `git apply failed: <first line of git's error>`
pub fn apply_diff(repo: &Path, diff_path: &str) -> ApplyResult {
    if diff_path.is_empty() {
        return ApplyResult::refused(diff_path, "no diff was proposed; nothing to apply", None);
    }
    if !Path::new(diff_path).exists() {
        return ApplyResult::refused(diff_path, "the diff file is missing; nothing to apply", None);
    }
    let text = match std::fs::read_to_string(diff_path) {
        Ok(t) => t,
        Err(e) => {
            return ApplyResult::refused(diff_path, &format!("cannot read the diff: {e}"), None)
        }
    };
    let files = diff_file_count(&text);
    if files > 1 {
        let m = format!("the diff touches {files} files, not one spec; apply it by hand");
        return ApplyResult::refused(diff_path, &m, None);
    }
    let Some(target) = diff_target(&text) else {
        return ApplyResult::refused(diff_path, "the diff names no file", None);
    };
    if !target.starts_with(SPEC_PREFIX) {
        let m = format!("the diff is for {target}, not this checkout's {SPEC_PREFIX}; apply it by hand");
        return ApplyResult::refused(diff_path, &m, Some(target));
    }
    if !repo.join(&target).exists() {
        let m = format!("{target} is not in {}", repo.display());
        return ApplyResult::refused(diff_path, &m, Some(target));
    }
    if spec_dirty(repo, &target) {
        let m = format!(
            "{target} has uncommitted changes or is not tracked; commit or revert them, then: git -C \"{}\" apply \"{diff_path}\"",
            repo.display()
        );
        return ApplyResult::refused(diff_path, &m, Some(target));
    }
    let output = match Command::new("git")
        .arg("-C")
        .arg(repo)
        .arg("apply")
        .arg(diff_path)
        .stdin(Stdio::null())
        .output()
    {
        Ok(o) => o,
        Err(e) => {
            let m = format!("git apply failed: {e}");
            return ApplyResult::refused(diff_path, &m, Some(target));
        }
    };
    if !output.status.success() {
        let stderr = String::from_utf8_lossy(&output.stderr);
        let stdout = String::from_utf8_lossy(&output.stdout);
        let first = stderr
            .lines()
            .chain(stdout.lines())
            .map(str::trim)
            .find(|l| !l.is_empty())
            .unwrap_or("no message");
        let m = format!("git apply failed: {first}");
        return ApplyResult::refused(diff_path, &m, Some(target));
    }
    ApplyResult {
        ok: true,
        error: None,
        target: Some(target),
    }
}
```

## Step 5: `calibrate/heal.rs`

LX-17 imports these (`commands::calibrate::{heal_file_name, invoke_heal,
HealHint, HealJob, HealRecord}`), with the call closure wrapping
`McpClient::call_tool("lab_uat_calibrate", args, timeout)` and the wait closure
wrapping `mcp::wait_lease_free`.

```rust
//! `lab uat --heal` (D-SV8 (a)): for each (row, pose) hint, one
//! `lab_uat_calibrate` call for that pose on the batch's instance; a proposed
//! diff is copied into the batch folder as `heal-<row>-<pose>.diff`. The spec
//! file is never written. The MCP call and the lease wait are closures, so
//! tests pass stubs and `uat` passes the real ones.

use std::path::{Path, PathBuf};

use serde_json::{json, Value};

use crate::daemon::mcp::McpError;

use super::outcome::{call_error_text, format_call_error, format_line, outcomes_from, Outcome};

/// One pose a failed row missed on.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct HealHint {
    pub row: String,
    pub pose: String,
}

/// Where and what to heal. `specs_dir` and `instance` are empty for "none".
#[derive(Debug, Clone, Copy)]
pub struct HealJob<'a> {
    pub batch_dir: &'a Path,
    pub section: &'a str,
    pub specs_dir: &'a str,
    pub instance: &'a str,
}

/// One hint's result. The last record of a stopped heal has `row` and `pose`
/// `None` and only `line` set.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct HealRecord {
    pub row: Option<String>,
    pub pose: Option<String>,
    /// The batch copy of the proposal, when there is one.
    pub diff: Option<PathBuf>,
    pub line: String,
    /// The proposal's text, kept so the caller can print it.
    pub text: Option<String>,
}

/// `heal-<row>-<pose>.diff`, anything but letters, digits, `.`, `_` and `-`
/// made `_`.
pub fn heal_file_name(row: &str, pose: &str) -> String {
    let safe = |s: &str| -> String {
        s.chars()
            .map(|c| {
                if c.is_ascii_alphanumeric() || matches!(c, '.' | '_' | '-') {
                    c
                } else {
                    '_'
                }
            })
            .collect()
    };
    format!("heal-{}-{}.diff", safe(row), safe(pose))
}

/// Calls `lab_uat_calibrate` once per hint (arguments `{section, row, pose,
/// instance?, specs_dir?}`) and returns one record per hint.
///
/// `on_record` gets each record as soon as its call is done, so a caller
/// interrupted mid-heal still has the earlier ones. `wait_lease_free` gets the
/// instance after a call that failed and before the next hint (a call our
/// timeout ended may still hold its lease): when it returns false, healing
/// stops with a last record naming the poses left.
pub fn invoke_heal(
    hints: &[HealHint],
    job: &HealJob<'_>,
    call: &mut dyn FnMut(Value) -> Result<Value, McpError>,
    mut on_record: Option<&mut dyn FnMut(&HealRecord)>,
    mut wait_lease_free: Option<&mut dyn FnMut(&str) -> bool>,
) -> Vec<HealRecord> {
    let mut results = Vec::new();
    for (i, hint) in hints.iter().enumerate() {
        let (row, pose) = (hint.row.as_str(), hint.pose.as_str());
        let mut args = json!({ "section": job.section, "row": row, "pose": pose });
        if !job.instance.is_empty() {
            args["instance"] = json!(job.instance);
        }
        if !job.specs_dir.is_empty() {
            args["specs_dir"] = json!(job.specs_dir);
        }
        let mut rec = HealRecord {
            row: Some(row.to_string()),
            pose: Some(pose.to_string()),
            diff: None,
            line: String::new(),
            text: None,
        };
        let mut threw = false;
        match call(args) {
            Ok(reply) => {
                let outcome = outcomes_from(&reply).into_iter().find(|o| o.pose == pose);
                match outcome {
                    None => {
                        rec.line = format!(
                            "heal {row} {pose}: lab_uat_calibrate returned no outcome for the pose"
                        );
                    }
                    Some(o) => {
                        let src = Path::new(&o.diff_path);
                        if o.ok && !o.diff_path.is_empty() && src.exists() {
                            let dest = job.batch_dir.join(heal_file_name(row, pose));
                            match std::fs::copy(src, &dest) {
                                Ok(_) => {
                                    rec.text = std::fs::read_to_string(&dest).ok();
                                    // The line names the batch copy, the one the summary lists.
                                    let shown = Outcome {
                                        diff_path: dest.display().to_string(),
                                        ..o.clone()
                                    };
                                    rec.line = format!("heal {row} {}", format_line(&shown));
                                    rec.diff = Some(dest);
                                }
                                Err(e) => {
                                    threw = true;
                                    rec.line = format!(
                                        "heal {row} {pose}: {}",
                                        format_call_error(&format!("cannot save the proposal: {e}"))
                                    );
                                }
                            }
                        } else {
                            rec.line = format!("heal {row} {}", format_line(&o));
                        }
                    }
                }
            }
            Err(e) => {
                threw = true;
                rec.line = format!(
                    "heal {row} {pose}: {}",
                    format_call_error(&call_error_text("lab_uat_calibrate", &e))
                );
            }
        }
        if let Some(f) = on_record.as_deref_mut() {
            f(&rec);
        }
        results.push(rec);
        // Nothing to wait for after the last hint: lab uat ends there.
        if threw && i + 1 < hints.len() {
            if let Some(wait) = wait_lease_free.as_deref_mut() {
                if !wait(job.instance) {
                    let left: Vec<String> = hints[i + 1..]
                        .iter()
                        .map(|h| format!("{} {}", h.row, h.pose))
                        .collect();
                    let stop = HealRecord {
                        row: None,
                        pose: None,
                        diff: None,
                        text: None,
                        line: format!(
                            "heal stopped: the lease on {} did not clear after the failed call; not recalibrated: {}",
                            job.instance,
                            left.join(", ")
                        ),
                    };
                    if let Some(f) = on_record.as_deref_mut() {
                        f(&stop);
                    }
                    results.push(stop);
                    break;
                }
            }
        }
    }
    results
}
```

If rustc rejects `as_deref_mut()` on the two `Option<&mut dyn FnMut>`
parameters, replace each use with `if let Some(f) = on_record.as_mut() { f(&rec); }`
(same for `wait`): the behaviour is identical.

    let o = Command::new("git").arg("-C").arg(repo).args(args).output().expect("git runs");

/// `--prepare` as clean row ids: split on commas, trimmed, blanks and repeats
/// dropped (clap already splits on commas; this also trims).
pub fn row_ids(rows: &[String]) -> Vec<String> {
    let mut ids: Vec<String> = Vec::new();
    for r in rows {
        for p in r.split(',') {
            let t = p.trim();
            if !t.is_empty() && !ids.iter().any(|i| i == t) {
                ids.push(t.to_string());
            }
        }
    }
    ids
}

/// The one instance to calibrate on (`Get-UatPlan` with one lease, one run,
/// no client cap). `Err((exit, message))`: exit 2 for an unknown instance,
/// else 3.
pub fn pick_instance(
    hosted: &[String],
    leased: &[String],
    requested: Option<&str>,
) -> Result<String, (u8, String)> {
    let hosted: Vec<&String> = hosted.iter().filter(|h| !h.is_empty()).collect();
    let leased: Vec<&String> = leased.iter().filter(|l| !l.is_empty()).collect();
    let names = |v: &[&String]| v.iter().map(|s| s.as_str()).collect::<Vec<_>>().join(", ");
    if let Some(i) = requested {
        if !hosted.iter().any(|h| h.as_str() == i) {
            return Err((2, format!("unknown instance '{i}'; the daemon hosts: {}", names(&hosted))));
        }
        if leased.iter().any(|l| l.as_str() == i) {
            return Err((3, format!("instance {i} is leased by another session; wait for it or pick another")));
        }
        return Ok(i.to_string());
    }
    if hosted.is_empty() {
        return Err((3, "-Leases 1 is more than the lab allows (0: 0 hosted, max clients 0)".to_string()));
    }
    let free: Vec<&String> = hosted
        .iter()
        .filter(|h| !leased.iter().any(|l| l == *h))
        .copied()
        .collect();
    match free.first() {
        Some(first) => Ok((*first).clone()),
        None => {
            let busy: Vec<&String> = hosted.iter().filter(|h| leased.iter().any(|l| l == *h)).copied().collect();
            Err((3, format!("only 0 free instance(s) for 1 lease(s); leased by other sessions: {}", names(&busy))))
        }
    }
}

/// The prepare run's verdict from `lab_uat_run`'s `rows`: `None` when every
/// planned row is there and is `PASS` or `SKIPPED`, else the exit-3 message
/// `prepare row <row> <result>: <reason>` (a missing row is result `MISSING`,
/// reason `the run reported no result for <rows>`; the reason is the first of
/// the row's `reasons`, lease ids hidden).
pub fn prepare_failure(rows: &[Value], expected: &[String]) -> Option<String> {
    let text = |r: &Value, k: &str| r.get(k).and_then(Value::as_str).unwrap_or("").to_string();
    let got: Vec<String> = rows.iter().map(|r| text(r, "row")).collect();
    let absent: Vec<&str> = expected
        .iter()
        .filter(|e| !e.is_empty() && !got.contains(e))
        .map(String::as_str)
        .collect();
    if let Some(first) = absent.first() {
        return Some(format!(
            "prepare row {first} MISSING: the run reported no result for {}",
            absent.join(", ")
        ));
    }
    for r in rows {
        let result = text(r, "result");
        if result != "PASS" && result != "SKIPPED" {
            let reason = r
                .get("reasons")
                .and_then(Value::as_array)
                .and_then(|a| a.first())
                .and_then(Value::as_str)
                .unwrap_or("");
            return Some(format!(
                "prepare row {} {result}: {}",
                text(r, "row"),
                hide_lease_ids(reason)
            ));
        }
    }
    None
}

/// Whether a process image name is the game client.
#[cfg_attr(not(windows), allow(dead_code))]
fn is_sgw_image(name: &str) -> bool {
    name.eq_ignore_ascii_case("SGW.exe")
}

/// Pids of every running `SGW.exe` (a copy of the doctor's, decision 5).
#[cfg(windows)]
pub fn sgw_pids() -> Vec<u32> {
    use std::mem::{size_of, zeroed};
    use windows_sys::Win32::Foundation::{CloseHandle, INVALID_HANDLE_VALUE};
    use windows_sys::Win32::System::Diagnostics::ToolHelp::{
        CreateToolhelp32Snapshot, Process32FirstW, Process32NextW, PROCESSENTRY32W,
        TH32CS_SNAPPROCESS,
    };

    let mut pids = Vec::new();
    // SAFETY: plain Win32 calls. `entry` is zeroed and its `dwSize` is set as
    // the API requires; the snapshot handle is closed before returning.
    unsafe {
        let snapshot = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
        if snapshot == INVALID_HANDLE_VALUE {
            return pids;
        }
        let mut entry: PROCESSENTRY32W = zeroed();
        entry.dwSize = size_of::<PROCESSENTRY32W>() as u32;
        let mut more = Process32FirstW(snapshot, &mut entry) != 0;
        while more {
            let len = entry
                .szExeFile
                .iter()
                .position(|&unit| unit == 0)
                .unwrap_or(entry.szExeFile.len());
            let name = String::from_utf16_lossy(&entry.szExeFile[..len]);
            if is_sgw_image(&name) {
                pids.push(entry.th32ProcessID);
            }
            more = Process32NextW(snapshot, &mut entry) != 0;
        }
        CloseHandle(snapshot);
    }
    pids
}

/// No process list off Windows: no `SGW.exe` runs there.
#[cfg(not(windows))]
pub fn sgw_pids() -> Vec<u32> {
    Vec::new()
}

    pub repo: Option<PathBuf>,

/// A usage or pre-flight failure: one JSON object on stdout under `--json`,
/// else the message on stderr (plain, as the PowerShell; fancy: `error:` in
/// bold red). Returns the exit code.
fn stop(ui: &Ui, json: bool, code: u8, message: &str, out: &mut dyn Write, err: &mut dyn Write) -> u8 {
    if json {
        let _ = writeln!(out, "{}", stop_json(code, message));
    } else if ui.fancy {
        let _ = writeln!(err, "{} {message}", ui.paint(Tone::Fail, "error:"));
    } else {
        let _ = writeln!(err, "{message}");
    }
    code
}

/// A progress line on stdout (not under `--json`); fancy mode leads with a
/// cyan `▶`.

        return;

        let _ = writeln!(out, "{} {text}", ui.paint(Tone::Cmd, ui.mark(Mark::Active)));
    } else {

    }

/// Runs the command and returns its exit code (0, 1, 2 or 3).
pub fn execute(
    args: &Args,
    ui: &Ui,
    deps: &mut Deps<'_>,
    out: &mut dyn Write,
    err: &mut dyn Write,
) -> u8 {
    let json = args.json;
    let section = args.section.as_deref().unwrap_or("");
    let row = args.row.as_deref().unwrap_or("");
    // Argument checks come before the daemon is asked, so they exit 2 whatever its state.
    if let Some(shape) = check_arguments(section, row, args.budget_minutes) {
        return stop(ui, json, 2, &shape, out, err);
    }
    let specs: Option<String> = args
        .specs_dir
        .clone()
        .filter(|s| !s.is_empty())
        .or_else(|| deps.specs.clone());
    let repo = deps.repo.clone();
    // A spec with local edits is refused before any lab time is spent; the
    // file the diff names is checked again before git apply.
    if args.apply {
        if let Some(repo) = &repo {
            let guess = format!("{SPEC_PREFIX}{section}.toml");
            if repo.join(&guess).exists() && spec_dirty(repo, &guess) {
                let m = format!("{guess} has uncommitted changes or is not tracked; --apply would clobber them (commit or revert first, or drop --apply)");
                return stop(ui, json, 2, &m, out, err);
            }
        }
    }
    let prepare_rows = row_ids(&args.prepare);

    // Pre-flight: daemon, instance, foreign clients.
    let Some(status) = status::fetch(deps.ep) else {
        return stop(ui, json, 3, "the lab daemon is not answering (lab status; lab start)", out, err);
    };
    let hosted: Vec<String> = status.instances.iter().map(|i| i.instance.clone()).collect();
    let leased: Vec<String> = status
        .instances
        .iter()
        .filter(|i| {
            i.lease
                .as_ref()
                .and_then(|l| l.get("held"))
                .and_then(Value::as_bool)
                == Some(true)
        })
        .map(|i| i.instance.clone())
        .collect();
    let requested = args.instance.as_deref().filter(|s| !s.is_empty());
    let lane = match pick_instance(&hosted, &leased, requested) {
        Ok(l) => l,
        Err((code, m)) => return stop(ui, json, code, &m, out, err),
    };
    let lab_pids: Vec<u32> = status.instances.iter().filter_map(|i| i.client_pid).collect();
    let foreign = foreign_pids(&lab_pids, &(deps.sgw_pids)());
    if !foreign.is_empty() {
        let list: Vec<String> = foreign.iter().map(u32::to_string).collect();
        let m = format!(
            "SGW.exe runs outside the lab (pid {}); close it first, or the lab cannot start its clients",
            list.join(", ")
        );
        return stop(ui, json, 3, &m, out, err);
    }

    // --prepare: walk the client to where the row starts.
    if !prepare_rows.is_empty() {
        say(ui, json, &format!("prepare: {} on {lane}", prepare_rows.join(", ")), out);
        // end_session = false: the calibration starts where these rows leave the
        // client, so the run must not log out and disconnect (TG-PIPE-08).
        let mut pa = json!({ "sections": [section], "rows": prepare_rows, "instance": lane, "end_session": false });
        if let Some(s) = &specs {
            pa["specs_dir"] = json!(s);
        }
        match (deps.call)("lab_uat_run", pa, Duration::from_secs(15 * 60)) {
            Err(e) => {
                let text = call_error_text("lab_uat_run", &e);
                let first = text.split('\n').next().unwrap_or("").trim_end_matches('\r');
                let m = format!("prepare failed: {}", hide_lease_ids(first));
                return stop(ui, json, 3, &m, out, err);
            }
            Ok(prep) => {
                let rows: Vec<Value> = prep
                    .get("rows")
                    .and_then(Value::as_array)
                    .cloned()
                    .unwrap_or_default();
                if let Some(m) = prepare_failure(&rows, &prepare_rows) {
                    return stop(ui, json, 3, &m, out, err);
                }
            }
        }
    }

    // The sweep.
    let pose = args.pose.as_deref().filter(|p| !p.is_empty());
    let mut ca = json!({ "section": section, "row": row, "instance": lane });
    if let Some(p) = pose {
        ca["pose"] = json!(p);
    }
    if let Some(s) = &specs {
        ca["specs_dir"] = json!(s);
    }
    if let Some(b) = args.budget_minutes {
        ca["budget_minutes"] = json!(b);
    }
    let pose_part = pose.map(|p| format!(" pose {p}")).unwrap_or_default();
    let budget = args.budget_minutes.unwrap_or(15);
    say(ui, json, &format!("calibrate {section} {row}{pose_part} on {lane} (budget {budget} min)"), out);
    let reply = match (deps.call)("lab_uat_calibrate", ca, timeout(args.budget_minutes)) {
        Ok(r) => r,
        Err(e) => {
            let m = format_call_error(&call_error_text("lab_uat_calibrate", &e));
            return stop(ui, json, 3, &m, out, err);
        }
    };
    let outcomes = outcomes_from(&reply);
    let code = exit_code(&outcomes);
    let diff_path: Option<String> = outcomes
        .iter()
        .map(|o| o.diff_path.clone())
        .find(|p| !p.is_empty());
    let run_dir = reply.get("run_dir").and_then(Value::as_str).unwrap_or("").to_string();

    // --apply.
    let mut applied = false;
    if args.apply {
        if let Some(diff) = &diff_path {
            let result = match &repo {
                Some(r) => apply_diff(r, diff),
                None => ApplyResult::refused(
                    diff,
                    "no checkout was found (run lab calibrate from inside the repository); apply it by hand",
                    None,
                ),
            };
            if !result.ok {
                // The error starts with the diff path, and --json keeps the run
                // folder and the poses: a refused apply must not lose the proposal.
                let why = result.error.unwrap_or_default();
                if json {
                    let m = format!("{why} (--apply)");
                    let _ = writeln!(out, "{}", apply_error_json(&m, &run_dir, diff, &outcomes, APPLY_ERROR_MAX));
                    return 2;
                }
                for o in &outcomes {
                    let _ = writeln!(out, "{}", render_line(ui, o));
                }
                let m = format!("{why} (--apply; the diff stays in the run folder)");
                return stop(ui, false, 2, &m, out, err);
            }
            applied = true;
        }
    }

    if json {
        let _ = writeln!(out, "{}", compact_json(section, row, &outcomes, applied));
        return code;
    }
    if outcomes.is_empty() {
        let _ = writeln!(out, "lab_uat_calibrate returned no outcomes; run folder {run_dir}");
    }
    for o in &outcomes {
        let _ = writeln!(out, "{}", render_line(ui, o));
    }
    if let Some(diff) = &diff_path {
        if !args.quiet && Path::new(diff).exists() {
            if let Ok(text) = std::fs::read_to_string(diff) {
                let _ = writeln!(out);
                let _ = writeln!(out, "{}", render_diff(ui, &text));
            }
        }
    }
    if applied {
        let repo_text = repo.as_ref().map(|r| r.display().to_string()).unwrap_or_default();
        let line = format!("applied to the checkout ({repo_text}); review it with git diff, nothing is staged or committed");
        if ui.fancy {
            let _ = writeln!(out, "{} {line}", ui.paint(Tone::Ok, ui.mark(Mark::Pass)));
        } else {
            let _ = writeln!(out, "{line}");
        }
    } else if let Some(diff) = &diff_path {
        let line = match &repo {
            Some(r) => format!("to apply: git -C \"{}\" apply \"{diff}\" (or rerun with --apply)", r.display()),
            None => format!("to apply: git apply \"{diff}\" in the checkout (or rerun with --apply)"),
        };
        let _ = writeln!(out, "{}", ui.paint(Tone::Dim, &line));
    }
    code
}

/// proposal or is unchanged, 1 a pose found none, 2 usage or `--apply`
/// refused or failed, 3 the pre-flight, a prepare row or the call failed.
pub fn run(args: &Args, ctx: &Ctx) -> u8 {
    let ep = Endpoint::discover();
    let specs = paths::default_specs_dir();
    let repo = specs.as_deref().and_then(preflight::repo_root_from_specs);
    let specs = specs.map(|p| p.display().to_string());

    let mut call = move |name: &str, call_args: Value, wait: Duration| -> Result<Value, McpError> {

        let reply = client.call_tool(name, call_args, wait);
        client.close();
        reply
    };
    let sgw = preflight::sgw_pids;
    let mut deps = Deps {
        ep: &ep,
        repo,
        specs,
        sgw_pids: &sgw,
        call: &mut call,
    };
    let mut out = anstream::stdout();
    let mut err = anstream::stderr();
    execute(args, &ctx.ui, &mut deps, &mut out, &mut err)
}

const DIFF: &str = "--- a/docs/guides/uat-specs/x.toml\n+++ b/docs/guides/uat-specs/x.toml\n@@ -1,3 +1,3 @@\n a\n-b\n+B\n c\n";

struct Ran {
    code: u8,
    out: String,
    err: String,
    calls: Vec<(String, Value)>,
}

fn args(tokens: &[&str]) -> calibrate::Args {
    let mut all = vec!["lab", "calibrate"];
    all.extend_from_slice(tokens);
    match Cli::try_parse_from(all).expect("parses").command {
        Some(Cmd::Calibrate(a)) => a,
        _ => panic!("not calibrate"),
    }
}

/// `[(instance, leased, client_pid)]` as the daemon's /status body.
fn status_body(rows: &[(&str, bool, Option<u32>)]) -> String {
    let instances: Vec<Value> = rows
        .iter()
        .map(|(name, held, pid)| json!({"instance": name, "account": null, "client_pid": pid, "lease": {"held": held}}))
        .collect();
    json!({"daemon": {"pid": 1, "version": "x"}, "instances": instances}).to_string()
}

fn run_flow(
    tokens: &[&str],
    ep: &Endpoint,
    repo: Option<PathBuf>,
    sgw: Vec<u32>,
    replies: Vec<Result<Value, McpError>>,
) -> Ran {
    let queue = RefCell::new(VecDeque::from(replies));
    let calls = RefCell::new(Vec::<(String, Value)>::new());
    let mut call = |name: &str, a: Value, _t: Duration| -> Result<Value, McpError> {
        calls.borrow_mut().push((name.to_string(), a));
        queue.borrow_mut().pop_front().expect("an unexpected MCP call")
    };
    let sgw_fn = move || sgw.clone();
    let mut deps = Deps { ep, repo, specs: None, sgw_pids: &sgw_fn, call: &mut call };
    let (mut out, mut err) = (Vec::new(), Vec::new());
    let code = calibrate::execute(&args(tokens), &Ui::plain(), &mut deps, &mut out, &mut err);
    Ran {
        code,
        out: String::from_utf8(out).unwrap(),
        err: String::from_utf8(err).unwrap(),
        calls: calls.into_inner(),
    }
}

fn frost_reply(diff: &str) -> Value {
    json!({"run_dir": "RUN", "outcomes": [
        {"ok": true, "pose": "frost", "score": 8312, "confirmed": 3, "changed": {"bearing_deg": [322.5, 330.0]}, "diff_path": diff}]})
}

fn git(repo: &Path, args: &[&str]) -> String {
    let o = Command::new("git").arg("-C").arg(repo).args(args).output().expect("git");
    assert!(o.status.success(), "git {args:?}");
    String::from_utf8_lossy(&o.stdout).trim().to_string()
}
