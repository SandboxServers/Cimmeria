**Fallback rules** (`fallback::run(ctx)` starts `uat.ps1`; the PowerShell does its own pre-flight, so it is called instead of the native pre-flight, never after it).

- LX-15: only `--plan-only` and the refusals before anything is driven are native. Every real run (no `--plan-only`) goes straight to `fallback::run` WITHOUT the native pre-flight (no double plan, no double batch folder). `preflight::execute` still implements the real-run path (tested through stubs) for LX-16b. No `.ps1` is edited or deleted.
- LX-16b: a real run is native (native pre-flight, then `batch_run::execute`) unless `--json`, `--diff-golden`, `--heal` or a non-empty `--chaos` is given (`batch_run::needs_powershell`); those go straight to `fallback::run`. `--plan-only` is native whatever else is given. No `.ps1` is edited or deleted.
- LX-17b: no fallback is left: `fallback::run` and `needs_powershell` are removed from `uat`. The PowerShell files stay on disk until LX-17c.
- LX-17c: deletes `uat.ps1`, `uat-lib.ps1`, `uat-chaos-lib.ps1`, `test-uat.ps1`, `test-uat-chaos.ps1`, `calibrate-lib.ps1`, `golden-lib.ps1`, only when a Grep proves nothing else dot-sources them and every check below has a Rust port.

## Decisions made here (the coordinator should reconcile the packet text)

1. **Flag names in messages.** The PowerShell messages say `-Leases`,
   `-RunsPerLease`, `-Instance`, `-Chaos`, ...; the Rust ones say `--leases`,
   `--runs-per-lease`, `--instance`, `--chaos` (everything else byte for byte).
   The usage line lists `--flag` forms too. Two existing PowerShell checks
   compare against the old spelling; they stay valid because `uat.ps1` is kept.
2. **Row ids are case sensitive where the daemon's reply is compared.** The
   PowerShell compared with `-notcontains`, which ignores case, although its
   message says "exact and case sensitive". Rust compares exactly: `--rows
   fs-01` against a section whose row is `FS-01` is exit 2 ("has no row(s)
   fs-01"). De-duplicating the typed list still ignores case, as before.
3. **Clap types replace three PowerShell checks.** `--stagger-seconds`,
   `--max-consecutive-failures`, `--leases`, `--runs-per-lease` and
   `--run-timeout-minutes` are `u32`, so `-5` is a clap usage error (exit 2,
   clap's message, before the daemon), not our message. The range checks below
   (upper bounds, and 0 for `--leases`, `--runs-per-lease`,
   `--run-timeout-minutes`) are still ours. `--fixtures Always` is likewise a
   clap error (the value parser is case sensitive); our own fixtures check stays
   as a second guard.
4. **`not ready:` reasons go through `hide_lease_ids`.** The PowerShell printed
   them raw. The plan call never holds a lease, so this changes nothing in
   practice; it keeps the rule that no lease id leaves the command.
5. **Only `--plan-only` is native here; a real run goes straight to the
   PowerShell** (coordinator decision, 2026-10-12). `run` calls the native
   pre-flight only when `--plan-only` is given. A real run calls `fallback::run`
   at once, so the script's own pre-flight is the only one: nothing is planned
   twice and no second batch folder is made. `preflight::execute` still
   implements the real-run path (a ready run returns `Outcome::Drive(Ready)`; a
   foreign `SGW.exe` is exit 3) and is tested through stubs, because LX-16b calls
   it from `native_preflight` for the runs it drives natively.
6. **`plan.json` is written by `plan::create_batch`**, tested here and called by
   LX-16. A fallback real run still writes its own `plan.json` from
   `uat.ps1`, so nothing writes it twice. `plan.json`'s `pid` is this process's
   (`std::process::id()`); `lab watch` (LX-13) already accepts `lab` as the
   owner.
7. **Own `golden_file`.** LX-11 is not a dependency of this packet, so
   `preflight.rs` carries its own `golden_file(specs, section)` with the same rule
   as LX-11's `golden_path` (every character outside `[A-Za-z0-9_-]` becomes
   `_`). Merging the two is a later cleanup; do not import LX-11's.
8. **Unreadable-golden text.** The PowerShell reported the first line of a .NET
   exception; Rust reports the first line of the `io` or `serde_json` error.
   The words differ, the exit code (2) and the prefix `golden for <section>
   cannot be read: ` do not.

## What the daemon returns (read once)

`lab_uat_run` with `plan_only: true` replies `{ "rows": [{ "row": "FS-01",
"result": "SKIPPED", "reasons": [] }], "chaos": ["chaos=cpu:safe seed=<per
run>", "chaos=flush:pack seed=5"] }`. `result` is `SKIPPED` for a row that is
ready to run (a plan-only pass skips every row it could run), anything else
(`BLOCKED`, ...) for a row that cannot. `chaos` is present only when the call
had `chaos`; it is the runner's resolved header, one entry per spec. A bad
chaos spec fails the call itself (a tool error whose text is the daemon's
refusal, for example `Invalid params: chaos "burst": burst is not wired yet; ...`).
`GET /status` is `{ "daemon": {...}, "instances": [{ "instance", "client_pid",
"lease": { "held": bool, ... }, ... }] }`.

```rust
//! The argument checks of `lab uat`. They run before the daemon is asked, so
//! they exit 2 whatever its state.

use super::Args;

/// Most lanes one batch may run (and most hosted instances).
pub const MAX_LEASES: u32 = 5;
/// Most runs one lane may do.
pub const MAX_RUNS_PER_LEASE: u32 = 20;

/// The usage error for a missing section (exit 2).
pub const USAGE: &str = "usage: lab uat <section> [--rows FS-01,...] [--leases 1-5] [--runs-per-lease 1-20] [--instance p2] [--fixtures auto|always|never] [--diff-golden] [--chaos spec,...] [--heal] [--plan-only] [--json]";

/// Where the progress lines go (`Get-UatProgressMode`).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Progress {
    /// Stdout (the PowerShell's `Write-Host`).
    Host,
    /// Stderr: `--progress-to-stderr`, even under `--json` or `--quiet`.
    Stderr,
    /// Nowhere: `--json` or `--quiet`.
    None,
}

/// `--progress-to-stderr` wins, then `--json` or `--quiet` silence, else stdout.
pub fn progress_mode(json: bool, quiet: bool, to_stderr: bool) -> Progress {
    if to_stderr {
        Progress::Stderr
    } else if json || quiet {
        Progress::None
    } else {
        Progress::Host
    }
}

/// The checks that need no daemon: the message to print (exit 2), or `None`.
/// The order is the PowerShell's.
pub fn check_arguments(args: &Args) -> Option<String> {
    let instance = args.instance.as_deref().is_some_and(|i| !i.is_empty());
    if !(1..=MAX_LEASES).contains(&args.leases) {
        return Some(format!("--leases must be 1 to {MAX_LEASES}"));
    }
    if !(1..=MAX_RUNS_PER_LEASE).contains(&args.runs_per_lease) {
        return Some(format!("--runs-per-lease must be 1 to {MAX_RUNS_PER_LEASE}"));
    }
    if instance && args.leases != 1 {
        return Some("--instance runs one lane; drop --leases or --instance".to_string());
    }
    if args.stagger_seconds > 300 {
        return Some("--stagger-seconds must be 0 to 300".to_string());
    }
    if !(1..=120).contains(&args.run_timeout_minutes) {
        return Some("--run-timeout-minutes must be 1 to 120".to_string());
    }
    if args.max_consecutive_failures > 20 {
        return Some("--max-consecutive-failures must be 0 to 20".to_string());
    }
    // lab-fixtures D-FX10: when a row's fixture is applied. Case sensitive: the
    // daemon takes snake_case.
    if let Some(fixtures) = args.fixtures.as_deref().filter(|f| !f.is_empty()) {
        if !["auto", "always", "never"].contains(&fixtures) {
            return Some("--fixtures must be auto, always or never".to_string());
        }
    }
    // D-SV8: a heal recalibrates on the batch's one instance, where the row failed.
    if args.heal && args.leases != 1 {
        return Some(
            "--heal needs --leases 1 (it recalibrates on the instance the batch ran on)"
                .to_string(),
        );
    }
    None
}

/// `--rows` as clean ids: split on commas, trimmed, blanks and repeats
/// (compared ignoring case, as PowerShell's `-notcontains` does) dropped.
pub fn row_ids(rows: &[String]) -> Vec<String> {
    let mut ids: Vec<String> = Vec::new();
    for raw in rows {
        for part in raw.split(',') {
            let id = part.trim();
            if !id.is_empty() && !ids.iter().any(|seen| seen.eq_ignore_ascii_case(id)) {
                ids.push(id.to_string());
            }
        }
    }
    ids
}

/// The non-empty `--chaos` values. They are not split on commas: a multi-knob
/// spec is one value. Both the request body and the header use this one filter,
/// so they always agree.
pub fn chaos_specs(chaos: &[String]) -> Vec<String> {
    chaos.iter().filter(|c| !c.is_empty()).cloned().collect()
}

/// The typed header: one `chaos=<spec>` per value, joined with `"; "`; `None`
/// when there is no chaos.
pub fn chaos_header(specs: &[String]) -> Option<String> {
    if specs.is_empty() {
        return None;
    }
    let parts: Vec<String> = specs.iter().map(|s| format!("chaos={s}")).collect();
    Some(parts.join("; "))
}

/// cpu chaos loads the whole machine and each lane's `lab_uat_run` starts its
/// own load, so `--leases 2` would double it. The profile is the text before
/// the first `:` of the trimmed spec, compared ignoring case (PowerShell `-eq`).
pub fn check_chaos_leases(chaos: &[String], leases: u32) -> Option<String> {
    let cpu = chaos
        .iter()
        .any(|c| c.trim().split(':').next().unwrap_or("").eq_ignore_ascii_case("cpu"));
    if cpu && leases > 1 {
        return Some("--chaos cpu loads the whole machine and each lease's run would start its own load; run it with --leases 1".to_string());
    }
    None
}
```

```rust
//! how its reply is judged, and the `plan.json` of the batch folder.

use std::path::{Path, PathBuf};

use chrono::{DateTime, NaiveDateTime, Utc};

use serde_json::Value;

/// A usage or pre-flight failure: the exit code and the message.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Stop {
    pub code: u8,
    pub message: String,
}

impl Stop {
    pub fn new(code: u8, message: impl Into<String>) -> Self {
        Stop {
            code,
            message: message.into(),
        }
    }
}

/// The first line of a message, trailing whitespace cut.
pub fn first_line(text: &str) -> String {
    text.lines().next().unwrap_or("").trim_end().to_string()
}

/// Picks the instances the lanes run on (`Get-UatPlan`). `hosted` is the
/// daemon's instance labels in order, `leased` the labels a session holds,
/// `max_clients` the daemon's `CIMMERIA_LAB_MAX_CLIENTS` (0 for none). Lanes
/// are numbered from 1. `Err` is exit 2 for an unknown `--instance`, else 3.
pub fn pick_lanes(
    leases: u32,
    runs_per_lease: u32,
    hosted: &[String],
    leased: &[String],
    max_clients: u32,
    instance: Option<&str>,
) -> Result<Vec<PlanLane>, Stop> {
    if !(1..=MAX_LEASES).contains(&leases) {
        return Err(Stop::new(3, format!("--leases must be 1 to {MAX_LEASES}")));
    }
    if !(1..=MAX_RUNS_PER_LEASE).contains(&runs_per_lease) {
        return Err(Stop::new(
            3,
            format!("--runs-per-lease must be 1 to {MAX_RUNS_PER_LEASE}"),
        ));
    }
    let hosted: Vec<&String> = hosted.iter().filter(|h| !h.is_empty()).collect();
    let leased: Vec<&String> = leased.iter().filter(|h| !h.is_empty()).collect();
    if let Some(instance) = instance.filter(|i| !i.is_empty()) {
        if leases != 1 {
            return Err(Stop::new(
                3,
                "--instance runs one lane; drop --leases or --instance",
            ));
        }
        if !hosted.iter().any(|h| h.as_str() == instance) {
            let names: Vec<&str> = hosted.iter().map(|h| h.as_str()).collect();
            return Err(Stop::new(
                2,
                format!(
                    "unknown instance '{instance}'; the daemon hosts: {}",
                    names.join(", ")
                ),
            ));
        }
        if leased.iter().any(|l| l.as_str() == instance) {
            return Err(Stop::new(
                3,
                format!("instance {instance} is leased by another session; wait for it or pick another"),
            ));
        }
        return Ok(vec![PlanLane {
            lane: 1,
            instance: instance.to_string(),
        }]);
    }
    let cap = if max_clients > 0 {
        hosted.len().min(max_clients as usize)
    } else {
        hosted.len()
    };
    if leases as usize > cap {
        return Err(Stop::new(
            3,
            format!(
                "--leases {leases} is more than the lab allows ({cap}: {} hosted, max clients {max_clients})",
                hosted.len()
            ),
        ));
    }
    let free: Vec<&String> = hosted
        .iter()
        .copied()
        .filter(|h| !leased.contains(h))
        .collect();
    if free.len() < leases as usize {
        let busy: Vec<&str> = hosted
            .iter()
            .filter(|h| leased.contains(h))
            .map(|h| h.as_str())
            .collect();
        return Err(Stop::new(
            3,
            format!(
                "only {} free instance(s) for {leases} lease(s); leased by other sessions: {}",
                free.len(),
                busy.join(", ")
            ),
        ));
    }
    Ok(free
        .iter()
        .take(leases as usize)
        .enumerate()
        .map(|(i, name)| PlanLane {
            lane: i as u32 + 1,
            instance: (*name).clone(),
        })
        .collect())
}

/// The arguments of one `lab_uat_run` call. Keys the PowerShell leaves out are
/// left out here.
#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct RunCall {
    pub sections: Vec<String>,
    #[serde(skip_serializing_if = "Vec::is_empty")]
    pub rows: Vec<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub specs_dir: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub server_version: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub fixtures: Option<String>,
    #[serde(skip_serializing_if = "Vec::is_empty")]
    pub chaos: Vec<String>,
    #[serde(skip_serializing_if = "is_false")]
    pub fingerprint: bool,
    #[serde(skip_serializing_if = "is_false")]
    pub plan_only: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub instance: Option<String>,
}

impl RunCall {
    /// The arguments every call of the batch shares (`$baseArgs`). `chaos` is
    /// already filtered (`args::chaos_specs`); `fingerprint` is
    /// `--fingerprint` or `--diff-golden` (and `--chaos` implies the latter).
    pub fn new(
        section: &str,
        rows: &[String],
        specs_dir: Option<&str>,
        server_version: Option<&str>,
        fixtures: Option<&str>,
        chaos: &[String],
        fingerprint: bool,
    ) -> Self {
        let some = |v: Option<&str>| v.filter(|s| !s.is_empty()).map(str::to_string);
        RunCall {
            sections: vec![section.to_string()],
            rows: rows.to_vec(),
            specs_dir: some(specs_dir),
            server_version: some(server_version),
            fixtures: some(fixtures),
            chaos: chaos.to_vec(),
            fingerprint,
            plan_only: false,
            instance: None,
        }
    }

    /// The plan call: `plan_only` on the first lane's instance.
    pub fn for_plan(&self, instance: &str) -> RunCall {
        RunCall {
            plan_only: true,
            instance: Some(instance.to_string()),
            ..self.clone()
        }
    }

    /// One run on a lane (LX-16 uses it): the instance set, `plan_only` off.
    pub fn for_lane(&self, instance: &str) -> RunCall {
        RunCall {
            plan_only: false,
            instance: Some(instance.to_string()),
            ..self.clone()
        }
    }

    /// The call as the JSON the daemon receives.
    pub fn to_value(&self) -> Value {
        serde_json::to_value(self).unwrap_or_default()
    }
}

/// What a ready plan reply says.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Planned {
    /// The rows the runner will run, in its order.
    pub rows: Vec<String>,
    /// The runner's own chaos header (`Get-UatRunChaos`), when the reply has one.
    pub chaos: Option<String>,
}

/// The runner's `chaos` list joined with `"; "`; `None` when the reply has none
/// (or only empty entries).
pub fn run_chaos(reply: &Value) -> Option<String> {
    let headers: Vec<&str> = reply
        .get("chaos")
        .and_then(Value::as_array)
        .map(|a| a.iter().filter_map(Value::as_str).filter(|s| !s.is_empty()).collect())
        .unwrap_or_default();
    if headers.is_empty() {
        None
    } else {
        Some(headers.join("; "))
    }
}

/// Judges the plan-only reply: a request for a row the section lacks is exit 2,
/// a row that cannot run is exit 3.
pub fn judge_plan(reply: &Value, requested: &[String], section: &str) -> Result<Planned, Stop> {
    let chaos = run_chaos(reply);
    let rows: Vec<&Value> = reply
        .get("rows")
        .and_then(Value::as_array)
        .map(|a| a.iter().collect())
        .unwrap_or_default();
    let text = |row: &Value, key: &str| -> String {
        row.get(key).and_then(Value::as_str).unwrap_or("").to_string()
    };
    let ids: Vec<String> = rows.iter().map(|r| text(r, "row")).collect();
    if ids.is_empty() {
        return Err(Stop::new(2, format!("no rows matched in section {section}")));
    }
    let missing: Vec<&str> = requested
        .iter()
        .filter(|r| !ids.contains(r))
        .map(String::as_str)
        .collect();
    if !missing.is_empty() {
        return Err(Stop::new(
            2,
            format!(
                "section {section} has no row(s) {} (row ids are exact and case sensitive)",
                missing.join(", ")
            ),
        ));
    }
    let not_ready: Vec<String> = rows
        .iter()
        .filter(|r| text(r, "result") != "SKIPPED")
        .map(|r| {
            let reason = r
                .get("reasons")
                .and_then(Value::as_array)
                .and_then(|a| a.first())
                .and_then(Value::as_str)
                .unwrap_or("");
            format!(
                "{} {}: {}",
                text(r, "row"),
                text(r, "result"),
                hide_lease_ids(reason)
            )
        })
        .collect();
    if !not_ready.is_empty() {
        return Err(Stop::new(3, format!("not ready: {}", not_ready.join("; "))));
    }
    Ok(Planned { rows: ids, chaos })
}

/// `plan.json`'s `started`: UTC, round-trip format with seven fractional digits.
pub fn started_text(at: DateTime<Utc>) -> String {
    format!(
        "{}.{:07}Z",
        at.format("%Y-%m-%dT%H:%M:%S"),
        at.timestamp_subsec_nanos() / 100
    )
}

/// The batch folder's name from the local start time: `batch-yyyyMMdd-HHmmss`.
pub fn batch_folder_name(local: &NaiveDateTime) -> String {
    format!("batch-{}", local.format("%Y%m%d-%H%M%S"))
}

/// The `plan.json` of a batch (schema 1).
pub fn build_plan(
    section: &str,
    rows: &[String],
    lanes: &[PlanLane],
    runs_per_lease: u32,
    started: DateTime<Utc>,
    pid: u32,
) -> Plan {
    Plan {
        schema: 1,
        section: section.to_string(),
        rows: rows.to_vec(),
        lanes: lanes.to_vec(),
        runs_per_lease,
        started: started_text(started),
        pid: Some(pid),
    }
}

/// Creates `<root>\<folder>` and writes `plan.json` into it before any lane
/// starts, so a watcher never sees runs without a plan. `Err` is exit 3.
pub fn create_batch(root: &Path, folder: &str, plan: &Plan) -> Result<PathBuf, Stop> {
    let dir = root.join(folder);
    fs::create_dir_all(&dir)
        .and_then(|_| write_plan(&dir.join(PLAN_JSON), plan))
        .map_err(|e| {
            Stop::new(
                3,
                format!(
                    "cannot write the batch folder {}: {}",
                    dir.display(),
                    first_line(&e.to_string())
                ),
            )
        })?;
    Ok(dir)
}
```

## Step 4: `uat/preflight.rs` (new)

The whole pre-flight with its collaborators passed in, so the tests drive it with
a stub `/status` server and a stub MCP closure. Order of events (the
PowerShell's): missing section; argument checks; chaos and leases; the golden
check; the daemon answers; the instances; foreign `SGW.exe` (not under
`--plan-only`); the plan call; the plan's checks; `--plan-only` output.

```rust
//! `lab uat` before anything is driven. Collaborators come in through [`Deps`]
//! so the pre-flight is tested without a daemon or a game client.

use std::io::Write;
use std::path::{Path, PathBuf};
use std::time::Duration;

use serde::Serialize;
use serde_json::Value;

use crate::batch::PlanLane;
use crate::daemon::env_file::{self, EnvLine};
use crate::daemon::mcp::{hide_lease_ids, McpError};
use crate::daemon::status::{self, Endpoint};
use crate::ui::{Mark, Tone, Ui};

use super::args::{
    chaos_header, chaos_specs, check_arguments, check_chaos_leases, progress_mode, row_ids,
    Progress, USAGE,
};
use super::plan::{first_line, judge_plan, pick_lanes, RunCall};
use super::Args;

/// The plan call is allowed two minutes (`Invoke-McpTool ... 120`).
pub const PLAN_TIMEOUT: Duration = Duration::from_secs(120);

/// What the pre-flight reaches outside itself for.
pub struct Deps<'a> {
    /// The daemon's endpoint (`GET /status` goes here).
    pub ep: &'a Endpoint,
    /// The default spec folder (`--specs-dir` overrides it); `None` outside a checkout.
    pub specs: Option<String>,
    /// The daemon's `CIMMERIA_LAB_MAX_CLIENTS`, 0 for none.
    pub max_clients: u32,
    /// Pids of every running `SGW.exe`.
    pub sgw_pids: &'a dyn Fn() -> Vec<u32>,
    /// One MCP tool call: name, arguments, timeout.
    pub call: &'a mut dyn FnMut(&str, Value, Duration) -> Result<Value, McpError>,
}

/// Everything LX-16 needs to drive the batch after a ready pre-flight.
#[derive(Debug, Clone)]
pub struct Ready {
    pub section: String,
    pub lanes: Vec<PlanLane>,
    /// The rows the runner will run.
    pub rows: Vec<String>,
    /// The runner's chaos header, else the typed one.
    pub chaos: Option<String>,
    /// The arguments shared by every run (plan_only off, no instance).
    pub call: RunCall,
    /// `--diff-golden`, or implied by `--chaos`.
    pub diff_golden: bool,
    /// The spec folder in use.
    pub specs: Option<String>,
}

/// How the pre-flight ended.
#[derive(Debug, Clone)]
pub enum Outcome {
    /// Finished: the exit code (a refusal, or `--plan-only` done).
    Done(u8),
    /// Ready to drive.
    Drive(Ready),
}

#[derive(Serialize)]
struct StopJson<'a> {
    ok: bool,
    exit: u8,
    error: &'a str,
}

#[derive(Serialize)]
struct PlanJson<'a> {
    ok: bool,
    plan_only: bool,
    rows: &'a [String],
    lanes: Vec<&'a str>,
    #[serde(skip_serializing_if = "Option::is_none")]
    chaos: Option<&'a str>,
}

/// A usage or pre-flight failure: under `--json` one object on stdout
/// (`{"ok":false,"exit":N,"error":...}`), else the message on stderr (plain, as
/// the PowerShell; fancy: `error:` in bold red first).
pub fn stop(ui: &Ui, json: bool, code: u8, message: &str, out: &mut dyn Write, err: &mut dyn Write) -> Outcome {
    if json {
        let body = StopJson { ok: false, exit: code, error: message };
        let _ = writeln!(out, "{}", serde_json::to_string(&body).unwrap_or_default());
    } else if ui.fancy {
        let _ = writeln!(err, "{} {message}", ui.paint(Tone::Fail, "error:"));
    } else {
        let _ = writeln!(err, "{message}");
    }
    Outcome::Done(code)
}

/// One progress line to where `progress` says.
fn say(progress: Progress, text: &str, out: &mut dyn Write, err: &mut dyn Write) {
    match progress {
        Progress::Host => {
            let _ = writeln!(out, "{text}");
        }
        Progress::Stderr => {
            let _ = writeln!(err, "{text}");
        }
        Progress::None => {}
    }
}

/// The committed golden of a section under a spec folder, named as the daemon
/// names it: every character outside `[A-Za-z0-9_-]` becomes `_`, so `v1.2` is
/// `golden/v1_2.json` (the same rule as LX-11's `golden_path`, decision 7).
pub fn golden_file(specs: &Path, section: &str) -> PathBuf {
    let safe: String = section
        .chars()
        .map(|c| if c.is_ascii_alphanumeric() || c == '_' || c == '-' { c } else { '_' })
        .collect();
    specs.join("golden").join(format!("{safe}.json"))
}

/// Why a committed golden cannot be used, or `None` when it reads as a JSON
/// object with `schema`, `section` and `fingerprint` (a `null` counts as
/// missing). A broken golden never costs a batch.
pub fn golden_unreadable(path: &Path) -> Option<String> {
    let bytes = match std::fs::read(path) {
        Ok(b) => b,
        Err(e) => return Some(first_line(&e.to_string())),
    };
    let text = String::from_utf8_lossy(&bytes);
    let value: Value = match serde_json::from_str(text.trim_start_matches('\u{feff}')) {
        Ok(v) => v,
        Err(e) => return Some(first_line(&e.to_string())),
    };
    let Some(object) = value.as_object() else {
        return Some("it is not a JSON object".to_string());
    };
    let missing: Vec<&str> = ["schema", "section", "fingerprint"]
        .into_iter()
        .filter(|k| object.get(*k).is_none_or(Value::is_null))
        .collect();
    if missing.is_empty() {
        None
    } else {
        Some(format!("it has no {}", missing.join(", ")))
    }
}

/// `CIMMERIA_LAB_MAX_CLIENTS` from the labd.env lines: all digits (trimmed),
/// else 0.
pub fn max_clients_from(lines: &[EnvLine]) -> u32 {
    env_file::get(lines, "CIMMERIA_LAB_MAX_CLIENTS")
        .map(str::trim)
        .filter(|v| !v.is_empty() && v.bytes().all(|b| b.is_ascii_digit()))
        .and_then(|v| v.parse::<u32>().ok())
        .unwrap_or(0)
}

/// Runs the pre-flight. Exit 2 for usage (before the daemon is asked), 3 when
/// the daemon, an instance, a foreign client or the plan stops it; with
/// `--plan-only` it prints the plan and finishes with 0; otherwise it returns
/// [`Outcome::Drive`].
pub fn execute(
    args: &Args,
    ui: &Ui,
    deps: &mut Deps<'_>,
    out: &mut dyn Write,
    err: &mut dyn Write,
) -> Outcome {
    let json = args.json;
    let Some(section) = args.section.as_deref().filter(|s| !s.is_empty()) else {
        return stop(ui, json, 2, USAGE, out, err);
    };
    // Argument checks come before the daemon is asked, so they exit 2 whatever its state.
    if let Some(shape) = check_arguments(args) {
        return stop(ui, json, 2, &shape, out, err);
    }
    let chaos = chaos_specs(&args.chaos);
    if let Some(shape) = check_chaos_leases(&chaos, args.leases) {
        return stop(ui, json, 2, &shape, out, err);
    }
    let specs: Option<String> = args
        .specs_dir
        .clone()
        .filter(|s| !s.is_empty())
        .or_else(|| deps.specs.clone());
    // lab-chaos D-CH7: a chaos run is reported against the golden, so --chaos
    // implies --diff-golden (and with it fingerprint capture on every row).
    let chaos_on = !chaos.is_empty();
    let diff_golden = args.diff_golden || chaos_on;
    // A diff needs a golden: without one, stop before anything is driven. A
    // chaos plan drives nothing, so it is not checked. With no local spec folder
    // a chaos run lets the daemon resolve its own (a missing golden is then each
    // run's diff error, exit 5); --diff-golden alone still needs a spec folder.
    let check_golden = diff_golden && !(chaos_on && args.plan_only) && (specs.is_some() || !chaos_on);
    if check_golden {
        let Some(dir) = &specs else {
            let m = "--diff-golden needs --specs-dir (no spec folder found next to this checkout)";
            return stop(ui, json, 2, m, out, err);
        };
        let path = golden_file(Path::new(dir), section);
        if !path.exists() {
            let m = if chaos_on {
                format!("no golden for {section}; --chaos reports against it, so record one first with lab golden record (lab-golden GD-10)")
            } else {
                format!("no golden for {section}; record one with lab golden record")
            };
            return stop(ui, json, 2, &m, out, err);
        }
        if let Some(why) = golden_unreadable(&path) {
            let m = format!("golden for {section} cannot be read: {why}");
            return stop(ui, json, 2, &m, out, err);
        }
    }
    let requested = row_ids(&args.rows);
    let progress = progress_mode(args.json, args.quiet, args.progress_to_stderr);

    // Pre-flight: daemon, instances, leases, foreign clients.
    let Some(status) = status::fetch(deps.ep) else {
        let m = "the lab daemon is not answering (lab status; lab start)";
        return stop(ui, json, 3, m, out, err);
    };
    let hosted: Vec<String> = status.instances.iter().map(|i| i.instance.clone()).collect();
    let leased: Vec<String> = status
        .instances
        .iter()
        .filter(|i| {
            i.lease
                .as_ref()
                .and_then(|l| l.get("held"))
                .and_then(Value::as_bool)
                == Some(true)
        })
        .map(|i| i.instance.clone())
        .collect();
    let instance = args.instance.as_deref().filter(|s| !s.is_empty());
    let lanes = match pick_lanes(args.leases, args.runs_per_lease, &hosted, &leased, deps.max_clients, instance) {
        Ok(lanes) => lanes,
        Err(s) => return stop(ui, json, s.code, &s.message, out, err),
    };
    if !args.plan_only {
        let lab_pids: Vec<u32> = status.instances.iter().filter_map(|i| i.client_pid).collect();
        let foreign: Vec<String> = (deps.sgw_pids)()
            .into_iter()
            .filter(|pid| !lab_pids.contains(pid))
            .map(|pid| pid.to_string())
            .collect();
        if !foreign.is_empty() {
            let m = format!(
                "SGW.exe runs outside the lab (pid {}); close it first, or the lab cannot start its clients",
                foreign.join(", ")
            );
            return stop(ui, json, 3, &m, out, err);
        }
    }

    // Plan once: a row that cannot run, or a requested row the spec lacks,
    // stops the batch before anything is driven.
    let base = RunCall::new(
        section,
        &requested,
        specs.as_deref(),
        args.server_version.as_deref(),
        args.fixtures.as_deref(),
        &chaos,
        args.fingerprint || diff_golden,
    );
    let first = lanes.first().map(|l| l.instance.clone()).unwrap_or_default();
    let reply = match (deps.call)("lab_uat_run", base.for_plan(&first).to_value(), PLAN_TIMEOUT) {
        Ok(reply) => reply,
        Err(e) => {
            let m = format!(
                "the plan call failed: {}",
                hide_lease_ids(&first_line(&e.to_string()))
            );
            return stop(ui, json, 3, &m, out, err);
        }
    };
    let planned = match judge_plan(&reply, &requested, section) {
        Ok(p) => p,
        Err(s) => return stop(ui, json, s.code, &s.message, out, err),
    };
    // The runner's resolved header replaces the typed one (lab-chaos CH-08).
    let header = planned.chaos.clone().or_else(|| chaos_header(&chaos));
    let lane_names: Vec<&str> = lanes.iter().map(|l| l.instance.as_str()).collect();

    if args.plan_only {
        if json {
            let body = PlanJson {
                ok: true,
                plan_only: true,
                rows: &planned.rows,
                lanes: lane_names.clone(),
                chaos: header.as_deref(),
            };

                format!("{} {text}", ui.paint(Tone::Ok, ui.mark(Mark::Pass)))
            } else {
                text
            };
            say(progress, &line, out, err);
        }
        return Outcome::Done(0);
    }

        section: section.to_string(),
        lanes,
        rows: planned.rows,
        chaos: header,
        call: base,
        diff_golden,
```

```rust
/// The native pre-flight on real collaborators. Returns the daemon endpoint (a
/// native batch drives on it) with how the pre-flight ended.
fn native_preflight(args: &Args, ctx: &Ctx) -> (Endpoint, Outcome) {
    let ep = Endpoint::discover();
    let specs = paths::default_specs_dir().map(|p| p.display().to_string());
    let max_clients =
        preflight::max_clients_from(&env_file::read_or_empty(&paths::labd_env_path()));
    // One MCP session per call, closed after it (the PowerShell did the same).
    let call_ep = ep.clone();
    let mut call = move |name: &str, call_args: Value, wait: Duration| -> Result<Value, McpError> {
        let mut client = McpClient::connect(&call_ep)?;
        let reply = client.call_tool(name, call_args, wait);
        client.close();
        reply
    };
    let sgw = sgw_pids;
    let mut deps = Deps {
        ep: &ep,
        specs,
        max_clients,
        sgw_pids: &sgw,
        call: &mut call,
    };
    let mut out = anstream::stdout();
    let mut err = anstream::stderr();
    let outcome = execute(args, &ctx.ui, &mut deps, &mut out, &mut err);
    (ep, outcome)
}

/// Runs `lab uat` and returns its exit code. `--plan-only` is native: a usage
/// error is 2, a refusal before anything is driven is 3, the plan ends with 0.
/// A real run goes straight to the PowerShell fallback WITHOUT the native
/// pre-flight (the script does its own), so nothing is planned twice and no
/// second batch folder is made. LX-16b replaces this function.
pub fn run(args: &Args, ctx: &Ctx) -> u8 {
    if !args.plan_only {
        return fallback::run(ctx);
    }
    match native_preflight(args, ctx).1 {
        Outcome::Done(code) => code,
        // `--plan-only` never returns Drive; the fallback is the safe answer if it did.
        Outcome::Drive(_) => fallback::run(ctx),
    }
}
```

```rust
struct Ran {
    outcome: Outcome,
    out: String,
    err: String,
    calls: Vec<(String, Value)>,

impl Ran {
    fn code(&self) -> Option<u8> {

            Outcome::Done(c) => Some(c),
            Outcome::Drive(_) => None,
        }
    }

fn args(tokens: &[&str]) -> Args {

    all.extend_from_slice(tokens);

/// `[(instance, leased, client_pid)]` as the daemon's /status body.
fn status_body(rows: &[(&str, bool, Option<u32>)]) -> String {
    let instances: Vec<Value> = rows
        .iter()
        .map(|(name, held, pid)| json!({"instance": name, "client_pid": pid, "lease": {"held": held}}))
        .collect();
    json!({"daemon": {"pid": 1, "version": "x"}, "instances": instances}).to_string()
}

fn one_free() -> String {
    status_body(&[("default", false, None)])
}

fn ready(rows: &[&str]) -> Value {
    let rows: Vec<Value> = rows
        .iter()
        .map(|r| json!({"row": r, "result": "SKIPPED", "reasons": []}))
        .collect();
    json!({ "rows": rows })
}

fn with_chaos(mut reply: Value, headers: &[&str]) -> Value {
    reply["chaos"] = json!(headers);
    reply
}

const FANCY: Ui = Ui { color: false, fancy: true, width: None };

fn run_with(
    tokens: &[&str],
    ep: &Endpoint,
    specs: Option<&str>,
    max_clients: u32,
    sgw: Option<Vec<u32>>,
    ui: Ui,
    replies: Vec<Result<Value, McpError>>,
) -> Ran {
    let queue = RefCell::new(VecDeque::from(replies));
    let calls = RefCell::new(Vec::<(String, Value)>::new());
    let mut call = |name: &str, a: Value, _t: Duration| -> Result<Value, McpError> {
        calls.borrow_mut().push((name.to_string(), a));
        queue.borrow_mut().pop_front().expect("an unexpected MCP call")
    };
    let sgw_fn = move || sgw.clone().expect("SGW.exe must not be scanned here");
    let mut deps = Deps {
        ep,
        specs: specs.map(str::to_string),
        max_clients,
        sgw_pids: &sgw_fn,
        call: &mut call,
    };
    let (mut out, mut err) = (Vec::new(), Vec::new());
    let outcome = execute(&args(tokens), &ui, &mut deps, &mut out, &mut err);
    Ran {
        outcome,
        out: String::from_utf8(out).unwrap(),
        err: String::from_utf8(err).unwrap(),
        calls: calls.into_inner(),
    }
}

    run_with(tokens, &ep, None, 0, Some(vec![]), Ui::plain(), replies)
}
```

```rust
//! LX-15: `lab uat` through the real binary. Ports test-uat-chaos.ps1's two
//! "reaches the daemon" guards, which ran `uat.ps1` with every daemon call stubbed.
//! Every call passes `--plan-only` (or `-PlanOnly`): a real run goes to the
//! PowerShell script until LX-16b, and a test must never start that.

use std::path::Path;
use std::process::{Command, Output};

use serde_json::Value;
use tempfile::TempDir;

fn fake_home() -> TempDir {

fn run_lab(args: &[&str], home: &Path) -> Output {
    Command::new(env!("CARGO_BIN_EXE_lab"))
        .args(args)
        .env("CIMMERIA_LAB_HOME", home)
        .env_remove("CIMMERIA_LAB_DAEMON_TOKEN")
        .env_remove("NO_COLOR")
        .output()
        .expect("run lab")
}

fn last_json(output: &Output) -> Value {
    let stdout = String::from_utf8_lossy(&output.stdout).into_owned();
    let line = stdout.lines().last().unwrap_or("").to_string();
    serde_json::from_str(&line).unwrap_or_else(|e| panic!("not JSON ({e}): {stdout:?}"))
}
```
