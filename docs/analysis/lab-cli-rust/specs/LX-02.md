## Things the real LX-01 code does that differ from the packet's text

- `Ctx.command` is a `String` (not `&'static str`); `Ui` is `Copy`.
- `commands::version::run()` returns `ExitCode` today; LX-02a changes it to `u8`.
- `lib.rs` has `main_with`, `help_for`, `dispatch`, `unknown_command`. `dispatch`
  currently special-cases `version` and sends every other known name to the
  fallback. LX-02a rewrites `help_for` and `dispatch` (code below).
- `argv::rewrite(args: Vec<OsString>) -> Vec<OsString>` exists in `src/argv.rs`.
- `fallback::run(ctx: &Ctx) -> u8` exists in `src/fallback.rs`.
- `commands::find(name: &str) -> Option<&'static CommandInfo>` exists.

Contract deviations decided here (the coordinator should reconcile the packet text):

1. `--chaos` is a repeatable list WITHOUT `value_delimiter`
   (`action = Append`, `num_args = 1..`). The contract says to split on commas,
   but a multi-knob spec such as `net:latency=120,loss=1` contains commas and
   must stay whole (the PowerShell help says to quote it). Splitting the top-level
   list (`cpu,flush:pack`) is the job of the later port of `uat`.
2. `[int]` parameters are `u32` (no `ValidateRange`: PowerShell checks ranges in
   code and each port will produce its own message and exit code). A negative or
   non-numeric value is a clap usage error, exit 2, which is the PowerShell exit
   code for a bad argument too.
3. `completions` has no clap subcommand (LX-18 adds it). It stays in `COMMANDS`.
4. `env` accepts `--value` as a flag as well as the third positional, because
   `argv::rewrite` turns `-Value:-x` into `--value=-x`.

3c. Replace the whole `dispatch` function with:

```rust
/// Runs one command: clap parses it (a name clap does not know yet becomes
/// `Command::Other` and goes to the PowerShell fallback with its original
/// tokens).
fn dispatch(ui: Ui, raw: Vec<OsString>, rewritten: Vec<OsString>) -> ExitCode {
    let name = raw
        .first()
        .map(|t| t.to_string_lossy().into_owned())
        .unwrap_or_default();
    if commands::find(&name).is_none() {
        return unknown_command(&ui, &name);
    }
    let cli = match Cli::try_parse_from(once(OsString::from("lab")).chain(rewritten)) {
        Ok(cli) => cli,
        Err(err) => return clap_error(err, &ui, &name),
    };
    let Some(command) = cli.command else {
        return ExitCode::SUCCESS;
    };
    let ctx = Ctx {
        ui,
        command: name,
        raw: raw.into_iter().skip(1).collect(),
    };
    ExitCode::from(commands::dispatch(&command, &ctx))
}

/// Prints a clap error (or help page) and returns its exit code: 0 for help,
/// 2 for a usage error. An unknown subcommand gets the `lab` unknown-command
/// message instead of clap's.
fn clap_error(err: clap::Error, ui: &Ui, name: &str) -> ExitCode {
    if err.kind() == clap::error::ErrorKind::InvalidSubcommand {
        return unknown_command(ui, name);
    }
    let code = u8::try_from(err.exit_code()).unwrap_or(2);
    let _ = err.print();
    ExitCode::from(code)
}
```

## Step 4: the nine command files

Each file has this shape (module doc, the `Args` struct with `#[derive(clap::Args,
Debug)]` and a `#[command(...)]`, the `run` function, a `tests` module). Rules
that apply to every file:

- Every field is `pub`. Field help text is the field's `///` doc comment, written
  exactly as in the tables, no trailing period (clap strips one anyway).
- Flags are `#[arg(long)]`. The flag name is the field name in kebab-case
  (`runs_per_lease` becomes `--runs-per-lease`); that is what `argv::rewrite`
  produces from the PowerShell spelling. There are no short flags.
- A positional field is `#[arg()]` or has no attribute at all (clap makes a
  field without `long` positional, in field order).
- A `Vec<String>` list flag is `#[arg(long, value_delimiter = ',', num_args = 1..)]`.
- Long text is a `const LONG: &str = concat!("para 1", "\n\n", "para 2", ...);` and
  the examples a `const EXAMPLES: &str = "Examples:\n  lab ...\n  lab ...";`
  (paragraphs below are given as text; copy them verbatim, one `concat!` item per
  paragraph, escaping nothing because they contain no double quotes or
  backslashes). `about` is the summary from `COMMANDS` (copy it from
  `commands/mod.rs`, do not retype it).
- The struct carries a plain `//` comment, not `///` (so clap cannot take it as
  help text): `// Arguments of `lab <name>`.`
- `run` is exactly: `pub fn run(args: &Args, ctx: &Ctx) -> u8 { let _ = args; fallback::run(ctx) }`
  with `use crate::commands::Ctx; use crate::fallback;`.
- No command writes anything itself in this packet.
