# Launcher Redesign UAT — 2026-10-03 (PR 1 of #1153)

> Type: how-to (UAT checklist). Audience: the owner or a tester on a Windows PC; no programming needed.
> Updated: 2026-10-03. Companions: [campaign ledger](README.md), [launcher guide](../../client/launcher-guide.md), [sgw-launcher.md](../../client/sgw-launcher.md), [unified UAT guide § Windows launcher](../../guides/unified-uat.md#windows-launcher).

This checklist accepts PR 1 of the Windows launcher redesign: the new
window, Install/Play, the game lifecycle, the diagnostics footer, Patch
Notes and Game settings. **Repair game** and **Uninstall…** are not in
PR 1; only check that they are visible and disabled (LR-34).

This file is the canonical list. The
[unified UAT guide](../../guides/unified-uat.md#windows-launcher) carries
the same step ids.

## Prerequisites

- A Windows 10 or 11 PC. Run on native Windows, not Wine.
- A launcher **release** build that contains PR 1 (a release embeds the
  client-patches DLL and `sgw-start32.exe`; a dev build cannot pass
  LR-43). Put it in a folder of your own, such as
  `%LOCALAPPDATA%\Stargate Worlds Launcher`.
- About 14 GB free on the install drive for a first install from the
  archive.org seed, and a working internet connection.
- A server account (the colo) for LR-43.
- Optional: an existing stock client folder you do not mind adopting
  (LR-12, LR-28), and the Atera tarball for LR-20.
- Task Manager (**Ctrl+Shift+Esc** › **Details**) to watch `SGW.exe`.
- Settings › Advanced › **Activity log** shows what the launcher did.
  Copy its lines into every failure report.

To start from a clean first run, close the launcher and rename
`launcher-config.json` beside it. Put it back afterwards.

## Steps

Do the steps in order; later ones assume an installed game.

### Look and layout

| # | Do | Expect | Notes |
|---|---|---|---|
| LR-01 | With Windows in **dark** mode (Settings › Personalization › Colors), start the launcher | Dark blue-gray window, cyan primary button, gate on the left, Play / Patch Notes tabs with a gear, **Share diagnostic logs** at the bottom. No game picker, no list of launch buttons | |
| LR-02 | Switch Windows to **light** mode, restart the launcher | The window is exactly as dark as in LR-01; every text is readable | Dark only, by design |
| LR-03 | Set Windows display scale to 100 %, 150 % and, if offered, 200 % (restart the launcher each time) | Nothing is clipped or overlaps; text is sharp; the window still fits the screen | Note the scale and screen size of any failure |
| LR-04 | Resize the window: from 1030 × 720 down to the minimum, and back. Cross 760 px wide both ways | Below 760 px the gate panel folds away and the main column fills the window; it returns when wider. The main column scrolls when short; the diagnostics footer always stays visible. The window will not go below 560 × 520 | |
| LR-05 | Use only the keyboard: **Tab** through the window, **Space** or **Enter** on the tabs, the gear, the checkbox and the primary button | Every control can be reached and shows where focus is; Space or Enter activates it | Note any control you cannot reach or cannot see focused |
| LR-06 | Read every text on the Play tab, Patch Notes and Game settings at your normal scale | Grey secondary text is still readable against the background; long patch descriptions wrap | |

### First run and install

| # | Do | Expect | Notes |
|---|---|---|---|
| LR-07 | Clean first run (see Prerequisites) | No pop-up or prompt about telemetry. **Share diagnostic logs · Off**, with "Your choice applies when you next launch the game." The Play tab says **One setup. Then just Play.** with the download size and the install folder | |
| LR-08 | Press **Install Stargate Worlds** once | The card changes on the same click (Starting…), then shows **Downloading** with a progress bar and size, later **Installing files** with file names. Switch to Patch Notes and back, and open and close the gear, while it runs: progress carries on | |
| LR-09 | During the download press **Cancel** | "Cancelling… the current step finishes first.", then "Installation cancelled. What finished is kept; Install picks up from there." The button is **Install** again (**Update** if the base game had finished). Close and reopen the launcher: the same state. Press it: the download continues from where it stopped, not from zero | |
| LR-10 | During the download, unplug the network (or turn Wi-Fi off) | "Installation failed: …" with a reason, in red; the button is **Install** (or **Update**) again. Reconnect and press it: it resumes | |
| LR-11 | Let an install finish | "Installation complete."; the card shows **● Ready to play** and the button **Play**. Restart the launcher: still **Ready to play** | |
| LR-12 | Settings › **Change folder…** to a folder that holds a stock client with no `launcher-installed.json`; **Check folder**, **Use this folder** | The Play tab shows **Stargate Worlds found in this folder** and **Use this installation**. Press it: "Existing installation adopted. Its files were not verified." Then **Update** (patches to apply) or **Play** | Adopt does not download the base game |
| LR-13 | Close the game. In the install folder, edit `launcher-installed.json` and remove one id from `applied_patches`. Restart the launcher | **An update is ready**, "1 patch to apply…", with **Update** and **Play without updating**. **Play without updating** starts the game. After closing it, **Update** applies the patch and returns to **Ready to play** | |

### Play and the game lifecycle

| # | Do | Expect | Notes |
|---|---|---|---|
| LR-14 | Diagnostics **off**. Press **Play** once | At once: **Starting Stargate Worlds…**, button **Starting…**. Then **● Game running**, button **Playing**, caption "This game session: diagnostics off…". While it runs: Settings › **Change folder…** is greyed (hover says "Close the game first."); Advanced › Install, update and adopt says "Close the game first." Quit the game: within two seconds, without touching the mouse, "The game closed." and **Play** | Telemetry off still follows the game |
| LR-15 | Diagnostics **on**. Repeat LR-14 | Same states; the caption reads "This game session: diagnostics on…". After the game closes the activity log has "Telemetry session complete — …" (or a session error line saying why not) | |
| LR-16 | Start the game with diagnostics **on**, then untick the box while it runs; tick it again. Repeat starting with it **off** | Turning off: "Off from your next game launch. The game running now keeps sending diagnostics until it closes." Turning on from an off session: "On from your next game launch. Nothing is sent for the game running now." | |
| LR-17 | Press **Play**, then close the launcher window while the game runs | The game keeps running | Closing the launcher never closes the game |
| LR-18 | With the game from LR-17 still running, start the launcher again | **● Game running** within two seconds; the caption says "The game is running. A change applies on your next game launch."; Install, Update, folder change and Play are off. Quit the game: the card returns to **Ready to play** within two seconds | The launcher did not start this game; the process probe finds it |
| LR-19 | Click **Play** several times quickly (double- and triple-click) | Exactly one `SGW.exe` in Task Manager. Any extra click shows nothing new, or "Not started: the game is already starting." | |
| LR-20 | Atera files in the folder that holds `SGW.exe`. Settings › Advanced › Debug launches › **Launch Atera Debug** | Within two seconds the Play tab shows **● Game running**, and **Play** is off. Quit the game: back to **Ready to play** | Needs the Atera tarball; skip otherwise |
| LR-21 | While an install runs (start **Update** after LR-13's edit, or a fresh install) | **Play**, the debug launches, **Change folder…** and the client-state resets are all off | |

### Diagnostics footer

| # | Do | Expect | Notes |
|---|---|---|---|
| LR-22 | Tick **Share diagnostic logs**. Switch to Patch Notes, open the gear, open Advanced | The same box, ticked, is at the bottom of every view. **What is sent?** opens the explanation | |
| LR-23 | Close and reopen the launcher | Still ticked. `launcher-config.json` has `"opted_in": true`. Untick, restart: still unticked | Saved at the click, not on exit |
| LR-24 | Close the launcher. Set `launcher-config.json` to read-only (file Properties › Read-only). Start the launcher and change the box | A red line under it: "Could not save this choice (…). It holds only while this launcher window stays open." Clear the read-only flag afterwards | If the save still succeeds, report how the file was protected |

### Game settings

| # | Do | Expect | Notes |
|---|---|---|---|
| LR-29 | Gear › **Open in Explorer ↗** | "Opening …" under the folder, and Explorer opens at the install folder | |

## Recording results

Use the template in the
[unified UAT guide § Recording results](../../guides/unified-uat.md#recording-results),
with `System: Windows launcher`. Instead of a character, give the Windows
version, display scale, whether Windows was in light or dark mode, and
the launcher version (Settings › Advanced › Launcher updates). Paste the
activity-log lines for any failure.
