# Nine-zone shell test

The `v6` candidate replaces the open four-way grid with a 3 × 3 Ancient
interior. The south edge leads to the existing gate apron. It is still an
actor assembly on the technical scaffold, not the final authored level.

| North ↑ | West | Center | East |
|---|---|---|---|
| `y=6316` | Cover gallery, elbow | Observation / archive, three-way | Encounter gallery, elbow |
| `y=4268` | Cover gallery, three-way | Index / control hub, four-way | Encounter chamber, three-way |
| `y=2220` | Archive / fixture room, elbow | Gate entry, four-way | Fabrication lab, elbow |
| `y=0` |  | Gate court with Stargate |  |
| `y=-2368` |  | Outdoor garden test slab |  |

The wall and ceiling geometry belongs to the Ancient hall meshes. Their
orientations are selected so the perimeter of the nine-module interior has
no intentional unused opening. The two northern side areas have physical
Ancient shield meshes for NPC cover experiments. The archive has shelves and
stasis equipment; fabrication has a mainframe, console and bench; the hub
has a power generator; the north hall has a terminal. The candidate also
clones an Agnos skydome actor. These are **placed visual meshes**. Native
cover nodes, NPC spawns, interactable fixtures and functional transport are
separate work.

The candidate is generated by
[`assemble_worldforge_probe.ps1`](../../../tools/map-lab/assemble_worldforge_probe.ps1)
from the `v2` grounded gate probe plus the `v4` visual fixtures. It adds a
guarded absolute-yaw placement option to `upk_patch`; the regression test
checks the serialized actor position and rotation. Package-level validation
found zero unloadable property names among 152 client-loaded exports.

## Client verification

The nine-module shell, sky, garden and fixtures have **not yet been visually
or collision verified in the client**. The first walkthrough must check:

1. Teleport to `.gotolocation CimmeriaLab 0 2 0`; keep ghost mode off.
2. Walk every interior edge, especially the joints between elbows,
   three-ways and hubs. Look for floor gaps, overlapping trims, missing
   walls or ceilings, and any route out into black void.
3. Check the gate court to garden seam and all exterior edges. The extra
   garden slab is a temporary SGC floor mesh; its border is **not sealed**.
4. Check whether the skydome renders from inside the level. Its placement
   passed package checks, not a lighting or visibility test.
5. Check that gallery cover and large fixtures do not block the main route.

The plan's transfer terrace, elevated mezzanine, functional Stargate,
environmental effects, NPCs, navigation and minimap remain to be built.
The current observation hall is on the main floor; the mezzanine's second
level and stairs require an authored vertical collision/nav test. Until an
exterior perimeter and the gate-hall join pass collision testing, the map
must not be described as sealed or escape-proof.
