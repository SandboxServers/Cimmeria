## Lessons

- **Don't run a live lab packet on a loaded workstation.** At full build load the client misses the bridge's fixed timeouts, and every failure looks like a spec or product bug. Check the lane and the CPU before taking the lease.
- **A clause that reads once races the thing it checks.** FS-01's heartbeat read 5 s after launch; SV-08's `timeout_ms` polling was the fix, and any similar one-shot clause after a launch or a login should poll too.
- **Docs follow code on grading semantics** (D-SV13): when a comment and the grader disagree, fix the comment, unless a row could PASS with a broken step.
