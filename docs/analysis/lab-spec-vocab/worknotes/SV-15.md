| Attempt | Result | Cause |
|---|---|---|
| 1 | FS-01 FAIL: the heartbeat clause read `unreachable` | The clause read `lab_client_status` once, about 5 s after `lab_client_start`. The bridge came up later; the display keep-awake engaged about 2 minutes after launch |
| 2 | FS-01 FAIL, the same way | The same |

The fix between attempts 2 and 3: FS-01's heartbeat clause polls for up to 60 s (`timeout_ms = 60000`, SV-08's clause polling) instead of reading once. It ships with the SV-16 close-out (`docs/guides/uat-specs/first-session.toml`, FS-01's `heartbeat` clause).

Root cause of attempt 3: machine load, not the spec or the build. The user chose to pause SV-15 rather than run the lab on a loaded workstation.
