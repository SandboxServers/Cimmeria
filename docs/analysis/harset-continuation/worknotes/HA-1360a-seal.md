## Decision and evidence

O14-17 requires Marsh to refuse completion without the owned Frost's Letter (item 3730); O14-19 makes mission 1360 one-shot. Castle CS-08a1 `583a85f` advances 4037 to 4038 on the Castle-to-Harset gate crossing while retaining the letter. Existing chain 6501 shows success dialog 4576, sends an unchecked asynchronous removal, clears dialog binding 5356 and completes mission 1360 independently. The base remover can refuse a missing item and the mission writer can later overwrite a completion. Current outbox delivery is keyed by entity ID and marks a channel send, not cell application. This is a `CIMMERIA_RECONSTRUCTION`, not a recovered 2009 mission script.

Database, mission, authority and testing advisers reviewed the source on 2026-10-14. Their common requirement is a mission-specific atomic consume/completion with a persisted one-shot receipt, plus a correlated, session-fenced result before any success side effect. Testing review found the proposed a2 child too broad: internal transport and session fencing become a2; the strict action and cell continuation become a3. Exact manifests and measured budgets still need signoff. No `db/scripts/` migration is authorized; canonical schema and seed reload are the database path.

## Shared a1/a2/a3 interface

- Fixed business tuple: mission 1360, active step 4038, owned accessible item type 3730, exact quantity 1, world 68, Marsh target `CmdCenter_Marsh`/template 10 and chain 6501. A request cannot substitute client counts, item instance, mission, recipient or quantity.
- The cell obtains player identity from the live entity and refuses unknown/zero or mismatched identity. It validates the server-resolved Marsh interaction, world, range, hydrated mission state and active 1360/4038 with 1361/4694 not active. The base dispatch rebinds entity, player and current session before calling a1. A stale request after logout or entity-ID reuse is refused.
- A request carries an opaque attempt key, a base-minted session token, the session generation and the world-entry epoch. The attempt survives same-attempt retry; the token changes on relog and the epoch changes on each entry, including same-world travel. A2 derives 16 bytes from `SHA-256("cimmeria:letter-turn-in:v1" || ConnectedClientState.key)` and sends only that digest prefix to the cell before interaction can run. The base recomputes it from the current connected session. Never log or expose the raw key or token. The result carries the same correlation, transaction outcome, consumed instance/before/after and persisted mission postimage. Both base and cell reject a mismatch. A3 checks the current world and Marsh target before any success effect. No client protocol or item propID changes are part of this packet.
- A1 owns the database transaction and durable receipt lookup. A2 owns internal messages, base routing and session fencing. A3 owns the strict content action, cell pending/retry, result application and feedback. A1–A3 do not deploy while old 6501 remains live; HA-1360b replaces the seed in the same campaign PR before any server uses the new handler.
