**A. `crates/base-methods/src/base/world_entry/methods/missions/letter_turn_in_concurrency_tests.rs`** (lines 55-88)

1. After the `FOR UPDATE` query (line 65), read the holder's backend pid on the same transaction:

   ```rust

       .fetch_one(&mut *delete_tx)
       .await
       .expect("deletion backend pid");
   ```

2. After `let turn_in = tokio::spawn(...)` (line 68), and before the `DELETE`, wait until the turn-in is blocked behind the holder:

   ```rust
   // The turn-in must be parked on the player row before the delete runs,
   // or the test only proves "no row" and never touches the lock order.
   let mut blocked = false;
   for _ in 0..1000 {
       let waiting: i64 = sqlx::query_scalar(
           "SELECT count(*) FROM pg_stat_activity WHERE $1 = ANY(pg_blocking_pids(pid))",
       )
       .bind(holder_pid)
       .fetch_one(&pool)
       .await
       .expect("blocked-session probe");
       if waiting > 0 {
           blocked = true;
           break;
       }
       tokio::time::sleep(Duration::from_millis(10)).await;
   }
   assert!(blocked, "turn-in never blocked on the player row lock");
   ```
